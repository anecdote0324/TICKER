# TICKER

블룸버그 터미널을 닮은 **개인용 데스크톱 시세 터미널**이에요.

> 지금은 **v0.1 미리 보기**예요. v0.1에 넣기로 한 기능은 모두 만들었고, 실제 Windows·Mac과 한국투자증권 계정으로 확인하는 중이에요. 설계는 [`docs/design/`](docs/design/)에 있고, 코드는 그 설계를 따라요. 버전마다 들어가는 기능과 진행 상황은 [버전별 기능](docs/versions.md)에 있어요.

## 설치하고 처음 열기

[Releases](https://github.com/anecdote0324/BloombergTerminal/releases)에서 가장 위 버전의 **Assets**를 열어 내 컴퓨터에 맞는 파일을 받아요. 정식 버전이 아직 없으면 저장소 첫 화면에는 `tag`로만 보이니, Releases 화면에서 `Pre-release` 표시가 붙은 버전을 찾아요. `Source code`는 실행 파일이 아니에요.

| 컴퓨터 | 받을 파일 |
|---|---|
| Windows (권장) | `TICKER.Setup.<버전>.exe` 설치형. 시작 메뉴에 등록되고 켜는 게 빨라요 |
| Windows (설치 없이) | `TICKER.<버전>.exe` 휴대용. 켤 때마다 압축을 풀어서 조금 느려요 |
| Mac (Apple Silicon, M1 이상) | `TICKER-<버전>-arm64.dmg`. 인텔 Mac은 지원하지 않아요 |

개인용이라 코드 서명을 하지 않아서, 처음 열 때 운영체제가 막아요. 아래처럼 한 번 허용하면 돼요.

**Windows**
- 브라우저가 "일반적으로 다운로드되지 않는 파일"이라고 하면 다운로드 목록의 `…` → **유지**를 눌러요.
- 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**을 눌러요.
- 새 버전은 새 설치 파일로 **덮어 설치**해요. 설정·한국투자증권 키·화면 배치는 그대로 남아요(`%APPDATA%\TICKER`).
- 제거 프로그램은 Windows 보안이 막을 수 있어요("이 앱의 일부가 차단되었습니다"). 지우려면 먼저 설정 → 앱 → 설치된 앱에서 제거해 보고, 막히면 앱을 끄고 설치 폴더(`%LOCALAPPDATA%\Programs\TICKER`)와 바로 가기를 지워요. 설정·키까지 지우려면 `%APPDATA%\TICKER`도 지워요.

**Mac**
1. `.dmg`를 열고 TICKER를 **응용 프로그램** 폴더로 끌어 놓아요.
2. 처음 실행하면 "확인되지 않은 개발자" 경고가 떠요. **완료(취소)** 를 누르고, **시스템 설정 → 개인정보 보호 및 보안**에서 "TICKER이(가) 차단되었습니다" 옆의 **그래도 열기**를 눌러요. 암호를 넣고 **열기**를 눌러요. macOS 15(Sequoia)부터는 오른쪽 클릭 → 열기로는 넘어가지 않아요.
3. "손상되었기 때문에 열 수 없습니다"가 뜨면 터미널에서 `xattr -cr /Applications/TICKER.app`을 실행한 뒤 다시 열어요.
4. 한국투자증권 키를 처음 저장할 때 키체인 사용을 묻는 창이 뜨면 **항상 허용**을 눌러요.
5. 새 버전을 설치하면 1~2번을 한 번 더 해야 할 수 있어요. 설정·키·화면 배치는 그대로 남아요(`~/Library/Application Support/TICKER`).

**공통**
- 자동 업데이트는 없어요. 새 버전은 Releases에서 받아 설치해요.
- 한국투자증권 키가 없으면 주식·지수는 `데모` 값으로 보여요. 코인(Binance)과 환율은 키 없이 실제 값이에요. 키는 앱의 설정(Ctrl+, / ⌘,) → 데이터 연결에서 넣어요.
- 예전 이름(Terminal)으로 설치했었다면, TICKER를 처음 켤 때 설정·키·화면 배치를 자동으로 옮겨 와요. 확인한 뒤 예전 Terminal 앱과 폴더는 지워도 돼요.

## 한눈에 보기

- 검정 배경에 주황 포인트를 쓰는 촘촘한 멀티 패널 화면, 키보드 중심의 커맨드 라인
- 국내·미국 주식(한국투자증권 Open API), 코인(Binance USDT), 환율, 그리고 단계적으로 금리 커브·채권·매크로·옵션·원자재까지
- 블룸버그 기능을 최대한 구현하되, 개인에게 의미 없는 속도의 데이터가 필요한 기능과 매매 기능은 빼요. 유료 데이터는 쓰지 않아요
- 실시간이 아닌 값에는 늘 회색 신선도 배지(`5초 주기`, `일별 10/22`, `마감`, `⚠ 멈춤`, `데모`)가 붙어요
- Windows 우선이고 macOS(Apple Silicon)도 지원하는 Electron 데스크톱 앱
- 나 혼자 쓰는 개인용 (시세를 다른 사람에게 재배포하지 않음)

## 실행하기 (개발 중)

필요한 것: Node.js 22 이상, pnpm(없으면 스크립트가 `corepack enable`로 켜요).

- Windows: `start.bat`을 더블클릭
- Mac: `start.command`를 더블클릭
- 직접: `pnpm install` 다음 `pnpm dev`

내장 서버(127.0.0.1:8787)와 화면 개발 서버(127.0.0.1:5173)가 함께 켜지고 브라우저가 열려요. 실행할 때마다 새 접속 토큰을 만들어 주소(`#token=…`)로 넘겨요. 끌 때는 그 창에서 Ctrl+C예요.

한국투자증권 앱키·앱시크릿은 앱의 설정(Ctrl+,) → 데이터 연결에서 넣어요. 키는 PC 안에 암호화해서 저장하고, 저장소에는 절대 올리지 않아요. 시세용으로는 잔고가 없는 별도 계좌의 키를 권해요.

## 데스크톱 앱 만들기

```
pnpm build            # 화면과 Electron 메인 프로세스 묶기
pnpm --filter @bt/desktop start   # 개발용으로 Electron 창 띄우기
pnpm dist             # 지금 OS용 설치 파일(apps/desktop/release). 종목 목록 사본(pnpm snapshot)도 새로 받아 넣어요
```

### 새 버전 내기

GitHub의 **Actions → Release → Run workflow**에서 종류만 고르고 실행해요. 번호는 지난 태그를 보고 자동으로 정해요.

| 종류 | 번호 예 |
|---|---|
| 미리 보기 (기본) | `0.1.0-beta.2` → `0.1.0-beta.3`, 정식 다음이면 `0.1.0` → `0.1.1-beta.1` |
| 정식 | `0.1.0-beta.3` → `0.1.0`, 정식 다음이면 `0.1.0` → `0.1.1` |
| 다음 단계 | `0.1.x` → `0.2.0-beta.1` |
| 설치 파일만 | 릴리스는 올리지 않고 Actions 실행 결과에만 남겨요(하루 뒤 지워져요) |

번호를 직접 정하려면 `tag` 칸에 `v0.1.0-beta.5`처럼 넣거나, 태그를 올려도 돼요(`git tag v0.1.0` → `git push origin v0.1.0`).

- GitHub Actions가 Windows 설치 파일(.exe, 설치형·휴대용)과 Mac(Apple Silicon) .dmg를 만들어 릴리스에 올려요. 정식 버전은 **초안**이라 GitHub의 Releases 화면에서 공개를 눌러야 하고, `-`가 붙은 미리 보기는 바로 공개돼요. 저장소가 비공개라 릴리스도 나만 볼 수 있어요.
- 앱 버전 번호는 태그에서 가져와요. package.json의 version은 고치지 않아도 돼요.
- 번호는 고치는 판이면 끝자리(`v0.1.1`), 다음 단계 기능이 다 들어가면 가운데(`v0.2.0`)를 올려요. `-`가 붙은 태그(`v0.2.0-beta.1`)는 미리 보기 릴리스예요.
- 릴리스에는 지난 릴리스와 바뀐 커밋을 비교하는 링크가 붙어요.
- 자동 업데이트는 없어요. 새 버전 설치 파일을 받아 덮어 설치하면 설정·키·화면 배치는 그대로 남아요.
- 개인용이라 코드 서명은 하지 않아서, 새 버전을 처음 실행할 때 경고가 떠요([01](docs/design/01-overview.md) 설치 파일과 서명).

## 저장소 구성

| 경로 | 내용 |
|---|---|
| `apps/desktop` | Electron 메인 프로세스, 창 관리, 메뉴, 패키징 |
| `apps/web` | 화면(React + Vite + dockview + Lightweight Charts) |
| `apps/server` | 내장 서버(Fastify + WebSocket): 시세 중계, 데이터 소스 어댑터, 설정·키 저장 |
| `packages/shared` | 공통 형식: 종목·시세, 신선도 정보와 배지 계산, 기능 목록, 설정 |
| `packages/command` | 커맨드 라인 해석기·완성기(한글 처리, 색인, Enter 규칙) |
| `docs/design` | 설계 문서 |

검사: `pnpm typecheck`, `pnpm test`.
