# v0.5.0-beta.1 (2026-11-08)

## 새 기능
- **앱 업데이트**: 설정 → 정보 → **업데이트**에서 새 버전을 확인하고 받아 설치해요. 켤 때와 6시간마다 자동으로 확인해서 새 버전이 있으면 알려 줘요.
  - Windows 설치형은 설치 프로그램이 열리고 앱이 닫혀요. 휴대용은 새 파일을 옆에 받아 실행해요.
  - Mac은 dmg를 열어 주면 TICKER를 끄고 응용 프로그램 폴더로 끌어 덮어써요.
  - 받은 파일은 GitHub가 알려 준 지문(SHA-256)으로 확인해요. **미리 보기 버전도 받기**와 **이 버전 건너뛰기**도 있어요.
- **패치노트 창**: 업데이트한 뒤 처음 켜면 이 창처럼 새로 생긴 것·바뀐 것을 보여 줘요. 설정 → 정보 → **패치노트 보기**로 다시 열어요.

## 바뀐 것
- 저장소 이름이 **TICKER**로 바뀌었어요. 설치 파일은 `github.com/anecdote0324/TICKER/releases`에서 받아요.

## 고친 것
- `F1` 기능 목록이 창 아래로 넘쳐 끝까지 볼 수 없던 문제. 이제 목록 안에서 스크롤되고, 창 아래쪽 패널에서는 위로 열려요.

## 알아 둘 것
- 앱 안 업데이트는 이 버전부터 돼요. 그 전 버전에서는 이번 한 번만 Releases에서 받아 덮어 설치해 주세요.
