# 패치노트

릴리스마다 사용자에게 보여 주는 변경 안내예요. 앱은 이 폴더의 파일을 화면에 넣어 두고, 업데이트한 뒤 처음 켤 때 **패치노트 창**으로 보여 줘요(설정 → 정보 → 패치노트 보기로 다시 열어요). GitHub 릴리스 설명에도 같은 내용이 들어가요.

## 파일

- `next.md`: 다음 릴리스에 들어갈 변경. 앱이 바뀌는 작업을 마칠 때마다 여기에 덧붙여요.
- `v0.5.0-beta.1.md`처럼 버전 이름의 파일: 릴리스한 버전의 패치노트. **직접 만들지 않아요.** Release 워크플로가 릴리스할 때 `next.md`를 이 이름으로 바꾸고 첫 줄에 `# v0.5.0-beta.1 (날짜)`를 붙여 커밋해요.
- 이미 릴리스한 버전의 파일은 고치지 않아요(그 버전 앱에 이미 들어갔어요). 틀린 것은 다음 `next.md`에 바로잡아요.

## 쓰는 법

사용자 눈높이로 써요. 코드 이름·커밋 이름 대신 화면에서 보이는 이름과 명령(`005930 HP`)으로 써요. 쓰는 마크다운은 `##` 제목, `-` 목록(두 칸 들여 쓰면 아래 목록), `**굵게**`, `` `코드` ``뿐이에요.

```
## 새 기능
- **HP 과거 시세 표**: `005930 HP`로 일·주·월 시세를 표로 보고 CSV로 저장해요.
```
