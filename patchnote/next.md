## 바뀐 것
- **업데이트가 보통 프로그램처럼 끝까지 자동으로 돼요.** 새 버전을 뒤에서 받아 두고, 알림의 **다시 시작해서 업데이트**를 누르면 앱이 닫히고 설치된 뒤 다시 켜져요. 설정 → 정보의 **업데이트하고 다시 시작** 단추도 같아요.
  - Windows 설치형은 설치 창 없이 설치돼요.
  - Mac은 dmg를 끌어 놓지 않아도 앱이 응용 프로그램 폴더의 TICKER를 새 버전으로 바꿔 끼워요. 업데이트 뒤 처음 켤 때 키체인 허용을 한 번 더 물을 수 있어요.
