# TICKER 사용설명서

TICKER는 블룸버그 터미널을 닮은 개인용 데스크톱 시세 터미널이에요. 이 설명서는 지금 앱(v0.1.0)에서 되는 모든 기능과 모든 명령어를 설명해요. 기능이 생기거나 바뀌면 이 설명서도 함께 고쳐요.

- 아직 만들지 않은 기능은 "v0.2에서 제공 예정"처럼 적어 두었어요. 버전별 계획은 [버전별 기능](../versions.md)에 있어요.
- `Mod`는 Windows의 **Ctrl**, Mac의 **⌘(Command)** 예요. 키를 적을 때 Windows 키를 먼저, Mac 키를 괄호 안에 적어요. 예: `Ctrl+K`(Mac `⌘K`).
- `⏎`는 Enter(Mac Return) 키예요.

## 1. 설치하고 처음 열기 (꼭 읽어 주세요)

### 1.1 설치 파일 받기

GitHub 저장소의 [Releases](https://github.com/anecdote0324/TICKER/releases)에서 받을 버전의 **Assets**를 열어 내 컴퓨터에 맞는 파일을 받아요.

| 컴퓨터 | 받을 파일 | 설명 |
|---|---|---|
| Windows (권장) | `TICKER.Setup.<버전>.exe` | 설치형. 시작 메뉴와 바탕 화면에 등록되고, 켜는 게 빨라요 |
| Windows (설치 없이) | `TICKER.<버전>.exe` | 휴대용. 설치하지 않고 바로 실행해요. 켤 때마다 임시 폴더에 압축을 풀어서 조금 느려요 |
| Mac (Apple Silicon, M1 이상) | `TICKER-<버전>-arm64.dmg` | 인텔 Mac은 지원하지 않아요. v0.3.0-beta.1부터는 Mac 설치 파일을 따로 요청한 릴리스에만 올려요(없으면 앞 버전의 dmg를 써요) |

- `Source code (zip)`, `Source code (tar.gz)`는 프로그램 코드라 실행 파일이 아니에요.
- `Latest` 표시가 붙은 것이 정식 버전이에요(지금은 `v0.1.0`). 저장소 첫 화면 오른쪽의 Releases에도 이 버전이 보여요. 정식 뒤에 나온 시험 버전에는 `Pre-release` 표시가 붙어요.
- **미리 보기(Pre-release)** 는 시험 중인 버전이고, **정식(Latest)** 은 확인을 마친 버전이에요. 둘 다 받는 방법과 설치 방법은 같아요.
- 설치형을 권하는 이유: 켜는 속도가 빠르고, 시작 메뉴에서 찾을 수 있고, 새 버전을 같은 자리에 덮어 설치할 수 있어요. 휴대용은 USB에 넣어 다니거나 잠깐 써 볼 때 좋아요. 두 방식 모두 설정·키·화면 배치는 같은 데이터 폴더(1.5)에 저장돼요.

### 1.2 Windows에서 처음 열 때

개인용이라 코드 서명을 하지 않아서, Windows가 처음 한 번 막아요. 아래처럼 허용하면 돼요.

1. 브라우저가 "일반적으로 다운로드되지 않는 파일"이라고 하면 다운로드 목록에서 `…` → **유지**(필요하면 **그래도 유지**)를 눌러요.
2. 실행할 때 파란 "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**을 눌러요.
3. 설치형은 설치가 끝나면 바로 켜져요. 다음부터는 시작 메뉴나 바탕 화면의 **TICKER**로 켜요.

주의할 것

- **새 버전**은 새 설치 파일을 받아 그대로 실행하면 덮어 설치돼요. 먼저 지울 필요가 없어요. 설정·한국투자증권 키·화면 배치는 그대로 남아요.
- **제거**: 설치 폴더의 제거 프로그램(`Uninstall TICKER.exe`)은 Windows 보안이 "이 앱의 일부가 차단되었습니다"로 막을 수 있어요. 먼저 **설정 → 앱 → 설치된 앱**에서 TICKER를 제거해 보고, 거기서도 막히면 앱을 끈 뒤 설치 폴더(`%LOCALAPPDATA%\Programs\TICKER`)와 바탕 화면·시작 메뉴의 바로 가기를 지워요. 설정과 키까지 지우려면 데이터 폴더(`%APPDATA%\TICKER`)도 지워요.
- 백신 프로그램이 서명 없는 앱이라고 경고할 수 있어요. 이 저장소의 Releases에서 받은 파일이면 허용해도 돼요.

### 1.3 Mac에서 처음 열 때

Apple 개발자 서명과 공증을 하지 않아서, macOS가 처음 한 번 막아요.

1. `.dmg`를 열고 **TICKER**를 **응용 프로그램(Applications)** 폴더로 끌어 놓아요. dmg 안에서 바로 실행하지 말아요.
2. 응용 프로그램 폴더에서 TICKER를 열면 "Apple은 'TICKER'에 … 악성 코드가 없음을 확인할 수 없습니다"(확인되지 않은 개발자) 경고가 떠요. **완료**(또는 **취소**)를 눌러 닫아요.
3. **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래쪽의 "TICKER이(가) 차단되었습니다" 옆 **그래도 열기**를 눌러요. 암호(또는 Touch ID)를 넣고, 다시 뜨는 창에서 **열기**를 눌러요.
   - macOS 15(Sequoia)부터는 Finder에서 오른쪽 클릭 → 열기로는 넘어가지 않아요. 꼭 시스템 설정에서 허용해요.
4. "'TICKER'이(가) 손상되었기 때문에 열 수 없습니다"가 뜨면, **터미널** 앱에서 아래를 실행한 뒤 다시 열어요. 인터넷에서 받은 파일에 붙는 격리 표시를 지우는 명령이에요.

   ```
   xattr -cr /Applications/TICKER.app
   ```

5. 한국투자증권 키를 처음 저장할 때 "TICKER이(가) 키체인에 있는 … 을 사용하려고 합니다" 창이 뜨면 로그인 암호를 넣고 **항상 허용**을 눌러요. 키는 Mac의 키체인으로 암호화해서 저장해요.
6. 새 버전을 설치하면(응용 프로그램 폴더에 덮어쓰기) 2~3번을 한 번 더 해야 할 수 있어요. 설정·키·화면 배치는 그대로 남아요.

주의할 것

- Mac 버전은 아직 실제 Mac에서 확인하지 못했어요. 이상한 점이 있으면 알려 주세요.
- 창을 닫으면 앱이 끝나요(Mac 앱의 관례와 달리 Dock에 남지 않아요).
- **제거**: 응용 프로그램 폴더의 TICKER를 휴지통으로 옮겨요. 설정·키까지 지우려면 `~/Library/Application Support/TICKER` 폴더도 지우고, 키체인 접근 앱에서 TICKER 항목을 지워요.

### 1.4 공통 주의사항

- **업데이트**: 앱이 켤 때와 6시간마다 새 버전을 확인해서 알려 줘요. **설정 → 정보 → 업데이트**에서 받아 설치해요([10.8](#108-업데이트)). Releases에서 직접 받아 덮어 설치해도 돼요. 앱의 버전도 **설정 → 정보**에서 봐요.
- **한국투자증권 키가 없으면** 주식·지수는 `데모` 표시가 붙은 가짜 시세로 보여요. 코인(Binance)과 환율은 키 없이도 실제 값이에요. 키 넣는 법은 [2장](#2-한국투자증권-키-넣기와-데이터-출처)에 있어요.
- **인터넷이 필요해요.** 시세는 인터넷으로 받아요. 처음 켤 때 인터넷이 없어도 앱에 들어 있는 종목 목록 사본으로 종목 검색은 돼요.
- **앱을 끄면 시세 수집도 멈춰요.** 꺼져 있던 동안의 시세는 데이터 출처가 과거 값을 주는 범위에서만 다시 채워요.
- **같은 앱을 두 번 켜면** 새로 켜지 않고 이미 켜진 창을 앞으로 가져와요.
- **나 혼자 쓰는 앱이에요.** 받은 시세를 다른 사람에게 보여 주거나 다시 배포하지 않아요(데이터 출처의 이용 조건).
- 예전 이름(Terminal)으로 설치했었다면, TICKER를 처음 켤 때 설정·키·화면 배치를 자동으로 옮겨 와요. 확인한 뒤 예전 Terminal 앱과 폴더는 지워도 돼요.

### 1.5 데이터 폴더

설정, 한국투자증권·DART 키(암호화), 화면 배치, 명령 기록, 분봉·이력(SQLite `history.db`), 뉴스 아카이브(`news.db`, v0.2), 미국 종목 인기도용 거래대금(`us-activity.json`, v0.2), 서버 기록(`logs/server.log`)이 여기에 저장돼요. 덮어 설치해도 지워지지 않아요. 서버 기록에는 앱키 끝 4자리만 남고, 앱시크릿·토큰은 남지 않아요.

| 컴퓨터 | 데이터 폴더 | 설치 폴더 |
|---|---|---|
| Windows | `%APPDATA%\TICKER` | `%LOCALAPPDATA%\Programs\TICKER` (설치형) |
| Mac | `~/Library/Application Support/TICKER` | `/Applications/TICKER.app` |

### 1.6 처음 켜면 보이는 것

처음 켜면 **Market Pulse** 화면에 7개 패널로 된 기본 배치가 열려요.

```
┌ 1 MON 관심종목 ─┬ 2 GP 가격 차트(삼성전자) ┬ 3 WEI 세계 지수 ─┐
│ 국내·미국·      │                          ├ 6 FXC 환율 매트릭스 ┤
│ 코인·환율·지수  │                          │                  │
├ 4 N 뉴스·공시 ──┼ 5 HMAP 업종 히트맵(코스피) ┼ 7 CRYP 코인 시세판 ┤
└────────────────┴──────────────────────────┴──────────────────┘
 시세 흐름 띠
 상태 표시줄
```

- 1·2번 패널은 같은 **파랑 연동 그룹**이에요. 1번 관심종목에서 종목을 누르면 2번 차트가 그 종목으로 바뀌어요.
- 두 번째 화면 탭 **Deep Dive**(v0.3)는 한 종목을 깊게 보는 배치예요: 8 GP 가격 차트, 9 DES 종목 개요, 10 GIP 장중 차트, 11 FA 재무제표, 12 N 뉴스·공시. 모두 **보라 연동 그룹**이라 한 패널에서 종목을 바꾸면 다섯 패널이 함께 바뀌고, Market Pulse(파랑)와는 따로 움직여요. 이미 저장된 배치가 있으면 생기지 않아요. 워크스페이스 메뉴의 **기본 배치로 새로 시작**을 누르면 두 화면이 모두 생겨요.
- 4번 N(전체 뉴스)과 5번 HMAP(코스피 업종)은 연동 그룹 없이 시작해요. v0.1에서 쓰던 배치(4번 두 번째 관심종목, 5번 장중 차트)를 저장해 두었다면 그대로 열려요. 새 배치를 보려면 워크스페이스 메뉴의 **기본 배치로 새로 시작**을 눌러요.
- 2번 패널의 커맨드 라인을 눌러 `AAPL US`를 치고 Enter를 눌러 보세요. 애플 차트로 바뀌어요. 커맨드 라인은 [7장](#7-커맨드-라인-쓰는-법)에서 자세히 설명해요.
- 커맨드 라인에 `?`를 치고 Enter를 누르면 명령 문법 요약이 떠요.

### 2.2 한국투자증권 키 넣기

1. 한국투자증권 홈페이지에서 Open API를 신청하고 **앱키(App Key)** 와 **앱시크릿(App Secret)** 을 받아요. 시세용으로는 **잔고가 없는 별도 계좌**의 키를 권해요. 이 앱은 매매 기능이 없지만, 키가 새어 나가도 피해가 없게 하려는 거예요.
2. 앱에서 **설정**(`Ctrl+,`, Mac `⌘,`) → **데이터 연결**로 가요.
3. 앱키와 앱시크릿을 넣고, 서버를 **실전** 또는 **모의**(모의투자 계좌의 키) 중에서 골라요.
4. **저장하고 연결 테스트**를 눌러요. 성공하면 `연결됐어요 · 삼성전자 현재가 …원`이 뜨고, 상태 표시줄에 `한국투자증권 실시간 n/40`이 보이고, 주식·지수의 `데모` 배지가 사라져요.
   - 실패하면 어느 단계에서 막혔는지(`토큰 받기`, `삼성전자 현재가 조회`)와 한국투자증권의 오류 내용(예: `EGW00103 유효하지 않은 AppKey`)을 함께 보여 줘요. 한국투자증권이 25초 동안 답하지 않아도 실패로 알려 줘요.
   - 접근 토큰은 1분에 한 번만 받을 수 있어요. 방금 받았다는 오류가 나오면 1분 뒤 **다시 테스트**를 눌러요.

알아 둘 것

- 키는 운영체제의 보안 저장소(Windows DPAPI, Mac 키체인)로 암호화해서 데이터 폴더에 저장해요. 저장한 뒤에는 화면에 다시 보여 주지 않아요. 바꿀 때만 새로 입력해요.
- **키 지우기**를 누르면 저장된 키를 지우고 데모 시세로 돌아가요.
- 받은 접근 토큰(24시간)은 저장해 두고 다시 써요. 그래서 앱을 여러 번 껐다 켜도 하루에 한 번만 받아요. 앱키를 바꾸거나 실전·모의를 바꾸면 새로 받아요.
- 한국투자증권은 토큰을 발급할 때마다 **카카오 알림톡**을 보내요. 알림톡이 하루에 여러 번 오면 진단 정보를 보내 주세요.
- 키는 채팅·메일·저장소 등 어디에도 붙여 넣지 말아요.
- 한국투자증권의 제한: **실시간 구독은 약 40개**, **조회는 초당 약 20건**까지예요. 앱은 화면에 보이는 종목부터 실시간으로 받고, 넘치는 종목은 몇 초 간격 조회로 바꿔요. 조회는 여유를 두고 초당 15건부터 보내고, 한국투자증권이 초과라고 답하면(`EGW00201`) 스스로 줄였다가 조용하면 천천히 되돌려요.
- **장이 닫힌 종목은 실시간 구독을 쓰지 않아요.** 국내 장이 끝난 밤에는 국내 주식이 5분마다 마감 값만 확인하고(`마감` 배지), 그 자리는 장이 열린 미국 주식이 써요. 국내 주식은 장 시작 전(08:30)부터, 미국 주식은 프리·애프터마켓에도 실시간으로 받아요. 장이 열리고 닫히면 30초 안에 저절로 바꿔요.
- 한국투자증권이 실시간 구독을 거절하면(`MAX SUBSCRIBE OVER`) 그 종목은 몇 초 간격 조회로 받고(`3초 주기` 같은 배지), 잠시 뒤 다시 구독해 봐요. 상태 표시줄의 한국투자증권에 마우스를 올리면 거절된 수가 보여요. 지금 쓰는 양은 설정 → 데이터 연결의 **실시간 슬롯**과 **조회 호출**, 그리고 상태 표시줄의 `한국투자증권 실시간 n/40`에서 볼 수 있어요.
- 슬롯은 국내·미국 주식의 체결만 써요. 기능을 열 때 슬롯이 모자라면 몇 초 간격 조회로 바뀐다고 알려 줘요. **기능별 실시간 슬롯** 표와 기능 설명 창(`Ctrl+/`, Mac `⌘/`)에도 슬롯 수가 보여요.

### 3.2 패널

패널 하나는 세 부분이에요.

```
┌ 2 │ 005930 KS EQUITY GP              ■ ↗ □ ✕ ┐  ← 1줄
│ GP 가격 차트 · 삼성전자 005930 KS   [배지] 도구 │  ← 2줄(제목 줄)
│ 본문 (차트·표)                                │
└──────────────────────────────────────────────┘
```

**1줄**

| 요소 | 하는 일 |
|---|---|
| 패널 번호 | 패널마다 붙는 번호(1, 2, 3 …). 끌기 손잡이이기도 해요. 끌어서 다른 자리로 옮기거나 다른 패널 위에 놓아 창 안 탭으로 묶어요. `Ctrl+숫자`(Mac `⌘숫자`)로 그 번호 패널로 가요 |
| 커맨드 라인 | 명령을 입력하는 칸. 지금 띄운 명령이 흐리게 보여요. 토큰(단어)에 마우스를 올리면 뜻(`GP = 가격 차트`, `KS = 코스피`)이 보이고, 누르면 그 토큰을 고칠 수 있게 줄에 넣어요 |
| `?` | 도움말 |
| ■ 연동 색 | 연동 그룹. 누를 때마다 파랑 → 보라 → 청록 → 없음으로 바뀌어요 ([4.4](#44-연동-그룹)) |
| ↗ | 이 패널(묶음)을 새 창으로 떼어내기 ([4.3](#43-새-창으로-떼어내기)) |
| □ | 최대화 / 원래 크기로 |
| ✕ | 패널 닫기. 되돌릴 수 없어요 |

**2줄(제목 줄)**: 기능 코드(주황), 기능 이름과 종목 이름·코드, 데이터 신선도 배지, 기능별 도구(차트의 일·주·월, 기간 버튼, 관심종목의 묶음 탭 등).

**본문**: 차트나 표. 패널 본문을 누르거나 `F6`을 누르면 본문에 주황 안쪽 테두리가 생기고, 키보드가 본문으로 가요([7.11](#711-포커스-커맨드-라인과-패널-본문)).

## 4. 화면 탭·패널·창 다루기

### 4.1 화면 탭

화면 탭 하나가 패널 배치 하나예요. 예: "Market Pulse"는 시장 전체, "Deep Dive"는 종목 하나를 깊게 보는 배치.

- **추가**: 화면 탭 끝의 `+`. 빈 화면이 생기고, 가운데의 **패널 추가**로 패널을 넣어요.
- **이름 바꾸기**: 탭을 두 번 누르거나, 오른쪽 클릭 → **이름 바꾸기**. Enter로 확정, Esc로 취소.
- **오른쪽 클릭 메뉴**: 탭을 오른쪽 클릭하면 **이름 바꾸기**, **새 창으로 떼어내기**(떼어낸 탭은 **그 창으로 가기**, **메인 창으로 돌려놓기**), **닫기**가 떠요. 메뉴 밖을 누르거나 `Esc`로 닫아요.
- **창이 좁을 때**: 탭 이름이 먼저 줄어서 아예 안 보일 수도 있어요. 그래도 탭에 마우스를 올리면 그 화면 이름이 떠요. 더 좁으면 탭의 ↗·✕ 단추도 숨기는데, 그때는 오른쪽 클릭 메뉴로 떼어내고 닫아요. 세계 시계는 그다음에야 숨겨요.
- **닫기**: 탭 오른쪽의 `✕`. 안의 패널(그 화면에서 떼어낸 창 포함)도 함께 닫혀요. 바로 뜨는 알림의 **되돌리기**로 배치까지 그대로 복구해요. 탭이 하나뿐이면 `✕`가 없어요.
- **떼어내기**: 탭 이름 오른쪽의 ↗ 버튼. [4.3](#43-새-창으로-떼어내기)을 보세요.
- **키로 옮기기**(v0.4): 입력칸 밖(패널 본문 등)에서 `Shift+→` 또는 `Shift+↑`는 오른쪽 화면 탭, `Shift+←` 또는 `Shift+↓`는 왼쪽 화면 탭으로 가요. 끝에서는 반대쪽 처음으로 돌아가요. 떼어낸 창에서 누르면 그 창의 화면 탭끼리 옮겨요. 커맨드 라인 같은 입력칸에서는 글자 선택이라 옮기지 않아요(먼저 `Esc`나 `F6`으로 본문으로 나와요). 설정 → 단축키에서 바꿀 수 있어요.

### 4.2 패널 다루기

| 하고 싶은 것 | 방법 |
|---|---|
| 패널 추가 | 맨 위 줄의 **패널 추가**. 활성 패널 오른쪽에 빈 패널이 생겨요. 빈 화면이면 가운데의 **패널 추가** |
| 기능 바꾸기 | 그 패널의 커맨드 라인에 명령을 넣고 Enter (예: `WEI⏎`, `005930 GP⏎`) |
| 옮기기 | 패널 번호 칸을 끌어서 원하는 자리(위·아래·왼쪽·오른쪽 가장자리)에 놓아요 |
| 창 안 탭으로 묶기 | 번호 칸을 끌어 다른 패널 한가운데에 놓아요. 한 자리에서 번호 탭으로 바꿔 봐요 |
| 크기 조절 | 패널 사이 경계선을 끌어요 |
| 최대화 | 1줄의 □. 다시 누르면 원래 크기 |
| 닫기 | 1줄의 ✕ (되돌릴 수 없어요) |
| 뒤로·앞으로 | `Alt+←` / `Alt+→` (Mac `⌘[` / `⌘]`). 그 패널에서 본 기능·종목을 오가요 |
| 다른 패널로 | `Ctrl+Tab` / `Ctrl+Shift+Tab`(다음·이전), `Ctrl+1…9`(Mac `⌘1…9`, 그 번호 패널) |
| 전체 화면 | `F11`(Mac `⌃⌘F`). 그 창만 ([4.6](#46-전체-화면)) |

### 4.3 새 창으로 떼어내기

두 가지 방법이 있어요. 둘 다 다른 모니터로 옮겨 쓰려는 거예요.

**패널 떼어내기** (패널 1줄의 ↗)

- 그 패널(창 안 탭으로 묶인 묶음)이 새 창이 돼요.
- 새 창의 닫기(X)를 누르면 패널이 메인 창의 원래 자리로 돌아와요. 패널을 없애려면 패널의 ✕를 눌러요.

**화면 탭 떼어내기** (화면 탭 이름 옆의 ↗)

- 그 화면이 **패널 배치째로** 새 창이 돼요. 새 창의 맨 위 줄에는 로고, 그 창의 화면 탭(옆에 메인 창으로 돌려놓기 ↙), **+**(이 창에 화면 탭 추가), **패널 추가**가 있어요.
- **떼어낸 창 안의 화면 탭**(v0.2): **+**를 누르면 그 창 안에 새 화면 탭이 생겨요. 탭을 눌러 바꾸고, 두 번 눌러 이름을 바꾸고, 탭이 둘 이상이면 ✕로 닫아요(알림에서 되돌리기). 탭 옆 ↙는 그 화면만 메인 창으로 돌려놓아요.
- 새 창 안에서도 패널을 끌어 옮기고, 크기를 바꾸고, 패널 하나를 다시 떼어낼 수 있어요.
- 메인 창의 화면 탭에는 떼어낸 화면이 흐린 기울임 글씨와 ↗ 표시로 남아요. 그 탭을 누르면 떼어낸 창을 앞으로 가져와요.
- **돌려놓기**: 떼어낸 창의 탭 옆 ↙, 메인 창 탭 옆의 ↙ 버튼, 또는 떼어낸 창의 닫기(X). 창을 닫으면 그 창의 화면이 **모두** 메인 창의 화면 탭으로 돌아와요.
- 메인 창에는 화면이 하나 이상 남아야 해요. 그래서 메인 창에 남은 마지막 화면에는 ↗와 ✕가 없어요. 화면 탭을 하나 더 만들면 떼어낼 수 있어요.
- 떼어낸 창의 위치와 크기를 기억해요. 떼어낸 채로 앱을 끄면 다음에 켤 때 같은 자리에 다시 열려요.
- 떼어낸 창에서 연 명령 팔레트(`Ctrl+K`)와 도움말은 그 창 안에 떠요. 설정 창은 메인 창에 뜨고, 메인 창을 앞으로 가져와요.

공통

- 떼어낸 창도 같은 앱 안의 창이라 시세·종목 목록·설정·연동 그룹을 메인 창과 함께 써요. 떼어낸 창의 관심종목을 누르면 메인 창의 같은 색 패널도 바뀌어요.
- **메인 창을 닫으면** 떼어낸 창까지 모두 닫히고 앱이 끝나요.
- 글자 크기 설정은 떼어낸 창에도 똑같이 걸려요.

### 4.4 연동 그룹

- 패널 1줄의 ■ 색이 연동 그룹이에요. 파랑·보라·청록 세 가지와 없음이 있어요.
- **같은 색 패널끼리는 종목이 함께 바뀌어요.** 한 패널에서 종목을 바꾸면(커맨드 라인에 종목 입력, 관심종목·세계 지수·코인 시세판의 줄 누르기) 같은 색의 다른 패널도 그 종목을 보여 줘요.
- 기능 변경은 퍼지지 않아요. 2번에서 GIP로 바꿔도 5번은 그대로예요.
- 떼어낸 창의 패널도 같은 그룹으로 이어져요.
- 상태 표시줄에 그룹마다 지금 종목이 보여요.

### 4.5 워크스페이스 저장·불러오기

**워크스페이스**는 모든 화면 탭, 그 안의 패널 배치, 떼어낸 창, 패널마다의 기능·종목·연동 색을 묶은 것이에요.

- **자동 저장**: 배치를 바꿀 때마다 저장되고, 다음 실행 때 그대로 복원돼요(설정 → 일반 → 시작할 때 마지막 배치 복원).
- 맨 위 줄 **워크스페이스 ▾** 메뉴. 커맨드 라인에 `BLP⏎`(블룸버그 런치패드)를 쳐도 이 메뉴가 열려요(v0.2).
  - **지금 배치 저장**: 이름을 넣고 저장. 같은 이름이 있으면 **덮어쓰기**로 바뀌어요.
  - 저장한 이름을 누르면 **불러오기**. 줄 오른쪽의 **덮어쓰기**(지금 배치로), **✕**(지우기).
  - **기본 배치로 새로 시작**: 처음 배치(1.6)로 돌아가요.
  - 불러오기·지우기·새로 시작은 바로 뜨는 알림의 **되돌리기**로 바로 전으로 돌아가요.
- 버튼에는 지금 불러온 워크스페이스 이름이 보여요(없으면 `저장 안 함`).

**다른 컴퓨터로 옮기기**(v0.2)

1. 지금 컴퓨터에서 **워크스페이스 ▾ → 파일로 내보내기**. `TICKER-workspaces-날짜-시각.json` 파일이 저장돼요(설치형 앱은 저장할 곳을 물어봐요).
   - 파일에 들어가는 것: 지금 배치, 저장한 워크스페이스 전부, 관심종목 묶음. 키·설정·명령 기록은 넣지 않아요.
2. 파일을 USB·메일·클라우드 등으로 다른 컴퓨터에 옮겨요.
3. 다른 컴퓨터에서 **워크스페이스 ▾ → 파일에서 가져오기**로 그 파일을 골라요.
   - 파일의 지금 배치가 `가져온 배치 11/04 15:30` 같은 이름으로 저장되고 **바로 열려요**. 파일 안의 다른 워크스페이스도 목록에 더해져요.
   - 이미 있는 이름과 겹치면 `내 배치 (가져옴)`처럼 이름을 바꿔 더해요. 그 컴퓨터의 워크스페이스는 지우지 않아요.
   - 관심종목은 없는 묶음만 더하고, 같은 묶음에는 없는 종목만 뒤에 더해요. 지우지 않아요.
   - 열기 전 배치로 돌아가려면 알림의 **되돌리기**.
   - TICKER에서 내보낸 파일이 아니면 `가져오지 못했어요: …`로 이유를 알려 줘요.
- 키(한국투자증권·DART)는 컴퓨터마다 따로 넣어요(설정 → 데이터 연결).

### 4.6 전체 화면

- **Windows: `F11`**, **Mac: `⌃⌘F`**(Control+Command+F) 또는 창 왼쪽 위의 초록 버튼으로 전체 화면을 켜요. 같은 키를 한 번 더 누르면 원래대로 돌아와요.
- 키를 누른 **그 창만** 전체 화면이 돼요. 메인 창과 떼어낸 창(패널 창·화면 창)을 모니터마다 따로 전체 화면으로 쓸 수 있어요.
- 메인 창이 전체 화면이 되면 `전체 화면이에요 · F11로 나가요` 알림이 잠깐 떠요.
- Mac에서 `F11`은 바탕 화면 보기(시스템 키)라서 `⌃⌘F`를 써요.
- 키는 설정 → 단축키의 **전체 화면**에서 바꿀 수 있어요.
- 전체 화면 상태는 다음 실행 때 복원하지 않아요. 창은 전체 화면 전의 크기와 위치로 열려요.

## 5. 데이터 신선도 배지

**배지가 없으면 실시간이에요.** 실시간이 아닌 값에는 빠짐없이 회색 배지가 붙어요. 늦은 값을 실시간으로 착각하지 않게 하려는 거라 끌 수 없어요.

| 상태 | 제목 줄·차트의 배지 | 표의 행·흐름 띠 | 언제 |
|---|---|---|---|
| 실시간 | 없음 | 없음 | 체결·시세가 오는 대로 바뀌어요 (한국투자증권 실시간, Binance) |
| 주기 조회 | `5초 주기` | `5초` | 정해진 간격으로 다시 받아요 (실시간 슬롯 밖의 종목, 해외 지수) |
| 지연 | `15분 지연` | `지연` | 출처가 늦게 줘요 |
| 일별 | `일별 10/21` | `일별` | 하루 한 번 받아요. 날짜는 출처의 기준일 (환율) |
| 장 마감 | `마감 15:30`, `마감 10/30` | `마감` | 장이 끝났어요. 값은 마지막 체결가(종가)이고, 시각은 그 장이 끝난 때예요 |
| 멈춤 | `⚠ 멈춤 14:03` | `⚠` | 받아야 할 때 새 값을 받지 못했어요. 시각은 마지막으로 받은 때. 반전 색으로 눈에 띄게 보여요 |
| 데모 | `데모` | `데모` | 실제 시세가 아닌 가짜 값 (한국투자증권 키 없음) |

- 배지에 마우스를 올리거나 누르면 출처, 기준 시각, 받는 방식 같은 자세한 내용이 보여요.
- 배지의 시각은 한국 시간이에요. 오늘이면 시각, 다른 날이면 날짜, 1년이 넘으면 연도까지 적어요.
- 한 패널의 값이 섞여 있으면(관심종목 등) 제목 줄에는 가장 늦은 상태를, 행마다 짧은 배지를 붙여요.

### 6.1 MON 관심종목

내가 고른 종목의 시세를 묶음별로 모아 봐요.

- 처음 묶음: **국내**(삼성전자, SK하이닉스 등 8개), **미국**(애플, 엔비디아 등 8개), **코인**(BTC, ETH 등 6개), **환율·지수**(원달러, 코스피, S&P 500 등 7개). 기본 배치의 1번 패널은 국내·미국, 4번 패널은 코인·환율·지수를 보여요.
- 제목 줄의 **전체 / 묶음 이름** 탭으로 묶음 하나만 볼 수 있어요. 고른 탭은 패널마다 기억해요(화면을 떼어냈다 돌려놓거나 앱을 다시 켜도 그대로).
- 열: 종목, 현재가, 등락(▲▼와 등락률), 신선도 배지, 추세(작은 선 그래프). 패널이 좁으면 추세 열부터 숨겨요.
- **줄 누르기**: 그 종목을 고르고, 같은 연동 색 패널(차트 등)이 그 종목으로 바뀌어요.
- **종목 추가**: 묶음 머리줄 오른쪽의 `+` → `종목코드·이름 (Enter로 추가, Esc 닫기)` 칸에 코드나 이름을 넣고 Enter.
- **종목 빼기**(v0.2): 줄에 마우스를 올리거나 줄을 고르면 오른쪽 끝에 **✕**가 보여요. 누르면 그 묶음에서 빠져요. 키보드로는 줄을 누른 뒤(본문 포커스) **Delete** 또는 **Backspace**(Mac `⌫`).
  - 빼면 `○○을(를) 국내에서 뺐어요 · 되돌리기` 알림이 떠요. **되돌리기**를 누르면 원래 자리로 돌아와요.
  - **전체** 탭에서는 그 줄이 있는 묶음에서만 빠져요. 같은 종목을 다른 묶음에도 넣어 두었다면 거기에는 남아요.
- **키보드로 고르기**: 본문 포커스에서 `↑` `↓`.
- 관심종목 목록은 모든 MON 패널이 함께 써요. 한 패널에서 추가하면 다른 패널의 같은 묶음에도 보여요.
- 값이 바뀌면 칸이 0.3초 동안 등락 색으로 반짝여요.

### 6.2 GP 가격 차트

- 캔들(봉) 차트, 아래쪽 거래량, 이동평균선(처음에는 **20봉 주황**, **60봉 회색**. 일봉이면 20일·60일). 제목 줄의 **지표**로 다른 보조지표를 켜고 끌 수 있어요(아래).
- 제목 줄 도구: **1시간 / 2시간 / 4시간 / 일 / 주 / 월**(봉 크기), **1M / 3M / 6M / 1Y / MAX**(보이는 기간, 일봉은 처음 3M, 시간봉은 처음 1M). 고른 봉 크기와 기간은 패널마다 기억해요(시간봉의 기간은 따로).
- **시간봉**(주식·코인): 지난 날까지 이어서 1·2·4시간 단위로 보여 주고, 가로축에 시각이 붙어요.
  - 칸은 정규장 시작에 맞춰요. 국내 1시간봉은 09·10·…·15시(15시 칸은 15:00~15:30), 2시간봉은 09·11·13·15시, 4시간봉은 09·13시예요. 미국은 뉴욕 정각부터(한국투자증권 60분봉이 정각에 와요. 4시간봉은 뉴욕 09·13·17시), 코인은 UTC 정각(한국 09·13·17·21·01·05시)부터예요.
  - 처음 열면 국내는 최근 5거래일, 미국은 약 240시간, 코인은 약 41일을 바로 보여 줘요. 그 앞(1년까지)은 앱이 뒤에서 조금씩 받아 저장하고, 차트는 1분마다 새로 받아서 지난 봉이 점점 이어져요. 한 번 받은 날은 다시 받지 않아요.
  - 국내 시간봉은 한국투자증권이 1분봉만 줘서 1분봉을 받아 묶어요. 하루치에 약 4번 조회라, 1년치를 다 채우는 데 몇 분 걸려요(화면의 시세 조회가 먼저예요).
  - 정규장 봉만 그려요. 미국 시간봉도 정규장과 겹치는 칸만(09시 칸은 09:30부터 정규장) 보여 줘요. 애프터마켓의 몇 주짜리 체결이 현재가처럼 보이지 않게 하려는 거예요.
  - 국내 15시 칸의 종가는 그날 종가(15:30 마감 동시호가)예요. 한국투자증권 분봉에는 15:20 뒤 체결이 없어서 앱이 일봉의 종가로 채워요.
  - 지수와 환율은 시간봉이 없어서 버튼이 안 보여요.
- 차트 왼쪽 위에 마우스가 가리키는 봉의 시가·고가·저가·종가와 신선도 배지.
- **움직이기**(v0.2):
  - 마우스 휠: 가로(시간) 확대·축소.
  - 차트를 끌기: 앞뒤로, 그리고 **위아래로도** 움직여요. 위아래로 움직이면 가격 축 자동 맞춤이 꺼지고 오른쪽 아래에 **자동** 단추가 생겨요.
  - **가격 눈금(오른쪽 숫자) 위에서 휠**: 세로 배율이 바뀌어요. 마우스가 가리키는 가격을 중심으로, 아래로 돌리면 넓게, 위로 돌리면 좁게 보여요. 가격 눈금을 위아래로 끌어도 세로 배율이 바뀌어요.
  - 자동 맞춤으로 돌아가기: **자동** 단추, 또는 가격 눈금 더블클릭. 종목·기간을 바꿔도 다시 자동 맞춤이에요.
- **과거 봉 더 보기**(v0.2, 일·주·월봉): 차트를 왼쪽 끝까지 끌면 더 오래된 봉을 받아 앞에 붙여요(`과거 봉 불러오는 중…`). **MAX**는 받을 수 있는 데까지 계속 받아 모두 보여 줘요. 받는 동안(`과거 봉 불러오는 중…`)과 다 받은 뒤에도 화면은 보던 자리 그대로예요. 받은 과거는 왼쪽으로 끌거나 휠로 넓혀서 봐요.
  - 받을 수 있는 과거: 국내·미국 주식과 지수는 한국투자증권이 주는 데까지(한 번에 일봉 약 400개씩), 코인은 Binance 상장일부터, 환율은 1999년(ECB 기준환율 시작)부터예요. 데모 시세는 일봉 400개까지예요.
  - 시간봉은 앱이 뒤에서 1년까지 채운 것을 보여 줘요. GIP(1분봉)는 과거를 더 받지 않아요.
- **보조지표**(v0.2): 제목 줄의 **지표**를 눌러 켜고 끄고, 패널마다 기억해요.
  - 이동평균: 5·20·60·120·200(일봉이면 일, 주봉이면 주, 시간봉이면 봉).
  - 가격 위에 겹쳐 그리기: **볼린저 밴드**(20, ±2 표준편차), **일목균형표**(전환선 파랑 9, 기준선 보라 26, 선행스팬 1 초록·2 분홍은 26봉 앞까지, 후행스팬 회색 점선은 26봉 뒤). 선행스팬 1·2 사이의 **구름**을 칠해요: 스팬 1이 위면 상승 색(기본 초록), 아래면 하락 색(기본 빨강). 등락 색 설정(한국식이면 빨강 상승)을 따라요.
  - 아래 창: **RSI**(14, 70·30 점선), **MACD**(12·26, 시그널 9, 히스토그램은 등락 색), **스토캐스틱**(슬로우 14·3·3, 80·20 점선, v0.5), **ATR**(14, v0.5), **OBV**(v0.5). 지표마다 계산법은 `TECH⏎`에서 봐요.
  - 켠 지표는 차트 왼쪽 위 시가·고가·저가·종가 옆에 색과 함께 보여요. GIP에는 보조지표가 없어요.
- **종목을 바꾸면** 지금 배율 그대로 가장 최근 봉으로 가고, 가격 축은 새 종목의 가격에 다시 맞춰요. 한 번 맞춘 배율을 종목마다 다시 맞출 필요가 없어요. 새 종목의 봉이 올 때까지는 앞 종목의 차트와 가격 축을 지우고 `불러오는 중…`을 보여 줘요.
- **같은 기간 버튼을 다시 누르면** 그 기간의 처음 보기(최근 봉이 오른쪽 끝)로 돌아가요.
- 이동평균선·볼린저 밴드·일목균형표는 가격 축을 맞출 때 빼요. 그래서 현재가에서 멀리 있으면 차트 밖으로 나갈 수 있어요(가격 눈금 위 휠로 넓혀 봐요).
- **표시 모드**(v0.5): **지표** 메뉴 맨 위의 **캔들 / 바 / 선**. 패널마다 기억하고, 처음 값은 TDEF에서 정해요. 환율처럼 종가만 있는 데이터는 늘 선이에요.
- **그리기**(v0.5, 트레이딩뷰처럼 v0.6): 제목 줄의 **그리기** → **추세선**·**박스**·**수평선**·**피보나치**를 고르고 차트를 눌러요(위에 안내가 떠요, `Esc` 취소). 그림은 종목마다 기억해서 같은 종목의 다른 GP·G에도 보여요(데이터 폴더 `state-chart.json`).
  - 그리는 법: 첫 점을 한 번 누르면 그림이 마우스를 따라 늘었다 줄었다 해요. 맞는 자리에서 다시 누르면 끝나요. 누른 채 끌다가 놓아도 돼요. 수평선은 한 번 누르면 끝이에요. 마지막 봉 오른쪽 빈 곳에도 점을 찍을 수 있어요.
  - **추세선**: 두 점 사이 선. **박스**: 두 모서리로 가격 구간을 칠해요(FVG·오더블럭), 오른쪽 끝에 위·아래 가격이 보여요. **피보나치**: 시작 0%와 끝 100%, 23.6·38.2·50·61.8·78.6% 줄.
  - 고르기·고치기: 그림 위에 마우스를 올리면 굵어지고, 누르면 손잡이(동그라미)가 생겨요. 손잡이를 끌면 그 점(박스는 네 모서리)을, 몸통을 끌면 그림 전체를 옮겨요. 빈 곳을 누르거나 `Esc`로 고르기를 풀어요.
  - 고른 그림 위쪽 막대: 색(강조·상승·하락), **오른쪽 늘리기**(추세선·박스를 화면 오른쪽 끝까지, 오더블럭에 좋아요), **🗑 지우기**. `Delete`·`Backspace`로도 지워요.
  - **그리기** 메뉴 아래 그린 그림 목록: 이름을 누르면 그 그림을 고르고(마우스를 올리면 차트에서 굵게 보여요), 🗑로 그것만 지워요. **모두 지우기**도 있어요.
- 블룸버그 별칭: `GPO`(바 차트), `GPC`(캔들 차트)를 쳐도 GP가 열려요. v0.5부터 `GPO`는 바, `GPC`는 캔들로 열어요. ⏎ 라벨에 `GPO → GP`처럼 보여 줘요.
- 예: `005930 GP⏎`, `AAPL US GP⏎`, `BTC GP⏎`, `USDKRW GP⏎`, `KOSPI GP⏎`

### 6.34 G 사용자 차트 (v0.5)

GP와 같은 차트에 지표를 골라 쓰고, 그 설정을 템플릿으로 저장해요. 예: `005930 G⏎`, `AAPL US G⏎`.

- 봉 크기·기간·표시 모드·보조지표·그리기는 GP와 같아요.
- 제목 줄의 **지표·템플릿** 메뉴의 **템플릿**: 이름을 넣고 Enter면 지금 표시 모드와 지표를 저장해요. 저장한 이름을 누르면 그 설정으로 바뀌고, ✕로 지워요. 템플릿은 모든 G에서 써요.
- 종목 뒤 `G`는 Enter 한 번에 G가 열려요. 가격 차트는 `GP`까지 쳐요. 줄 첫머리에 `G`만 치면 선택만 해요(1번 줄이 G).

### 6.35 TECH 기술적 지표 (v0.5)

`TECH⏎`: 쓸 수 있는 보조지표(이동평균 5~200, 볼린저 밴드, 일목균형표, RSI, MACD, 스토캐스틱, ATR, OBV)의 계산법과 읽는 법을 봐요. 줄의 **켜기 / 끄기**는 같은 연동 색의 G 패널(없으면 GP)에 그 지표를 켜고 꺼요. 연동 색이 없으면 처음 찾은 G·GP 패널이에요. 제목 줄에 켜는 곳(패널 번호·종목)이 보여요.

### 6.36 TDEF 차트 기본값 (v0.5)

`TDEF⏎`: 새로 여는 GP·G(그 패널에서 직접 고르지 않은 패널)의 **표시 모드**(캔들·바·선), **일·주·월봉 처음 기간**(1M~MAX), **처음 켜 둘 지표**를 정해요. **처음 값으로**는 캔들·3M·20·60선이에요. 패널에서 직접 고른 값은 그대로 둬요.

### 6.37 HP 과거 시세 표 (v0.5)

`005930 HP⏎`(별칭 `HCP`, `HCPI`): 일·주·월봉의 시가·고가·저가·종가·등락률(앞 봉 종가 대비)·거래량을 최신부터 표로 봐요. 주식·코인·환율·지수 모두 돼요.

- 위 버튼 **일 / 주 / 월**로 봉 크기를 바꿔요. 표 위에 받은 기간, 기간 등락률, 최고·최저가 보여요.
- 표 아래 **과거 더 받기**로 그 앞 기간을 이어 받아요(더 없으면 알려 줘요).
- **CSV**: 지금 표(받은 기간 전체)를 CSV 파일로 저장해요. 엑셀에서 한글이 깨지지 않게 저장하고, 파일 이름은 `HP_005930_1d_20261107.csv`처럼 영문·숫자예요. 저장 위치는 다운로드 폴더(앱이 물으면 고른 곳)예요.

### 6.38 QR 체결 테이프 (v0.5)

`005930 QR⏎`(별칭 `GIT`), `AAPL US QR⏎`: 체결을 최신부터 한 줄씩 봐요: 시각, 체결가, 등락률, 수량(미국은 누적 거래량도).

- 국내는 위 버튼으로 **KRX / NXT / 통합** 체결을 골라요(BQ와 같은 선택).
- 한국투자증권 체결 조회로 2초마다 받아서 앱이 이어 붙여요. 실시간 등록 칸(40개)을 쓰지 않아요. 화면을 연 뒤 받은 체결만 보여요(최근 500건). 한 번에 받는 체결은 30건 남짓이라, 2초 사이에 그보다 많이 체결되면 일부가 빠질 수 있어요(위에 **빈 구간** 수로 알려 줘요).
- 색은 매수·매도 **추정**이에요: 국내는 직전 체결보다 오르면 매수(상승 색)·내리면 매도(하락 색), 미국은 매도호가 이상이면 매수·매수호가 이하면 매도. 위에 추정 매수·매도 수량 합과 체결강도가 보여요.
- 받은 체결 수량 상위 5%의 큰 체결은 굵게 보여요(20건 넘게 모였을 때).
- 시각은 한국 시각이에요(미국도 한국 기준 시각).

### 6.39 AQR 체결 요약 · VAP 가격대별 거래량 (v0.5)

둘 다 틱 기록이 없어서 봉으로 계산한 **근사**예요(제목 줄에 `분봉 근사`·`일봉 근사` 표시).

- `005930 AQR⏎`: 마지막 거래 세션(밤을 넘는 미국 장도 한 세션)의 1분봉으로 **VWAP**(대표가 = (고가 + 저가 + 종가) ÷ 3), 현재가와 VWAP 차이, 시가·고가·저가, 거래량, 거래대금(근사)을 요약하고, **30분 구간**마다 거래량 막대·VWAP·고가·저가·종가를 최신부터 보여 줘요. 1분마다 다시 받아요.
- `005930 VAP⏎`: 가격대 24칸마다 거래량을 막대로 보여 줘요. 봉마다 거래량을 그 봉의 저가~고가에 고르게 나눠 더해요. 위 버튼으로 **당일**(1분봉)·**1M·3M·6M·1Y**(일봉)를 골라요. 가장 많이 거래된 가격대는 앰버, 거래량 70%가 모인 구간은 밝은 줄, 현재가가 있는 칸에는 `◀ 현재가`가 붙어요.

### 6.40 FAVE 즐겨찾기 (v0.5)

자주 여는 화면을 모아 두는 곳이에요. `FAVE⏎`.

- **넣기**: 패널 머리글(연동 색 네모 왼쪽)의 **☆**을 누르면 그 패널 화면(예: `005930 KS EQUITY GP`)이 들어가고 ★로 바뀌어요. 다시 누르면 빠져요. 종목이 필요한 기능인데 종목이 없는 패널처럼 다시 열 수 없는 화면에는 ☆이 없어요.
- FAVE 화면 위 칸에 명령을 쳐서 넣을 수도 있어요(예: `005930 HP`, `WEI`, Enter). 아래 **지금 열린 화면에서 추가**의 **+**로 다른 패널의 화면을 골라 넣어요.
- 줄을 누르면 그 화면이 **이 패널**에서 열려요. **↑ ↓**로 순서를 바꾸고 **✕**로 빼요(알림의 **되돌리기**로 되돌려요).
- 즐겨찾기는 데이터 폴더의 `state-favorites.json`에 남아요(최대 100개).

### 6.41 GRAB 화면 캡처 (v0.5)

패널 커맨드 라인에 `GRAB⏎`(또는 `캡처⏎`)을 치면 그 패널(제목 줄 포함)을 이미지로 **클립보드에 복사**해요. 메신저·메일·문서에 바로 붙여넣어요.

- 알림의 **파일로 저장**을 누르면 PNG 파일로 저장해요. 처음 위치는 사진 폴더, 파일 이름은 `GRAB_GP_005930_20261107-153001.png`처럼 영문·숫자예요.
- 찍기 전에 커맨드 라인의 후보 목록을 닫고 찍어요. 떼어낸 창의 패널도 돼요.
- 데스크톱 앱에서만 돼요. 브라우저(개발용)에서는 안내만 떠요.
- 기능 화면이 아니라 명령이라 패널의 화면은 그대로예요. 미국 종목 GRAB(그랩 홀딩스)은 `GRAB US`로 쳐요.

### 6.42 NOTE 메모 (v0.5)

종목·테마에 태그를 단 메모를 쓰고 찾아요. `NOTE⏎`(모든 메모), `005930 NOTE⏎`(그 종목 메모).

- **쓰기**: 위 칸에 쓰고 **저장**(또는 Ctrl+Enter, Mac ⌘+Enter). 태그 칸에 띄어 쓰기로 태그를 넣거나, 본문에 `#반도체`처럼 쓰면 그것도 태그가 돼요. 종목 화면에서 쓰면 그 종목이 달려요(체크를 풀면 종목 없는 메모).
- **찾기**: 검색 칸은 본문·태그에서 찾아요(띄어 쓰면 모두 들어간 메모). 태그 줄(`#태그 개수`)이나 메모의 태그를 누르면 그 태그만 봐요.
- 종목 화면에서 열면 **이 종목** 메모만, **전체** 버튼으로 모든 메모를 봐요. 메모의 종목 이름을 누르면 이 패널이 그 종목 메모로 바뀌어요.
- **고치기**·**지우기**(알림의 **되돌리기**). 메모는 데이터 폴더의 `notes.db`에만 남아요(이 컴퓨터에만, 서버로 보내지 않아요).

### 6.43 FXIP·FXCA·FRD·FIXI·WCRS 외환 (v0.6)

- `FXIP⏎` **FX 홈**: 주요 환율(원/달러·원/유로·원/엔·원/위안, 유로/달러·달러/엔 등)과 등락, 고시환율 요약(매매기준율, 없으면 ECB), 환율 뉴스(NI의 환율 주제와 같은 뉴스). 환율 줄을 누르면 이 패널이 그 환율 차트로 바뀌어요. 금·은 같은 귀금속은 원자재 데이터를 붙이는 v0.11에서 더해요.
- `FXCA⏎` **환산 계산기**: 금액과 두 통화를 고르면 지금 환율로 환산해요(⇄로 앞뒤 바꾸기). 날짜를 고르면 그날(없으면 그 앞 영업일) 일봉 종가로 환산하고, **지금 환율로**로 돌아와요. 원화 환율로 교차 계산해요(FXC와 같은 환율).
- `FRD⏎` **선물환 계산기**: 기준 통화/표시 통화(기본 USD/KRW)를 고르면 1주~1년 선물환 이론값과 포인트(선물환 − 현물)를 보여 줘요.
  - 금리평형: 선물환 = 현물 × (1 + 표시 통화 금리 × 일수/기준일수) ÷ (1 + 기준 통화 금리 × 일수/기준일수). 달러·유로·엔·위안은 실제/360, 원·파운드·호주달러는 실제/365.
  - 금리는 자동으로 SOFR(달러, FRED 키), €STR(유로, FRED 키), CD91(원, ECOS 인증키)을 써요. 다른 통화나 바꾸고 싶은 값은 금리 칸에 직접 넣어요(비우면 자동 값).
  - 결제일은 현물이 거래일 T+2, 만기는 두 나라가 모두 여는 영업일(공용 영업일 달력, 달 끝은 수정 다음 영업일)이에요.
  - 실제 시장 스왑포인트와 다를 수 있어요(신용·수급 프리미엄).
- `FIXI⏎` **공식 고시환율**: 하루 한 번 정해지는 공식 환율을 출처별로 보여 줘요. **ECB 기준환율**(키 없음, 중부 유럽 16시 무렵), **매매기준율**(한국은행 ECOS 인증키, 서울외국환중개 고시), **연준 H.10**(FRED 키, 뉴욕 정오). 앞 기준일 대비와 기준일이 함께 보여요. 키가 없는 출처는 안내만 떠요.
- `WCRS⏎` **통화 순위**: 기준 통화(**KRW**·**USD**·**EUR** 단추) 대비 각 통화의 1일·1주·1달·3달·올해·1년 수익률(+면 그 통화 강세), 한 달 변동성(연환산), 단기 금리와 캐리(그 통화 금리 − 기준 통화 금리, 금리가 있는 통화만). 칸 이름을 누르면 정렬하고, 줄을 누르면 그 환율 차트로 바뀌어요. PPP·CDS 칸은 무료 데이터가 마땅치 않아 아직 없어요.

### 6.44 BTMM·OIS·WB·CMX·FWCM·HSA·FICM·SOVM 금리 (v0.6)

모두 하루 한 번 정해지는 고시 금리예요(`일별` 배지). 장중 금리는 무료 데이터가 없어요. 커브 금리는 GC와 같은 출처이고, 키가 없는 출처는 화면 위에 `일부 없음: …` 안내가 떠요.

- `BTMM⏎` **금리 종합**: 나라 탭 **한국**(기준금리·콜·CD 91일·CP 91일·국고 1·3·5·10년·회사채 AA-·BBB- 3년, ECOS 인증키), **미국**(연방기금 목표 상단·하단·EFFR·SOFR·3개월 단기국채·국채 2·5·10·30년, FRED 키와 재무부), **유로·일본**(€STR, 유로 AAA·일본 국채). 줄마다 값, 1일·1주·1달 변화(bp), 기준일, 1년 그래프예요. `USSW⏎`는 BTMM을 미국 탭으로 열어요. 스왑 금리는 무료 데이터가 없어요.
- `OIS⏎` **무위험지표금리**: SOFR·EFFR·€STR(FRED 키)·KOFR·콜금리(ECOS 인증키) 단추로 고르면 최근 고시 이력과 1년 그래프를 보여 줘요. 아래 **복리 계산기**에 시작일·끝날을 넣으면 그 동안 매일 복리로 굴린 연율 금리를 계산해요(주말·휴일은 직전 고시 금리, 달러·유로는 실제/360, 원은 실제/365). OIS 스왑 호가는 무료 데이터가 없어요.
- `WB⏎` **세계 국채**: 한국·미국·일본·유로 AAA 국채의 2·5·10·30년 금리를 한 표로(없는 만기는 앞뒤 만기로 보간). **나라 간 스프레드** 탭(`WBX⏎`로 바로 열려요)은 10년·2년 금리 차이(행 − 열, bp)와 1달 변화예요. 영국·독일 개별 국채는 무료 출처를 확인하는 중이라 아직 없어요.
- `CMX⏎` **커브 매트릭스**: **KR / US / JP / EU** 단추로 커브를 고르면 만기별 금리와 1일·1주·1달·3달·1년 변화(bp)를 보여 줘요.
- `FWCM⏎` **선도금리 매트릭스**: 고른 커브로 '지금·1·2·3·5·7·10년 뒤'에 시작하는 '1·2·3·5·10년' 금리를 계산해요. 예: '2년 뒤 · 3년'은 2Y3Y. 고시 금리를 연복리 현물 금리로 본 근사예요.
- `HSA⏎` **커브 전략 모니터**: 나라별 2s10s(10년 − 2년), 5s30s, 2s5s10s 버터플라이(2×5년 − 2년 − 10년)와 나라 간 10년 금리 차이의 지금 값(bp), 1주·1달 변화, 최근 1년 안에서 어느 정도인지(백분위·z점수)와 그래프. 내가 만든 조합은 CIX(v0.6 뒤쪽)에서 더해요.
- `FICM⏎` **크레딧 스프레드**: 한국 회사채 AA-·BBB- 3년 − 국고 3년(ECOS 인증키), 미국 AAA·투자등급·BBB·하이일드 OAS(FRED 키)의 지금 값, 1주·1달 변화, 1년 범위와 그래프.
- `SOVM⏎`(`DEBT`도 돼요) **국채·국가부채**: 맨 위에 미국 연방 부채 총액(재무부 FiscalData, 영업일마다)과 하루 변화, 아래 표는 10개 나라의 중앙정부 부채/GDP(세계은행, 연 단위라 나라마다 몇 해 늦을 수 있어요)와 앞 해 대비, 국채 10년·2s10s예요. 키는 필요 없어요.
- 받지 못하면 마지막으로 받은 값(데이터 폴더의 `rates-cache.json`, `money-cache.json`)을 보여 줘요.

### 6.47 WEIF 지수선물 · CIX 수식 티커 (v0.6)

- `WEIF⏎` **세계 지수선물**: KOSPI200 선물(최근 두 월물)·미니 KOSPI200·코스닥150·KRX300·VKOSPI 선물의 현재가, 대비, 기초 지수, 베이시스(선물 − 지수), 한국투자증권 이론가와 괴리율, 앱이 계산한 단순 이론가(지수 × (1 + CD91 × 잔존일/365), 배당은 빼지 않아요), 거래량, 미결제약정과 증감, 잔존일. 제목에 장 구분(**주간** 08:45~15:45 · **야간** 18:00~다음 날 06:00 KRX 야간 파생시장 · **장 마감**)이 보여요.
  - 한국투자증권 키가 있어야 해요(없으면 계약 이름만 보여요). 화면이 열려 있는 동안 5초마다 조회로 받아요(실시간 등록 칸은 주식 시세에 써요).
  - 줄을 누르면 아래 **5호가**(매도·매수 잔량 막대, 3초마다)가 그 계약으로 바뀌어요.
  - 계약은 한국투자증권 지수선물옵션 종목 마스터에서 하루 한 번 골라요(데이터 폴더 `masters/`). 미국 지수선물은 CME 유료 시세라 넣지 않아요.
- `CIX⏎` **수식 티커**: 이미 받는 시세를 조합한 나만의 지수예요. 아래에 이름과 식을 넣고 **더하기**(Enter).
  - 식: 종목은 대괄호 안에 커맨드 라인처럼(`[005930]`, `[AAPL US]`, `[SPX]`, `[BTC]`, `[USDKRW]`), 숫자와 `+ - * /`, 괄호. 예: `[005930] / [000660]`, `[SPX] - [NDX] * 0.25`.
  - 칸: 지금 값, 전일(각 종목 전일 종가로 계산), 대비, %. 원래 시세와 같은 속도로 바뀌어요. 식이 틀리거나 종목을 못 찾으면 이유가 빨갛게 떠요.
  - 식 속 종목 코드를 누르면 연동 그룹의 패널이 그 종목으로 바뀌어요. **빼기**로 지워요. 이 컴퓨터에 저장돼요.

### 6.46 ECOD·ECST·ECOF·ECMX·IFMO 매크로 (v0.6)

미국 지표는 FRED API 키, 한국 지표는 BOK ECOS 인증키가 있어야 해요(ECMX는 키가 필요 없어요). 키가 없는 쪽은 `일부 없음: …` 안내가 떠요. 6시간마다 다시 받아요.

- `ECOD⏎` **지표 상세**: 지표 하나의 그래프(제목 줄 **2Y / 5Y / 10Y**)와 최근 24번의 값·전기 대비 변화. 미국(FRED) 지표는 **첫 발표** 값과 **수정**(지금 값 − 첫 발표)도 보여요(ALFRED). 처음에는 지표 목록이 뜨고, ECO·ECST·ECOF·IFMO에서 줄을 누르면 그 지표로 열려요. **목록**으로 돌아가요. 한국 지표는 ECOS가 지금 값만 줘서 수정 이력이 없어요.
- `ECST⏎` **경제 통계**: **한국 / 미국 / 내 통계** 탭. 성장·물가·고용·대외·심리·기대인플레 묶음별로 최근 값(기간), 이전, 1년 전, 5년 그래프. 값은 지표에 맞게 바꾼 것(물가·생산은 전년 대비 %, 소매판매는 전월 대비 %, 고용은 증감 등)이에요.
  - 내 통계: ECOF에서 **내 통계에**로 더한 FRED 시계열과 KOSIS 통계를 모아요. KOSIS는 KOSIS 사이트에서 통계표를 열고 OpenAPI → URL 생성으로 만든 주소를 이름과 함께 붙여 넣고 **더하기**(설정 → 데이터 연결의 KOSIS 인증키 필요). 주소 속 인증키는 지우고 저장해요. 한 표에 항목이 여럿이면 첫 항목을 보여 줘요. **빼기**로 지워요.
- `ECOF⏎` **지표 찾기**: 낱말을 넣고 Enter. 앱 지표, FRED 시계열(영문, 인기순, 키), ECOS 통계표 이름(인증키)에서 찾아요. **열기**는 ECOD, **내 통계에**는 ECST 내 통계 탭, **원문**은 FRED·ECOS 페이지예요.
- `ECMX⏎` **세계 경제 매트릭스**: 한국·미국·일본·중국·독일 등 15개 나라 × 실질 GDP 성장률·소비자물가 상승률·실업률·경상수지/GDP·정부 부채/GDP·1인당 GDP(세계은행 연간)와 정책금리(BIS, 독일·프랑스·이탈리아는 ECB). 칸 이름 옆은 가장 흔한 해이고, 다른 해 값에는 `'24`처럼 해를 붙여요. 값 색은 앞 해 대비. 칸 이름을 누르면 정렬해요.
- `IFMO⏎` **인플레이션 모니터**: **물가** 탭은 미국 CPI·근원 CPI·PCE·근원 PCE·PPI, 한국 소비자물가·근원물가 2가지·생산자물가, 유로 HICP의 전년 대비 상승률(최근 칸 색은 2%를 넘으면 상승 색), 이전·3달 전·1년 전, 2년 그래프. **기대인플레** 탭은 BEI 5·10년, 5년 뒤 5년 기대인플레, 미국 실질금리 10년(TIPS), 미시간대·한국은행 1년 기대인플레이션율과 1주·1달·1년 전. 줄을 누르면 ECOD.

### 6.45 CENB·FOMC·DOTS·WIRP·CSDR 중앙은행 (v0.6)

키 없이 돼요(WIRP의 시장 금리만 ECOS 인증키·FRED 키). 6시간마다 다시 받고, 받지 못한 출처는 화면 위 `일부 없음: …`에 이유가 뜨고 마지막으로 받은 값(데이터 폴더의 `centralbank-cache.json`)을 보여 줘요.

- `CENB⏎`(`FED`도 돼요) **중앙은행**: 미국·유로·일본·한국·영국·중국 등 15개 중앙은행의 정책금리(미국은 목표 범위), 마지막으로 바뀐 날과 폭(bp), 1년 전 대비, 3년 그래프, 다음 회의(연준·ECB·일본은행·한국은행, `D-17`처럼 남은 날). 아래 **다가오는 회의**에 네 곳의 회의를 날짜순으로 모아요. 정책금리는 BIS 자료라 나라마다 며칠 늦게 반영될 수 있어요.
- `FOMC⏎`(`FOMS`도 돼요) **FOMC 결과**: 제목 줄 **FOMC / 금통위** 단추로 바꿔요.
  - FOMC: 연준 성명·의사록·경제 전망 발표를 최신순으로. 줄을 고르면 오른쪽에 본문(최근 성명 3개, 영문 원문), **원문 열기**로 연준 페이지를 열어요. 위 줄은 올해 회의 날짜(`*`는 경제 전망·점도표를 내는 회의, 밝은 것은 앞으로의 회의).
  - 금통위: 한국은행 통화정책방향 결정문(본문)과 금통위 의사록(원문 링크), 올해 통화정책방향 결정회의 날짜.
- `DOTS⏎` **점도표**: 가장 최근 경제 전망(3·6·9·12월 FOMC)의 점도표예요. 점 하나가 위원 한 명의 연말 연방기금금리 전망(목표 범위 가운데), 흰 점선이 중간값이에요. 아래 표는 실질 GDP 성장률·실업률·PCE 물가·근원 PCE 물가·연방기금금리 전망의 중간값과 지난 전망 대비(괄호)예요.
- `WIRP⏎`(`FFIP`도 돼요) **정책금리 경로(근사)**: 시장 금리 − 정책금리(bp)로 시장이 기대하는 방향을 어림해요. 한국은 통안 91일·CD 91일·통안 1년·국고 3년 − 기준금리(ECOS 인증키), 미국은 단기국채 3개월·국채 1·2년 − 연방기금 목표 가운데(FRED 키). `≈ 25bp 몇 번` 칸은 그 차이를 25bp(한 번)로 나눈 값이고, 1주·1달 변화와 1년 그래프, 다음 회의 날짜가 함께 보여요. 기간 프리미엄·신용 차이가 섞인 근사라 확률이 아니에요. 미국 회의별 확률은 **회의별 확률(Atlanta Fed)** 단추로 Atlanta Fed 도구를 열어 봐요.
- `CSDR⏎` **국가 신용등급(근사)**: 15개 나라의 S&P·무디스·피치 장기 외화 등급, 세 곳 평균(S&P 표기), 투자·투기 등급. 무료 API가 없어 앱에 넣어 둔 값(2025-12 기준)을 써요. 바뀐 등급은 칸을 눌러 고치고 Enter(Esc는 취소), **되돌리기**로 넣어 둔 값으로 돌아가요. 고친 값은 이 컴퓨터에 저장돼요. 아래 **신용등급 뉴스**는 제목에 등급 낱말(신용등급·무디스·Fitch·downgrade 등)이 든 최근 헤드라인이에요. NI의 **신용등급** 주제와 같아요.

### 6.3 GIP 장중 차트

- **1분봉** 차트예요. 실시간 움직임을 보는 기능이라 봉 크기는 고르지 않아요. 1시간봉 같은 큰 봉과 지난 흐름은 GP에서 봐요([6.2](#62-gp-가격-차트)).
- 받은 분봉은 데이터 폴더의 `history.db`에 쌓아 두고(최근 30일) 다음에 다시 써요.
- 제목 줄 도구: `1분봉` 표시와 **1H / 4H / 1D / MAX**(보이는 기간, 처음은 4H). `1H`는 1시간봉이 아니라 '최근 1시간'이라는 뜻이에요.
- **1D**는 가장 최근 장 전체(코인처럼 24시간 열리는 시장은 최근 24시간), **MAX**는 받아 둔 분봉 전체예요. 고른 기간은 패널마다 기억해요.
- 확대·축소, 종목을 바꿀 때, 같은 버튼을 다시 누를 때의 동작은 GP와 같아요.
- **정규장 봉만** 그려요(국내 09:00~15:30, 미국 주식은 프리·애프터마켓 포함, 코인은 24시간). 장이 닫힌 뒤에는 가장 최근 장의 분봉을 보여 줘요. 아직 분봉이 없으면 `아직 장중 분봉이 없어요`가 떠요.
- 국내 주식은 15:20~15:30 마감 동시호가 동안 봉이 생기지 않아요(체결이 없어요). 장이 끝나면 15:30 봉을 그날 종가와 동시호가 거래량으로 채워요.
- 환율은 하루 한 번 발표되는 기준환율이라 분봉이 없어서 GIP를 쓸 수 없어요.
- 예: `005930 GIP⏎`, `AAPL US GIP⏎`, `BTC GIP⏎`

### 6.4 WEI 세계 지수

- 지역별(한국, 미주, 유럽, 아시아) 주요 지수: 현재, 변동, 변동률, 시간(장 상태와 신선도), 추세.
- 줄을 누르면 그 지수를 고르고, 같은 연동 색 패널이 그 지수로 바뀌어요.
- 해외 지수는 1분마다, 장이 닫힌 지수는 5분마다 확인해요. 장이 닫혔으면 시간 칸에 `마감`만 보여요.
- 값을 받지 못한 지수는 0 대신 `—`로 비워 둬요. **다우존스**는 한국투자증권이 장중 값을 주지 않아서 가장 최근 일봉의 종가를 보여 줘요(`일별` 배지).
- 장중인데 15분 넘게 값이 그대로인 지수(지금은 프랑스 CAC 40에서 봤어요)는 한국투자증권이 장중에 갱신하지 않는 것으로 보고 `일별` 배지를 붙여요.
- 들어 있는 지수: 코스피(KOSPI), 코스닥(KOSDAQ), 코스피200(KOSPI2), S&P 500(SPX), 다우존스(INDU), 나스닥 종합(CCMP), 나스닥 100(NDX), 필라델피아 반도체(SOX), FTSE 100(UKX), 독일 DAX(DAX), 프랑스 CAC 40(CAC), 유로스톡스 50(SX5E), 니케이 225(NKY), 항셍(HSI), 상하이 종합(SHCOMP), 대만 가권(TWSE).

### 6.5 FXC 환율 매트릭스

- USD, EUR, JPY, GBP, CNY, AUD, KRW 일곱 통화 사이의 환율 표예요.
- **칸 하나 = 행 통화 1단위가 열 통화로 얼마인지**예요. 예: USD 행 · JPY 열 = 1달러가 몇 엔인지.
- 한국투자증권 키가 있으면 10초마다 받아요(`10초 주기` 배지). 키가 없거나 1분 넘게 받지 못하면 ECB 기준환율로 돌아가고 `일별` 배지가 붙어요. 표 아래에 지금 출처를 적어요.
- 원화 외환시장은 다음 날 02:00까지 열려요. 기준 시각은 배지에 마우스를 올려 확인해요.
- 환율 차트(`USDKRW GP` 등)도 키가 있으면 한국투자증권 일봉이라 마지막 봉이 지금 환율과 이어져요. 원/달러·달러/엔처럼 달러가 한쪽인 환율은 캔들, 원/유로 같은 교차 환율은 선으로 그려요.
- **칸 누르기**(v0.2): 같은 연동 색 패널(차트 등)이 그 환율로 바뀌어요. 관심종목에서 종목을 누르는 것과 같아요. 누른 칸에는 테두리가 생겨요.
  - 그 방향의 환율 종목이 없으면 뒤집은 쌍으로 열어요. 예: KRW 행 · USD 열(1원당 달러) → 원/달러 `USDKRW`, JPY 행 · CNY 열 → 위안/엔 `CNYJPY`. 칸에 마우스를 올리면 어느 환율로 바뀌는지 보여요.
  - FXC 패널에 연동 색이 없으면 다른 패널이 바뀌지 않아요. 제목 줄의 ■를 눌러 차트 패널과 같은 색으로 맞춰요(처음 누를 때 알림으로 알려 줘요). 관심종목·세계 지수·코인 시세판·상위 종목·업종 화면도 같아요.
- 별칭: `WCR`을 쳐도 FXC가 열려요.

### 6.6 CRYP 코인 시세판

- 실시간이에요(배지 없음).
- 줄을 누르면 그 코인을 고르고, 같은 연동 색 패널이 그 코인으로 바뀌어요.

### 6.7 DES 종목 개요 (v0.2)

주식 한 종목의 기본 정보를 한 화면에 모아 봐요. 예: `005930 DES⏎`, `AAPL US DES⏎`. 별칭 `ISSD`도 돼요.

- **맨 위**: 이름, 코드·시장, 현재가와 등락(실시간 시세와 같아요), 업종, 52주 최저·최고(날짜)와 지금 자리를 보여 주는 막대. 관리종목·투자주의·투자경고·거래정지 같은 상태가 있으면 빨간 글씨로 붙어요.
- **가치**: 시가총액, 상장주식수, PER, PBR, EPS, BPS. 한국투자증권 키가 있어야 보이고, 패널이 열려 있는 동안 60초마다 다시 받아요. 시가총액은 지금 가격 × 상장주식수로 다시 계산해서 시세와 함께 움직여요.
- **거래**: 거래량, 거래대금. 국내 종목은 외국인 소진율과 거래량 회전율, 미국 종목은 원화 환산가.
- **실적**(국내만): 매출액, 영업이익, 영업이익률, ROE. 한국투자증권 종목 마스터의 값이라 키가 없어도 보여요. 묶음 제목에 기준 월(예: `기준 2026-06`)을 적어요.
- **회사**(국내, DART 인증키가 있을 때): 대표이사, 설립일, 홈페이지(누르면 브라우저로), 주소, 산업분류(KSIC 코드). DART 기업개황이라 하루 동안 같은 값을 써요.
- **기본 정보**: 업종(국내는 `제조 > 전기·전자`처럼 KRX 업종 대분류 > 중분류), 상장일(국내), 액면가, 결산월(국내), 통화.
- **ETF**(v0.4, 국내 ETF일 때): NAV, 괴리율, 추적 오차율, 순자산, 상장 주수, 분류, 구성 종목 수, 분배 주기와 구성 상위 5종목. 자세히는 `069500 ETF⏎`.
- 묶음 제목 오른쪽에 그 묶음의 출처를 적어요(`한국투자증권 · 60초마다`, `종목 마스터 · 2026-11-03`).
- 키가 없으면 실적·기본 정보만 보이고, 아래에 `한국투자증권 키를 넣으면 PER·PBR·52주 고저도 보여요`라고 알려 줘요.
- 주식이 아닌 종목(코인·환율·지수)에서는 쓸 수 없어요.

### 6.8 MOST 상위 종목 (v0.2)

시장 하나의 거래량·거래대금·상승률·하락률 상위 30종목을 봐요. 기능 뒤에 시장을 붙여요.

| 입력 | 시장 |
|---|---|
| `MOST⏎` | 띄운 종목의 시장(없으면 코스피). 처음 정한 뒤에는 패널이 기억해요 |
| `MOST KS⏎`, `MOST 코스피⏎` | 코스피 |
| `MOST KQ⏎`, `MOST 코스닥⏎` | 코스닥 |
| `MOST US⏎` (`UW`·`UN` 등도 돼요) | 미국: 나스닥과 뉴욕 순위를 합쳐요 |
| `MOST CRYPTO⏎` | 코인: Binance USDT 현물 |

- `EQUITY⏎`(자산군 단어 하나만)도 MOST를 열어요.
- 제목 줄 오른쪽 버튼(코스피·코스닥·미국·코인)으로 시장을, 그 아래 탭(거래량·거래대금·상승률·하락률)으로 순위 종류를 바꿔요.
- 칸: 순위, 종목, 현재가, 등락률, 거래량, 거래대금. 좁은 패널에서는 거래량 칸을 숨겨요.
- 30초마다 다시 받아요(`30초 주기` 배지). 장이 닫혔으면 마감 값이라 `마감` 배지가 붙어요.
- 줄을 누르면 같은 연동 색 패널이 그 종목으로 바뀌어요. 종목 목록에 없는 종목은 누를 수 없어요.
- 국내·미국은 한국투자증권 키가 있어야 해요. 키가 없으면 `MOST CRYPTO`(코인)만 볼 수 있어요.
- 국내 순위와 값은 KRX 기준이에요. NXT(넥스트레이드) 거래는 들어가지 않아서, 통합 시세나 다른 데이터 제공처를 쓰는 곳과 이웃한 종목의 순서가 가끔 다를 수 있어요.
- 미국 상승률·하락률은 하루 거래량 1만 주 이상, 코인 상승률·하락률은 24시간 거래대금 100만 USDT 이상만 봐요. 코인은 종류마다 수량 단위가 달라서 거래량 순위도 USDT 거래대금 순으로 매겨요.
- 종목 MOST(미국 티커)를 보려면 `MOST US EQUITY`처럼 자산군까지 붙여요. 기능 바로 뒤의 시장 단어는 MOST의 시장으로 읽어요.

### 6.9 COMP 비교 차트 (v0.2)

기준 종목과 비교 종목들의 수익률을 한 차트에 겹쳐 봐요. 기간 시작을 0%로 맞춘 선이에요.

| 입력 | 결과 |
|---|---|
| `005930 COMP⏎` | 삼성전자와 코스피(대표 지수) |
| `005930 COMP 000660 KOSPI⏎` | 삼성전자(기준)와 SK하이닉스·코스피 |
| `COMP AAPL US MSFT US SPX⏎` | 애플(기준)과 마이크로소프트·S&P 500 |
| `BTC COMP ETH SOL⏎` | 비트코인(기준)과 이더리움·솔라나 |

- 첫 종목이 기준(강조 색 굵은 선), 기능 뒤의 종목이 비교 종목이에요. 비교 종목은 5개까지예요.
- 비교 종목을 안 붙이면 대표 지수와 비교해요: 코스피 종목은 코스피, 코스닥 종목은 코스닥, 미국 종목은 S&P 500, 코인은 비트코인(비트코인이면 이더리움), 지수는 S&P 500(S&P 500이면 코스피). 환율은 대표 지수가 없어서 비교 종목을 붙여야 해요.
- 미국 비교 종목은 `AAPL US`처럼 시장을 붙여도 돼요. 그 시장은 바로 앞 비교 종목의 것이에요. 비교 종목 칸에서도 자동완성 목록이 떠요.
- 기간 버튼: 1M, 3M, 6M, YTD(올해 1월 1일부터), 1Y(기본). 한쪽 데이터가 기간보다 짧으면 모두 그 날부터 함께 0%로 맞춰요.
- 위쪽 범례에 이름, 기간 수익률, 마지막 종가가 보여요. 비교 종목 옆 ✕로 비교에서 뺄 수 있어요.
- 일봉 종가로 그리고 1분마다 다시 받아요. 국내·미국 주식은 거래일이 달라서 서로 다른 날짜에 점이 찍혀요.
- 종목만 쳐서(`000660⏎`) 기준 종목을 바꾸면 비교 종목은 그대로예요. 연동 그룹으로 종목이 바뀔 때도 같아요.

### 6.10 N 뉴스·공시 (v0.2)

국내 공시(DART)와 국내외 뉴스 헤드라인을 최신순으로 봐요. 예: `뉴스⏎`, `005930 N⏎`, `AAPL US N⏎`.

- `N`은 한 글자라 줄 첫머리에서는 선택만 해요(Enter 한 번 더). `뉴스⏎`·`공시⏎`나 종목 뒤의 `N`(`005930 N⏎`)은 바로 실행돼요.
- 탭: 전체 · 공시 · 국내 뉴스 · 해외 뉴스. 줄을 누르면 원문(기사, DART 공시 뷰어)을 브라우저로 열어요. 15분 안의 새 줄은 밝은 굵은 글씨예요.
- 칸: 시각(오늘이면 시:분, 아니면 월/일), 출처(한경 증권·서경·MarketWatch…, 공시는 파란 `DART`), 제목(공시는 `[회사명]`이 앞에).
- **종목과 함께**: 국내 주식은 그 회사의 공시와 제목에 회사 이름이 들어간 헤드라인, 미국 주식·코인은 이름(한글 이름, 영문 이름, 3글자 이상 티커)이 들어간 헤드라인만 보여요. 지수·환율은 거르지 않아요. 제목 줄 오른쪽 버튼으로 그 종목만 / 전체를 바꿔요. 연동 그룹으로 종목이 바뀌면 함께 바뀌어요.
- **공시**는 DART 인증키가 있어야 보여요(설정 → 데이터 연결, [10.5](#105-데이터-연결)). 2분마다 오늘 공시 100건을 받고, 종목을 열면 그 회사의 지난 1년 공시를 받아요(10분에 한 번).
- **뉴스**는 키 없이 RSS 7곳에서 5분마다 받아요. 연합뉴스·매일경제·WSJ는 자동 요청을 막아서 넣지 않았어요.
- 받은 헤드라인과 공시는 앱이 켜져 있는 동안 데이터 폴더의 뉴스 아카이브(`news.db`)에 계속 쌓여요(제목·링크·시각만). v0.4의 뉴스 검색이 이 아카이브를 써요.
- 맨 아래에 RSS 몇 곳을 받았는지, DART가 켜졌는지, 아카이브에 쌓인 수가 보여요.

### 6.11 HMAP 업종 히트맵 (v0.2)

지수의 업종마다 기간별 등락을 색 칸으로 봐요. 예: `HMAP⏎`(코스피), `HMAP KOSDAQ⏎`, `HMAP KOSPI2⏎`(코스피200). `KS`·`KQ`·`코스닥`·`코스피200`도 돼요.

- 칸: 업종(옆 숫자는 종목 수), 지수, 오늘, 1주, 1개월, 3개월, 올해, 추세(최근 60일 선).
- 업종은 KRX 업종이에요(코스피·코스닥은 중분류, 중분류가 없으면 대분류. 금융·IT 서비스처럼). 코스피200은 코스피200 섹터 11개(정보기술·금융·산업재 등).
- 오늘 등락은 한국투자증권 업종 지수에서 30초마다, 기간 등락은 업종 지수 일봉(하루 한 번 받아 데이터 폴더에 저장)에서 계산해요. 처음 열면 일봉을 뒤에서 받는 동안 기간 칸이 `—`로 비어 있다가 차례로 채워져요.
- 칸 색은 기간마다 다른 폭에서 가장 진해요: 오늘 ±3%, 1주 ±6%, 1개월 ±10%, 3개월 ±20%, 올해 ±30%. 색은 설정의 등락 색을 따라요.
- 업종 줄을 누르면 그 업종의 종목(시가총액 큰 순, 오늘 등락)이 보이고, 종목을 누르면 같은 연동 색 패널이 그 종목으로 바뀌어요. `← 업종`으로 돌아가요. 코스피·코스닥은 시가총액 상위 200종목 안에서만 보여요.
- 한국투자증권 키가 없으면 업종과 종목 수만 보여요.

### 6.12 IMAP 업종 타일 (v0.2)

업종별로 묶은 종목 타일(시장 지도)이에요. 예: `IMAP⏎`, `IMAP KOSDAQ⏎`, `IMAP KOSPI2⏎`, `IMAP SPX⏎`(S&P 500), `IMAP NDX⏎`(나스닥100). 위 버튼으로도 지수를 바꿔요.

- 타일 넓이는 시가총액, 색은 오늘 등락률(±3%에서 가장 진해요). 업종 띠에 업종 이름과 오늘 등락(업종 지수)이 보여요.
- 코스피·코스닥은 시가총액 상위 200종목, 코스피200은 구성 종목 전부를 그려요. 우선주·ETF·ETN은 빼요.

- 한국투자증권 키가 없으면 회색 타일(업종과 시가총액만)로 그리고 아래에 알려 줘요.

미국 지수(v0.3):

- 업종은 한국투자증권 해외 업종 분류로 묶어요. 처음 한 번은 업종 분류를 받는 데 1~2분 걸려서 그동안 "업종 확인 중" 한 묶음으로 보여요(7일 동안 데이터 폴더의 `us-industries.json`을 써요). 분류에 없는 종목은 "기타"예요.

### 6.15 GC 금리 커브 (v0.3)

미국채와 국고채, 일본 국채·유로 AAA 국채(v0.6)의 금리 커브(만기별 금리)를 겹쳐 보고, 지난 커브와 비교해요. 제목 줄의 **전체 / 미국 / 한국 / 일본 / 유로**로 바꿔요.

| 입력 | 보이는 것 |
|---|---|
| `GC⏎` | 미국채와 국고채 둘 다 |
| `GC US⏎` (`UST`·`미국`도 돼요) | 미국채만 |
| `GC KR⏎` (`KTB`·`한국`도 돼요) | 국고채만 |
| `GC JP⏎` (`JGB`·`일본`도 돼요, v0.6) | 일본 국채만 |
| `GC EU⏎` (`EUR`·`유로`·`독일`도 돼요, v0.6) | 유로 AAA 국채만 |

- 실선은 가장 최근 커브, 점선은 비교 커브예요. 제목 줄의 **1W / 1M / 1Y**로 비교할 날(1주·1개월·1년 전, 그날이 휴일이면 앞 영업일)을 골라요. 패널마다 기억해요.
- 미국채는 주황(앰버), 국고채는 하늘색, 일본 국채는 빨강, 유로 국채는 초록. 점에 마우스를 올리면 만기와 금리가 보여요. 가로축은 만기의 제곱근 간격이라 1~6개월물도 보여요.
- 아래 표: 만기별 금리와 1주·1개월·1년 변동(bp, 0.01%p). 오르면 상승 색, 내리면 하락 색이에요.
- 스프레드 표: 미국 10Y-2Y, 미국 10Y-3M, 국고 10Y-3Y, 국고 10Y - 미국 10Y(bp)와 비교 날 대비 변화.
- 출처: 미국채는 미국 재무부 일별 금리(키 없음, 1.5개월물처럼 새 만기도 저절로 보여요), 국고채는 BOK ECOS(인증키 필요, 1·2·3·5·10·20·30·50년), 일본 국채는 일본 재무성 CSV(키 없음, 1~40년), 유로 국채는 ECB 수익률 곡선(유로 지역 AAA 국채로 추정한 현물 금리, 키 없음, 3개월~30년). 하루 한 번 정해지는 값이라 `일별` 배지가 붙어요.
- ECOS 인증키가 없으면 미국채만 보이고 `국고채: BOK ECOS 인증키를 넣으면…` 안내가 떠요(설정 → 데이터 연결).
- 받지 못하면 마지막으로 받은 값(데이터 폴더의 `rates-cache.json`)을 보여 줘요.

### 6.21 ALRT 알림 (v0.3)

가격·등락률 조건을 만들어 두면 맞을 때 알려 줘요. 예: `ALRT⏎`, `005930 ALRT⏎`(그 종목으로 시작), `알림⏎`.

- 위 줄에서 만들어요: 종목(코드·이름 + Enter, 또는 패널의 종목), 조건(**가격 이상 / 가격 이하 / 등락률 이상(%) / 등락률 이하(%)**), 값, **반복**(체크 안 하면 한 번만) → **알림 만들기**.
- 조건이 맞으면 오른쪽 아래에 `🔔 삼성전자 72,000 · 가격 이상 70,000` 알림이 10초 동안 떠요. 설정에 따라 운영체제 알림과 소리도 내요([10.6](#106-알림)).
  - 이미 조건이 맞아 있으면 만들자마자 한 번 알려요.
  - 한 번만: 알린 뒤 꺼지고 상태에 `알림 11/04 10:01`이 남아요. 반복: 조건이 풀렸다가 다시 맞을 때마다 알려요.
- 표: 종목, 조건, 지금 값, 남은 거리(가격은 %, 등락률은 %p), 방식, 상태, **끄기/켜기**, ✕(지우기). 줄을 누르면 연동 그룹이 그 종목으로 바뀌어요.
- **최근 알림**: 알림 기록 100개(✕로 지우기). 줄을 누르면 그 종목으로.
- 이 패널을 닫아도 알림은 동작해요(앱이 켜져 있는 동안). 데모 시세로는 알리지 않아요. 알림 목록은 데이터 폴더의 `state-alerts.json`에 저장돼요.
- **뉴스 탭**(v0.4): 위 **뉴스** 버튼을 누르고 낱말을 넣어 **뉴스 알림 만들기**. 만든 뒤 들어오는 헤드라인·공시 제목에 그 낱말이 모두 들어가면 알려요(띄어 쓰면 모두 든 것, `-낱말`은 빼기, NSE와 같은 검색). 2분마다 확인하고, 새 줄이 들어올 때마다 알려요(여러 줄이면 묶어서). 알림 방식은 가격 알림과 같아요.
- **지표 탭**(v0.4): 위 **지표** 버튼을 누르고 ECO의 발표 이름(CPI·고용보고서 등)과 미리 알림(없음·15분 전·1시간 전)을 골라 **지표 알림 만들기**. 발표 전(고른 만큼)과 발표 뒤에 그때 받은 최근 값·이전 값을 알려요. 발표마다 반복하고, 앱을 6시간 넘게 꺼 뒀던 발표는 알리지 않아요. 발표 뒤 값은 ECO가 받은 값이라 원천이 값을 올리기 전이면 지난 값일 수 있어요.

### 6.20 PORT 포트폴리오 (v0.3)

내가 가진 종목을 넣어 두고 원화로 평가·손익을 봐요. 예: `PORT⏎`, `포트폴리오⏎`, `BBU⏎`(블룸버그 업로드 = 가져오기).

- 위 줄: 평가금액, 매입금액, 손익(원·%), 오늘 손익, 지금 원/달러.
- 표: 종목(계좌), 수량, 평균단가(미국 종목은 달러, `@1300`은 매입 환율), 현재가, 평가금액(원), 손익(원), 수익률, 오늘(원), 비중. 줄을 누르면 같은 연동 색 패널이 그 종목으로 바뀌어요.
- **종목 추가**: 종목코드·이름을 치고 Enter(또는 줄 누르기)로 고른 뒤 수량·평균단가를 넣고 **추가**. 미국 종목·코인은 **매입 환율**(원/달러)도 넣을 수 있어요. 계좌 이름은 선택이에요.
- **고치기**: 수량·평균단가 숫자를 누르면 고칠 수 있어요(Enter 저장, Esc 그만). ✕로 빼고, 알림의 **되돌리기**로 돌아와요.
- **CSV 가져오기**(신한 등 잔고 파일): 머리줄에서 종목코드(종목번호)·수량(잔고수량)·평균단가(매입단가)·계좌 열을 찾아 읽어요. `A005930` 같은 앞 글자는 떼고, EUC-KR 파일도 읽어요. 같은 종목·같은 계좌는 파일 값으로 바꾸고, 다른 종목은 그대로 둬요. 찾지 못한 코드는 알림에 보여요(되돌리기 있음).
- 원화 환산: 미국 종목·코인(USDT)은 지금 원/달러로 평가해요. 매입금액은 매입 환율을 넣었으면 그 환율, 없으면 지금 환율이라 환율 손익이 0이에요. 시세가 없는 종목은 합계에서 빠져요.
- 보유 목록은 데이터 폴더의 `state-portfolio.json`에 저장돼요(워크스페이스 파일로 내보내기에는 들어가지 않아요). 매매·잔고 자동 연동은 하지 않아요.

### 6.19 ECO 경제 캘린더 (v0.3)

지난 2주와 앞으로 30일의 미국·한국(v0.6) 경제지표 발표 일정을 한국 시간으로 보고, 한국 주요 지표의 최근 값도 봐요. 예: `ECO⏎`, `WECO⏎`, `경제지표⏎`. 제목 줄의 **전체 / 미국 / 한국**으로 걸러요(v0.6).

- 칸: 날짜(요일), 시각(한국 시간), 나라, 지표, 최근 값(기간), 이전 값, 예상(v0.6), 출처. 지난 발표는 흐리게, 오늘은 옅은 바탕, 지금 시각에 앰버 선이 있어요.
- 시각: **BEA**(GDP·개인소득·지출·무역수지 등)는 원천이 준 시각이에요. **FRED**(CPI·고용보고서·PPI·소매판매·산업생산·JOLTS·실업수당 청구·주택 착공·FOMC·미시간대 소비자심리 등)는 날짜만 줘서 관례 시각(뉴욕 08:30 등)을 붙이고 `*`를 달아요. 서머타임은 날짜마다 맞춰요.
- 최근 값·이전 값: FRED 시계열의 가장 최근 두 값이에요(CPI·PCE·PPI는 전년 대비 %, 소매판매·산업생산은 전월 대비 %, 고용은 전월 대비 증감). 발표 전 줄의 최근 값은 지난 발표 값이에요.
- **예상**(v0.6): 칸의 `＋`를 눌러 예상 값을 적고 Enter(Esc는 취소, 비우면 지워요). 이 컴퓨터에 저장돼요. 무료 컨센서스 자료는 없어요.
- **한국 발표 일정**(v0.6): 국가데이터처 보도계획(소비자물가동향·고용동향·산업활동동향 등, 발표 시각까지)과 한국은행 통계공표일정(국제수지·생산자물가·소비자동향조사 등, 날짜만이라 주요 통계는 관례 시각에 `*`, 나머지는 `시각 미상`). 행사·포상 같은 보도는 빼요. 소비자물가·고용·산업활동·생산자물가·국제수지·GDP·소비자동향은 ECOS 인증키가 있으면 최근 값도 보여요. 출처 칸은 `데이터처`·`한은`.
- 지표 이름에 점선이 있으면 눌러서 그 지표의 상세(ECOD)로 바꿔요(v0.6).
- 오른쪽(좁으면 아래) **한국 주요 지표**: BOK ECOS 100대 통계지표에서 기준금리·경제성장률·소비자물가·실업률·경상수지·수출입·산업생산 등의 최근 값과 기간.
- 키: BEA 일정은 키가 필요 없어요. FRED 발표일·값은 FRED API 키, 한국 지표는 BOK ECOS 인증키가 있어야 해요(설정 → 데이터 연결). 없으면 위에 안내가 떠요.
- 3시간마다 다시 받아요. BLS(미국 노동통계국) 공표일정은 자동 요청을 막아서 쓰지 않아요.

### 6.18 FA 재무제표 (v0.3)

주식의 손익계산서·재무상태표·현금흐름표와 비율을 기간별 표로 봐요. 예: `005930 FA⏎`, `AAPL US FA⏎`, `삼성전자 재무⏎`.

- 제목 줄의 **연간**(최근 6년) / **분기**(최근 8분기). 가장 최근 기간이 오른쪽이에요. 패널마다 기억해요.
- 줄: 손익(매출액, 매출원가, 매출총이익, 영업이익, 법인세차감전순이익, 당기순이익, 지배주주 순이익), 재무상태(자산총계, 유동자산, 현금, 부채총계, 유동부채, 자본총계, 지배주주 지분), 현금흐름(영업·투자·재무활동, CAPEX), 비율(매출 성장률, 매출총이익률, 영업이익률, 순이익률, ROE, ROA, 부채비율, 유동비율, 잉여현금흐름). 값이 없는 줄은 빼요. 음수는 하락 색이에요.
- **국내**: DART 단일회사 전체 재무제표(DART 인증키가 있어야 해요). 연결재무제표가 있으면 연결, 없으면 별도. 단위는 억 원.
  - 분기 값: 1분기·반기·3분기·사업보고서의 누적 값에서 앞 누적을 빼서 만들어요(4분기 = 연간 − 3분기 누적). 재무상태는 그 시점 값.
- **미국**: SEC EDGAR(US GAAP, 설정에 연락처가 있어야 해요). 단위는 백만 달러. 기간 머리줄은 회계연도 끝 달(예: 애플 `2026.09`)이에요.
  - 쓰는 인터넷 연결에 따라 SEC가 프로그램 요청을 막아서(`HTTP 403: … Undeclared Automated Tool`) 미국 재무제표가 안 보일 수 있어요. 브라우저로는 열려도 그래요. 다른 방법은 마지막 단계(후순위)에서 붙일 예정이에요.
  - 분기 값: 10-Q의 3개월 값. 현금흐름처럼 누적만 있는 계정은 누적끼리 빼고, 4분기는 연간 − 앞 세 분기.
- 분기의 ROE·ROA는 그 분기 이익 그대로예요(연환산하지 않아요). 성장률은 연간은 전년, 분기는 전년 같은 분기와 비교해요.
- 받은 값은 12시간 동안 다시 써요. ETF·리츠처럼 재무제표가 없는 종목은 안내가 떠요.

### 6.16 GRID 소형 차트 격자 (v0.3)

여러 지수·환율·코인·종목의 작은 차트를 격자로 한눈에 봐요. 예: `GRID⏎`, `격자⏎`.

- 처음 칸: 코스피, 코스닥, S&P 500, 나스닥 종합, 니케이 225, 항셍, 원/달러, 달러/엔, 비트코인.
- 칸마다: 이름·코드, 현재가, 오늘 등락률, 보이는 기간의 등락률(흐린 글씨), 일봉 종가 선(기간 동안 오르면 상승 색, 내리면 하락 색).
- 제목 줄의 **1M / 3M / 6M / 1Y**로 기간을 골라요. **편집**을 누르면 위에 입력칸이 생겨 종목을 더하고(코드·이름 + Enter), 칸마다 ✕로 빼요. **처음 칸으로**는 처음 9칸으로 돌아가요. 칸 목록과 기간은 패널마다 기억해요.
- 칸을 누르면 같은 연동 색 패널(차트 등)이 그 종목으로 바뀌어요.

### 6.17 MAP 세계지도 (v0.3)

나라별 대표 지수의 오늘 등락을 지도 위치에 놓은 칸으로 봐요(지형 그림 대신 대략의 자리에 놓은 칸). 예: `MAP⏎`, `WM⏎`, `지도⏎`.

- 미주(S&P 500·나스닥·다우), 유럽(영국·독일·프랑스·유로존), 아시아(중국·한국 코스피·코스닥·일본·홍콩·대만).
- 칸 색은 오늘 등락률이에요(±2%에서 가장 진해요). 칸 안에 지수 이름, 등락률, 현재가, 장 상태(장중·마감·개장전)와 원화 대비 통화 등락(달러·파운드·유로·위안·엔)을 보여 줘요.
- 칸을 누르면 같은 연동 색 패널이 그 지수로 바뀌어요. 지수 시세의 출처와 지연 여부는 WEI와 같아요.

### 6.22 KINV·KPGM·KCRD·SI 수급 (v0.4)

국내 주식의 날마다 수급을 표와 작은 그림으로 봐요. 예: `005930 KINV⏎`, `005930 KPGM⏎`, `005930 KCRD⏎`, `005930 SI⏎`. KINV·KPGM·KCRD는 블룸버그 코드가 아닌 이 앱의 자체 코드예요.

- **KINV 투자자별 매매동향**: 외국인·기관(기관계 합)·개인의 순매수 금액과 수량. 위 그림은 표 기간(약 30일)의 누적 순매수 선이에요.
- **KPGM 프로그램 매매**: 프로그램 매수·매도·순매수와 그날 거래대금 대비 순매수 비중.
- **KCRD 신용·대차 잔고**: 위 버튼으로 **신용**(융자 잔고 주·금액·잔고율, 신규·상환, 대주 잔고)과 **대차**(대차거래 잔고·금액·증감·체결·상환)를 바꿔요. 신용 잔고는 결제일 기준이라 하루 늦어요.
- **SI 공매도**: 위 버튼으로 **거래**(공매도 체결 수량·금액, 거래량·거래대금 대비 비중, 평균가)와 **잔고(대차 근사)**를 바꿔요. 국내 공매도 잔고는 공개 조회가 없어서 공매도의 재료인 대차거래 잔고로 대신 보여 줘요. 미국 주식(`AAPL US SI⏎`)은 FINRA 공매도 잔고(15일·월말 결제일, 약 2주 뒤 공개)와 변화율·평균 거래량·상환 일수를 보여 줘요(키 필요 없음).
- 표는 최근 날짜가 위예요. 금액은 억 원(평균가는 원), 순매수처럼 +·−가 뜻이 있는 칸은 등락 색이에요. 그림은 KINV는 누적 선, 나머지는 날마다 막대와 종가 선(앰버).
- 한국투자증권에서 5분마다 받아요(장중에는 오늘 줄이 바뀌어요). 키가 없으면 안내가 떠요. 미국 주식·코인 등은 볼 수 없어요.

### 6.23 KWRN 시장경보·VI (v0.4)

종목의 경보와 오늘 VI(변동성완화장치) 발동 목록을 봐요. 예: `KWRN⏎`(목록만), `005930 KWRN⏎`, 별칭 `KVI`.

- 위 **종목 경보**: 투자주의·투자경고·투자위험, 관리종목, 거래정지, 단기과열, 정리매매, 투자유의 중 해당하는 것. 없으면 "없음". 그 종목이 지금 VI 발동 중이면 앰버 표시가 붙어요.
- 아래 **오늘 VI 발동**: 시각, 종목, 종류(정적·동적), 발동가, 괴리율, 해제 시각(아직이면 "발동 중"), 횟수. 최근 발동이 위예요. 줄을 누르면 같은 연동 색 패널이 그 종목으로 바뀌어요.
- 30초마다 새로 고쳐요. 출처는 한국투자증권 VI 현황과 주식현재가 시세(DES와 같은 경보)예요.

### 6.24 EE·ANR 실적 추정치와 투자의견 (v0.4)

- **EE**(`005930 EE⏎`, 별칭 `EEO`): 한국투자증권이 주는 추정 손익(매출액·영업이익·순이익과 증감률)과 투자 지표(EBITDA·EPS·PER·EV/EBITDA·ROE·부채비율·이자보상배율)를 결산년월별로 봐요. 화면에는 "KIS 제공 추정"이라고 적어요(증권사 컨센서스가 아니에요). 금액은 억 원, 증감률·ROE·부채비율은 %.
- **ANR**(`005930 ANR⏎`): 최근 1년 증권사 투자의견, 직전 의견, 목표가, 전일 종가, 괴리율. 위 요약은 최근 3개월 증권사별 마지막 의견의 매수·중립·매도 수와 평균·최고·최저 목표가예요.
- 국내 주식만, 6시간마다 새로 받아요. 미국 종목의 추정치·투자의견은 유료 소스라 넣지 않아요.

### 6.25 DVD·CACS·EVTS·IPO 배당과 기업 일정 (v0.4)

모두 한국투자증권 예탁원 정보예요.

- **DVD**(`005930 DVD⏎`, `AAPL US DVD⏎`): 국내는 지난 10년 배당 기준일·종류·주당 현금배당·현금배당률(액면 대비)·주식배당률·지급일(예탁원 정보). 미국은 지난 5년 배당·특별배당의 현지 기준일과 주당 배당(달러, 한국투자증권 해외주식 기간별권리). 위에 최근 1년 주당 배당 합과 지금 가격 기준 배당수익률.
- **CACS 기업행위**(`CACS⏎`, `005930 CACS⏎`, 별칭 `CACT`): 유상증자·무상증자·감자·합병·분할·액면 변경·의무보유(보호예수).
- **EVTS 이벤트 캘린더**(`EVTS⏎`, `005930 EVTS⏎`): 주주총회, 공모 청약·신규 상장, 배당 기준일, 유상·무상증자, 의무보유. DART 인증키가 있으면 IR(기업설명회) 개최 공시와 잠정실적 발표도 더해요(날짜는 공시일, IR 개최일은 원문에 있어요). 이 줄을 누르면 DART 원문이 열려요.
- CACS·EVTS는 종목과 함께 치면 그 종목의 지난 2년~앞으로 1년, 종목 없이 치면 시장 전체의 지난 7일~앞으로 30일이에요. 지난 일정은 흐리게, 오늘은 옅은 바탕이에요. 시장 전체 목록의 줄을 누르면 같은 연동 색 패널이 그 종목으로 바뀌어요.
- **IPO**(`IPO⏎`, 별칭 `ECDR`): 지난 60일~앞으로 60일 공모주 청약 기간·공모가·상장일·주간사, 상장한 종목은 지금 가격과 공모가 대비 수익률.

### 6.26 MGMT·RELS·HDS·OWN 경영진·관계사·보유자 (v0.4)

모두 DART(인증키 필요)이고 국내 주식만이에요. 12시간마다 새로 받아요.

- **MGMT**(`005930 MGMT⏎`): 가장 최근 정기보고서의 임원(직위·등기·상근·담당·재직 기간·최대주주와의 관계, 마우스를 올리면 주요 경력)과 임원 보수(전체 인원·총액·1인 평균, 5억 원 이상 개인별).
- **RELS**(`005930 RELS⏎`, 별칭 `CAST`): 타법인 출자 현황(법인·지분율·장부가·보유 주식·목적·최초 취득일·피출자회사 총자산·순이익). 장부가 큰 순이고 금액은 억 원.
- **HDS**(`005930 HDS⏎`): 위 버튼으로 **최대주주**(특수관계인 포함 기말·기초 지분), **5% 보유**(대량보유 보고), **임원·주요주주**(소유 보고)를 바꿔요. 보고 줄을 누르면 DART 원문이 브라우저로 열려요. 미국 13F는 후순위예요.
- **OWN**(`005930 OWN⏎`): 1년 종가 선 위에 임원·주요주주가 보유를 늘린 보고(▲)와 줄인 보고(▼)를 표시해요(마우스를 올리면 보고자·수량). 아래는 보고 목록. 날짜는 보고일이라 실제 매매일과 다를 수 있어요.
- 정기보고서 정보는 올해 3분기 → 반기 → 1분기 → 지난해 사업보고서 순서로 가장 최근 것을 찾고, 화면 위에 어느 보고서인지 적어요.

### 6.27 ERN·EM 실적 이력과 추세 (v0.4)

- **ERN**(`005930 ERN⏎`): 최근 3년 잠정실적 공시(공정공시)마다 그 분기의 매출·영업이익·순이익(억 원)과 전년 같은 분기 대비, 발표일 종가의 전일 대비 반응(당일·이틀)이에요. 장 마감 뒤나 주말 공시는 다음 거래일 종가로 봐요. 같은 분기의 정정 공시는 "정정"으로 표시해요. 줄을 누르면 원문. 분기 값은 FA와 같은 DART 재무제표라 정기보고서가 나온 분기만 있어요. 서프라이즈(추정치 대비)는 넣지 않았어요.
- **EM**(`005930 EM⏎`, `AAPL US EM⏎`): 최근 8분기 매출·영업이익·순이익 막대와 표, 영업이익률. FA 분기 값과 같아요.

### 6.28 CF 공시 검색 (v0.4)

DART 공시를 찾아봐요. 예: `CF⏎`(전체 최근 7일), `005930 CF⏎`(그 회사 최근 1년).

- 위 버튼으로 종류(전체·정기·주요사항·발행·지분·기타·거래소·감사·공정위), 검색칸으로 제목·회사 이름을 걸러요.
- 제목을 누르면 DART 원문이 브라우저로 열려요. 전체 목록에서 회사 이름을 누르면 같은 연동 색 패널이 그 회사로 바뀌어요.
- 5분마다 새로 받아요. 미국 공시(SEC)는 후순위예요.

### 6.29 CN·TOP·NI·NSE·FIRS 뉴스 보기 (v0.4)

모두 N과 같은 뉴스 아카이브(RSS 5분·DART 2분마다 받아 쌓은 것)에서 골라요. 줄을 누르면 원문이 브라우저로 열려요.

- **CN 종목 뉴스**(`005930 CN⏎`): N과 같은 화면이지만 늘 그 종목만(제목에 종목 이름이 든 헤드라인과 그 회사 공시). 네이버 뉴스 검색은 쓰지 않아요.
- **TOP 주요 뉴스**(`TOP⏎`): 최근 6·24·72시간 헤드라인을 비슷한 제목끼리 한 줄로 묶고, 출처 가중치·여러 곳이 같이 다룬 정도·최근 정도로 점수를 매겨 위에서부터 보여 줘요. 줄 끝의 `+2 (서경, 전자신문)`은 같은 이야기를 다룬 다른 줄이에요. `TOP BON⏎`(또는 제목 줄 **채권**)은 금리·국채·회사채·신용 낱말이 든 헤드라인만으로 골라요(v0.6). 뉴스·공시도 `N BON⏎`이면 채권 헤드라인만 보여요(`N`은 한 글자라 Enter 두 번).
- **NI 주제별 뉴스**(`NI⏎`): 실적, 금리·채권, 환율, 반도체, 2차전지, 바이오, 원자재, 코인, 부동산, M&A, 정책·관세, 공모·상장, 신용등급(v0.6) 버튼으로 주제를 골라요(제목에 주제 낱말이 든 최근 헤드라인). `STNI⏎`은 금리·채권 주제로 열어요(v0.6).
- **NSE 뉴스 검색**(`NSE⏎`): 검색칸에 낱말을 넣고 Enter. 띄어 쓰면 모두 든 것, `-낱말`은 빼기(예: `삼성 HBM -중국`). 7일·30일·1년, **저장**으로 검색어를 칩으로 남겨 두고 눌러 다시 찾아요(패널마다 기억). 앱이 켜져 있는 동안 쌓인 것만 있어요.
- **FIRS 속보**(`FIRS⏎`, 근사): 블룸버그 First Word 대신, 최근 12시간 제목에 속보·1보·단독·Breaking이 든 헤드라인, MarketWatch Pulse 2시간, 주요 DART 공시(증자·자기주식·합병·공급계약 등). 1분마다.

### 6.30 MEMB·MOV 지수 구성종목과 기여도 (v0.4)

- **MEMB**(`MEMB⏎`, `MEMB KOSDAQ150⏎`, `MEMB SPX⏎`, `MEMB NDX⏎`): 지수의 구성종목과 비중, 현재가, 등락률. 위 버튼으로 코스피200·코스닥150·S&P 500·나스닥100을 바꿔요.
- 지수 회사의 구성종목 목록은 유료라, 그 지수를 따르는 ETF의 구성으로 대신해요(근사): 코스피200은 KODEX 200(069500), 코스닥150은 KODEX 코스닥150(229200)(한국투자증권 ETF 구성종목시세), S&P 500·나스닥100은 IMAP과 같은 SPY·QQQ 보유 종목 파일. 화면에 어느 ETF인지 적어요.
- **MOV**(`MOV⏎`, 별칭 `IMOV`): 같은 구성으로 **기여도**(비중 × 등락률 ÷ 100, %p), **상승 상위**, **하락 상위**. 위에 상승·하락 종목 수와 기여도 합. 지수 산식과 달라서 합이 지수 등락과 조금 달라요.
- 1분마다 새로 받아요. 줄을 누르면 같은 연동 색 패널이 그 종목으로 바뀌어요.

### 6.31 ETF·FFLO ETF 분석과 자금 흐름 (v0.4)

국내 ETF를 봐요. 예: `069500 ETF⏎`, `069500 FFLO⏎`.

- 위 줄: 현재가·등락률, NAV, 괴리율, 추적오차율, 순자산, 상장 주수, 분류·구성 종목 수·분배 주기.
- 버튼으로 **NAV**(최근 30거래일 종가·NAV·괴리율), **구성종목**(비중 큰 순, 누르면 연동), **자금 흐름**을 바꿔요. FFLO는 자금 흐름 탭으로 열려요.
- 자금 흐름은 날마다 상장 주수 변화 × NAV예요. 설정 → 데이터 연결에 **KRX Open API** 인증키가 있으면 KRX ETF 일별매매정보로 최근 거래일(약 30일)을 바로 보여 줘요(지난 날은 데이터 폴더 `krx-etf.json`에 두고 다시 받지 않아요). 키가 없으면 앱이 그 ETF 화면을 연 날마다 데이터 폴더(`etf-shares.json`)에 기록한 상장 주수로 이틀째부터 보여요. 화면 아래에 어느 쪽인지 적어요.
- 한국투자증권에서 1분마다 받아요.

### 6.32 WATC 관심종목 분석 (v0.4)

`WATC⏎`: MON의 모든 묶음 종목을 한 표로 봐요. 현재가, 오늘·1주·1개월·3개월 등락(일봉 종가 기준), 최근 24시간 뉴스·공시 수(제목에 이름이 든 헤드라인과 그 회사 공시). 줄을 누르면 연동돼요(CN·EVTS로 더 자세히 봐요).

### 6.33 BQ 10호가 (v0.4)

`005930 BQ⏎`: 국내 종목의 호가창이에요.

- **10호가**: 위 버튼으로 **KRX**·**NXT**(넥스트레이드)·**통합**을 바꿔요. 매도호가는 위(하락 색), 매수호가는 아래(상승 색), 잔량 막대, 총 잔량과 호가 시각, 동시호가 때는 예상 체결가.
- 호가는 한국투자증권 조회로 2초마다 받아요. 실시간 등록 칸(40개)을 쓰지 않아서 다른 화면의 실시간 시세에 영향이 없어요. 미국 종목은 무료로 1호가만 있어서 호가판이 없어요.

### 6.14 아직 없는 기능

- 아직 만들지 않은 기능(`WB` 세계 국채 등 v0.6 이후)은 없어요. 아직 없는 기능을 치면 `⏎ 실행 안 됨: … v0.6에서 제공 예정`처럼 알려 주고 실행하지 않아요.
- 전체 계획은 [버전별 기능](../versions.md)과 [03 기능 코드](../design/03-functions.md)에 있어요.
- 매매(주문) 기능은 넣지 않아요.

## 7. 커맨드 라인 쓰는 법

### 7.1 가장 중요한 두 가지

- **Tab은 채우고, Enter는 실행해요.**
- **입력이 여러 뜻일 수 있으면, 첫 Enter는 1번 줄을 선택만 하고 두 번째 Enter가 실행해요.** 커맨드 라인 오른쪽의 **⏎ 라벨**이 Enter가 할 일을 늘 미리 알려 줘요.

예

| 입력 | 결과 |
|---|---|
| `005930⏎` | 삼성전자. 코드가 정확해서 Enter 한 번에 실행 |
| `삼성⏎⏎` | 이름 일부라 첫 Enter는 1번 줄(삼성전자) 선택, 두 번째 Enter로 실행 |
| `ㅅㅅㅈㅈ` | 초성으로 삼성전자 찾기 |
| `AAPL US GIP⏎` | 애플 장중 차트 |
| `BTC⏎` | 비트코인(BTC/USDT) |
| `WEI⏎` | 세계 지수 |
| `USDKRW⏎` | 원달러 환율 |

### 7.2 명령의 칸

표준 순서는 `종목 시장 자산군 기능 ⏎`예요. 블룸버그의 `IBM US <Equity> GP <GO>`와 같은 모양이에요.

| 칸 | 꼭 필요한가 | 넣을 수 있는 것 |
|---|---|---|
| **종목** | 종목이 필요한 기능일 때만 | 국내 코드(`005930`), 미국 티커(`AAPL`, `BRK.B`), 코인(`BTC`, `BTCUSDT`, `BTC/USDT`), 환율(`USDKRW`, `USD/KRW`), 지수(`KOSPI`, `코스피`), 한글·영문 이름, 초성, 별칭 |
| **시장** | 아니요 | `KS`(코스피), `KQ`(코스닥), `US`(미국) 등 ([8.3](#83-시장-단어)) |
| **자산군** (노란 칩) | 같은 글자가 두 자산군에 있을 때만 | `EQUITY`, `CRYPTO`, `CURNCY`, `INDEX`와 줄임말 ([8.2](#82-자산군-단어)), 단축키 `Ctrl+Shift+E/C/X/I` |
| **기능** | 종목 없이 칠 때 필요. 종목 뒤에선 생략 가능 | 코드(`GP`), 한국어 키워드(`차트`), 키워드 초성(`ㅊㅌ`), 한글 모드로 친 코드(`헤`) |

- 대소문자는 상관없어요. `005930 gp`도 돼요.
- 순서를 바꿔 쳐도 돼요. `GP 005930`, `차트 삼성전자`도 `005930 KS EQUITY GP`로 실행돼요.
- **인자**(v0.2): 기능 뒤에 붙이는 값이에요. MOST는 시장 하나(`MOST KQ`), HMAP·IMAP은 지수 하나(`IMAP KOSDAQ`, IMAP은 미국 `IMAP SPX`도), COMP는 비교 종목 여러 개(`005930 COMP 000660 KOSPI`)를 받아요. 인자를 받지 않는 기능 뒤에 단어를 치면 `⏎ 실행 안 됨: FXC는 뒤에 인자를 받지 않아요`라고 알려 줘요.
- 기능 바로 뒤, 줄 끝의 `GO`·`<GO>`는 지워요. 그래서 블룸버그식으로 `005930 KS <EQUITY> GP <GO>`를 그대로 쳐도 돼요.

### 7.3 줄여 쓰기와 빈 칸이 정해지는 방법

| 입력 | 실행 | 규칙 |
|---|---|---|
| `005930 GP` | `005930 KS EQUITY GP` | 시장·자산군은 종목에서 정해져요 |
| `005930` (종목만) | 지금 기능 그대로 그 종목 | 보던 기능이 종목용이고 그 종목에 쓸 수 있으면 유지, 아니면 GP. 예: GIP를 보던 패널에서 `005930⏎` → `005930 KS EQUITY GIP`, WEI를 보던 패널에서는 GP |
| `GIP` (기능만) | 패널에 띄운 종목의 GIP | 띄운 종목이 없으면 `[종목]`을 물어요 |
| `MON`, `WEI`, `FXC`, `CRYP` | 그대로 | 종목이 필요 없는 기능. 패널은 띄운 종목을 기억해서, `WEI⏎` 다음 `GP⏎`로 이전 차트가 돌아와요 |
| `005930 WEI` | WEI 실행, 005930을 띄운 종목으로 | 연동 그룹에도 005930이 퍼져요 |
| `BTC`, `btcusdt`, `BTC/USDT`, `비트코인` | `BTC CRYPTO` | 코인은 USDT 쌍만 |
| `USDKRW`, `USD/KRW`, `원달러` | `USDKRW CURNCY` | 환율 |
| `EUR`, `JPY` (통화 하나) | 그 통화의 원화 환율(`EURKRW`, `JPYKRW`) | `KRW`만 치면 `USDKRW` |
| `KRWUSD` (거꾸로) | `USDKRW` | 환율은 USDKRW 방향으로 보여 줘요 |
| `CRYPTO⏎` / `CURNCY⏎` / `INDEX⏎` | CRYP / FXC / WEI | 자산군의 대표 기능 |
| `EQUITY⏎` | 상위 종목(MOST) | v0.1에서는 주식만 보이는 후보 목록이었어요 |
| `?`, `도움말`, `HELP` | 도움말·문법 요약 | |
| `설정`, `PDF` | 설정 창 | `PDF`는 블룸버그의 개인 설정 명령 |

### 7.4 Enter 한 번에 실행되는 것과 선택만 하는 것

**Enter 한 번에 실행**

- 정확히 맞는 코드·이름·키워드: `005930`, `AAPL`, `삼성전자`, `차트`, `WEI`, 종목 뒤의 `GP`
- 종목만 친 것: 지금 기능 그대로(못 쓰면 자산군별 기본 기능, 기본 GP). 설정에서 **블룸버그식 기능 메뉴**를 고르면 그 종목의 기능 메뉴가 열려요(v0.2, [7.15](#715-기능-메뉴와-로컬-검색-페이지-v02))
- 줄 첫머리의 2글자 기능 코드: `GP⏎` (띄운 종목의 가격 차트)
- 종목에서 정해지는 시장·자산군, 기본 기능, 띄운 종목
- 고쳐서 실행: `005930 KQ` → KS(005930은 코스피라서), 종목 뒤 `헤` → GP. 주황 점선 밑줄과 ⏎ 라벨의 `(KQ → KS)`로 알려 줘요
- Tab·클릭·화살표로 이미 **고른** 토큰(글자를 고치기 전까지)

**첫 Enter는 선택만(두 번째 Enter가 실행)**

- 앞부분만 친 것: `0059`, `삼성`, `삼성바이` (후보가 하나여도). 종목 목록이 바뀌면 같은 입력의 결과가 달라질 수 있어서예요
- 짧은 입력: 줄 첫머리 한 글자(`G`, `N`, `ㅅ`), 첫 칸 영문·숫자 2글자 이하 중 기능 코드가 아닌 것(`GS`, `KT`, `GO`)
- 초성·부분·오타: `ㅅㅅㅈㅈ`, `5930`, `apel`
- 첫 칸의 한/영 실수: `ㅁ메ㅣ` → AAPL
- 겹치는 이름: `CVX`(셰브론 / Convex 코인) ([7.9](#79-겹치는-이름))

**실행 안 함(빨간 밑줄 + ✗)**

- 자산군에 안 맞는 기능: `BTC CRYPTO FA` → `FA는 주식 전용이에요`
- 지원하지 않는 시장: `VOD LN` → `지원하지 않는 시장이에요 (KS·KQ·US만)`
- 아직 없는 기능: `WB` → v0.6에서 제공 예정
- 기능 두 개: `005930 GP GIP` → `기능은 하나만 쓸 수 있어요`
- USDT가 아닌 코인 쌍: `ETHBTC` → `코인은 USDT 마켓만 지원해요`

**일치 없음**: ⏎ 라벨이 `⏎ 검색`이에요. Enter를 누르면 로컬 검색 페이지가 열려요(v0.2, [7.15](#715-기능-메뉴와-로컬-검색-페이지-v02)).

고칠 방법은 늘 목록의 1번 줄에 있어요. Tab을 누르면 그 고침이 적용돼요.

### 7.5 화면에 보이는 도움

| 이름 | 어디에 | 뜻 |
|---|---|---|
| **⏎ 라벨** | 커맨드 라인 오른쪽 | `⏎ 실행: 삼성전자 가격 차트`(Enter가 실행), `⏎ 선택: 005930 삼성전자`(Enter가 고르기만), `⏎ 실행: … (헤 → GP)`(고쳐서 실행), `⏎ 실행: … (내가 정한 기본값 ↺)`, `⏎ 종목 필요`, `⏎ 실행 안 됨: …`(오류), `⏎ 일치 없음` |
| **흐린 글씨** | 입력 뒤 | Tab·→로 받아들일 수 있는 나머지 글자 |
| **후보 목록** | 입력 아래 | 최대 8줄 + `더 보기 (+N)`. 줄마다 배지(`EQ·KS`, `EQ·US`, `CRY`, `CUR`, `IDX`, 기능은 `FN`, 기록은 `HIST`), 코드, 이름(맞은 글자는 주황), 시장·종류, `↺`(기억된 선택), 그 줄이 만드는 명령. 기능 줄 오른쪽에는 지금 종목에 대한 가장 짧은 명령이 보여요 |
| **더 보기** | 목록 맨 아래 | 기능·명령 줄이 위, 종목 줄은 `── 주식 195 ──`처럼 자산군별로 묶어 최대 200줄 |
| **설명 창** | 목록 오른쪽 | 강조된 줄의 설명. 종목이면 이름·코드·시장·종류·헷갈리기 쉬운 종목(`005935 삼성전자우`)·쓸 수 있는 기능, 기능이면 하는 일·종목 필요 여부·지원 자산군·데이터 속도·실시간 슬롯 수·예시. 겹치는 종목에는 **기본값으로** 버튼 |
| **진행 표시** | 입력 아래 한 줄 | `종목 ✓ │ 시장 ✓ │ 자산군 ✓ │ 기능 ▸`처럼 어디까지 채웠는지. ✓ 채움, ▸ 지금 칸, ✗ 오류. 칸을 누르면 커서가 그 칸으로 가요 |
| **시작 목록** | 빈 줄에서(입문) | 최근 명령, 종목 없이 바로 쓰는 기능, `?` 안내 |
| **팁** | 실행한 뒤(입문) | 목록·Tab의 도움을 받아 실행했으면 더 짧은 형태를 알려 줘요(`다음엔 005930 GP ⏎ 만 입력해도 돼요`). 같은 팁은 최대 3번, `그만 보기` |
| **한** 표시 | 입력칸 오른쪽 | 한글 조합 중이면 보여요 |

후보 목록의 줄 표시

- `PREF`(우선주), `ETF`, `ETN`, `SPAC`, `ADR`, `HALT`(거래 정지), `DELISTED`(상장폐지, 흐리게 맨 아래), `LOOKUP`(직접 조회로 찾은 종목), `한/영`·`영→한`(자판 변환 줄)
- 우선주는 보통주 아래에 와요.

### 7.6 도움 수준 (입문·표준·전문가·끔)

보이는 도움의 양만 바꿔요. Tab·Enter가 하는 일은 모든 수준에서 같아요. 설정 → 커맨드 라인, 또는 상태 표시줄의 `도움: ▾`에서 바꿔요.

| 보이는 것 | 입문 (처음 기본값) | 표준 | 전문가 | 끔 |
|---|---|---|---|---|
| 후보 목록 | 입력하면 바로 | 입력하면 바로 | Tab·↓·Alt+↓를 누를 때, 또는 애매하거나 오류일 때 | ↓·Alt+↓를 누를 때만 |
| 흐린 글씨 | ✓ | ✓ | ✓ | — |
| 기능 설명 | ✓ | ✓ | 코드와 이름만 | — |
| 설명 창 | 자리가 있으면 자동 | Ctrl+/ | Ctrl+/ | Ctrl+/ |
| 기능 목록 (v0.2) | F1 | F1 | F1 | F1 |
| 진행 표시 | 전체 | 전체 | 메시지만(오류·교정·겹침) | 메시지만 |
| 키 안내·시작 목록·팁·안 맞는 기능 흐리게 | ✓ | — | — | — |
| ⏎ 라벨 | ✓ | ✓ | ✓ | ✓ |

- 입문에서 목록·Tab·화살표 없이 직접 쳐서 Enter 한 번에 실행한 명령이 30개가 되면 "표준으로 바꿀까요?"를 한 번만 물어봐요.

### 7.7 한글로 찾기

- **한글 이름**: `삼성전자`, `카카오`, `애플`, `비트코인`, `코스피`, `원달러`
- **이름 일부**: `삼성` → 삼성전자, 삼성바이오로직스, 삼성SDI …
- **초성**: `ㅅㅅㅈㅈ` → 삼성전자. 기능 키워드 초성도 돼요(`ㅊㅌ` → 차트 → GP)
- **한국어 키워드**: `차트`, `분봉`, `관심종목`, `지수`, `환율`, `코인` 등 ([8.6](#86-한국어-키워드))
- **한/영 실수 교정**: 한글 모드로 영문 코드를 쳐도 알아봐요.
  - 기능·시장·자산군 칸: 바로 고쳐서 실행. `005930 헤⏎` → `005930 GP`
  - 종목 칸: 고치지 않고 `ㅁ메ㅣ → AAPL` 줄을 보여 줘요. 직접 골라야 해요
  - 영문 모드로 한글 이름을 친 경우(`tkatjd`): `tkatjd → 삼성전자 (영→한)` 줄
  - 한글 모드로 친 코드 예(두벌식): GP→`헤`, GIP→`햐ㅔ`, WEI→`ㅈ댜`, FXC→`ㄹㅌㅊ`, CRYP→`ㅊ교ㅔ`, EQUITY→`ㄷ벼ㅑ쇼`, KS→`ㅏㄴ`, AAPL→`ㅁ메ㅣ`, BTC→`ㅠㅅㅊ`
  - 세벌식 등 다른 자판에서는 맞지 않을 수 있어요. 그때는 설정에서 **한/영 실수 교정**을 꺼요.
- **영문 머리글자**(v0.2): 두 단어 이상인 영문 이름은 머리글자로도 찾아요. `boa` → Bank of America, `er` → Equity Residential. 줄에 `머리글자` 표시가 붙어요.
- **미국 종목 순서**(v0.2): 앱에서 본 거래대금(관심종목·차트의 시세, MOST US 순위)이 큰 미국 종목이 목록에서 위로 올라와요. 종목 목록을 다시 만들 때(켤 때·12시간마다) 반영돼요.
- **오타 한 글자**(v0.2): 4글자 이상 영문 이름을 한 글자 틀려도 찾아요. `apel` → Apple(`오타?` 표시). 결과가 3개보다 적을 때만, 첫 글자는 맞아야 해요. 코드·티커에는 쓰지 않아요. 기능 코드도 4글자 이상이면 한 글자 차이까지(`CRPY` → CRYP).
- 단축키는 한글 모드에서도 키보드 자리로 알아봐요. `Ctrl+Shift+ㄷ`도 `Ctrl+Shift+E`예요.
- 한글 입력 중(조합 중)에 누른 Tab·Enter는 글자가 끝난 뒤 한 번만 처리해요.

### 7.7.1 별칭 만들기 (ALIAS, v0.2)

자주 보는 종목에 짧은 이름을 붙여요.

- 만들기: `ALIAS 별칭 종목⏎`. 예: `ALIAS SS 005930⏎` → 이제 `SS⏎`가 삼성전자예요. `ALIAS AP AAPL US⏎`처럼 시장을 붙여도 돼요. `별칭 이름 종목⏎`도 같아요.
- 별칭은 영문·숫자·한글 2~12글자예요. 기능(GP 등)·명령·시장(KS 등)·자산군 단어는 쓸 수 없어요.
- 줄 첫머리에서는 별칭이 같은 글자의 티커보다 먼저예요(후보 줄에 `ALIAS` 배지). 진짜 티커를 보려면 `SS US`처럼 시장을 붙여요.
- 같은 별칭으로 다시 만들면 바뀌어요. 알림의 **되돌리기**로 되돌릴 수 있어요.
- 목록과 지우기: `ALIAS⏎`(설정 → 커맨드 라인 → 별칭).

### 7.9 겹치는 이름

같은 글자가 여러 뜻일 때의 규칙이에요. 어느 뜻으로 읽었는지는 진행 표시에 늘 적고, 다른 뜻은 바로 아래 줄에 있어요.

1. **시장이나 자산군을 직접 쓰면** 그것으로 정해요. `BTC US`(미국 ETF), `BTC CRYPTO`(코인), `GS KS`(코스피의 GS홀딩스).
2. **정해 둔 표**: `BTC`, `ETH`, `SOL`, `XRP`는 코인, 통화 코드(`USD`, `EUR`, `JPY` …)는 환율로 읽어요.
3. **내가 정한 기본값**(아래).
4. **그 밖에는 실행하지 않아요.** 첫 Enter는 1번 줄을 선택만 하고 두 줄을 모두 보여 줘요. 예: `CVX`(셰브론 / Convex 코인).

줄 첫머리의 단어

- **3글자 이상의 기능 코드는 기능**이에요. `FXC`, `WEI`, `CRYP`는 미국 티커이기도 하지만 기능으로 읽어요. 종목을 원하면 `FXC US`처럼 시장을 붙이거나 2번 줄을 골라요.
- **2글자 정확한 기능 코드**(`GP`, `FA`)도 기능으로 바로 실행해요. 같은 글자의 종목은 2번 줄에, `GP US`처럼 시장을 붙이면 종목이에요.
- `HELP⏎`는 도움말이에요. 미국 종목 HELP는 `HELP US`로 쳐요.
- `GO`만 치면 미국 종목 Grocery Outlet 검색이에요(2글자라 선택만).
- 한국 회사 이름과 미국 티커가 같은 것(`GS`, `KT`, `KB`)은 선택만 해요.
- 시장 단어(`UA`, `UN`, `AMS` 등)는 종목 뒤에서는 시장으로, 줄 첫머리에서는 종목으로 읽어요.

**내 기본값 정하기**

- 겹치는 입력에서 1번이 아닌 같은 줄을 **두 번** 고르거나, 설명 창의 **기본값으로** 버튼을 누르면 그 줄이 그 입력의 기본값이 돼요. `이제 BTC⏎는 BTC US(ETF)로 열려요 · [되돌리기]` 알림이 떠요.
- 그 뒤 ⏎ 라벨에 `(내가 정한 기본값 ↺)`가 붙어요.
- 지우기: 설명 창의 `기본값 지우기`, ↺ 줄에서 `Shift+Delete`, 또는 설정 → 커맨드 라인 → **기억된 선택 초기화**.
- 애매한 목록에서 고른 줄은 기억해서(↺) 다음에 같은 입력을 하면 위로 올려 줘요.

**겹치는 이름 표**: 도움말의 **겹치는 이름 표**에서 앱이 아는 모든 겹침(약 280줄)과, 그 단어만 치고 Enter를 누르면 무엇을 하는지, 그렇게 정한 이유를 거르며 볼 수 있어요.

### 7.10 목록에 없는 코드 직접 조회

오늘 상장한 종목처럼 앱의 종목 목록에 아직 없는 코드는 한국투자증권에서 직접 찾아요.

- 국내 6자리 코드(숫자로 시작)나 미국 티커 모양(영문 1~5자, `.B` 같은 클래스)을 치면 `목록에 없는 코드예요 — ⏎로 KIS에서 직접 조회` 줄이 보여요.
- 첫 Enter로 그 줄을 고르고, **두 번째 Enter**에 조회해요. 찾으면 `LOOKUP` 표시를 달고 이번 실행 동안 목록에 넣어요. 기능을 안 쳤으면 GP로 열어요.
- 한국투자증권 키가 있어야 해요. 키가 없으면 `한국투자증권 키를 넣으면 직접 조회할 수 있어요`라고 알려 줘요.

### 7.11 포커스: 커맨드 라인과 패널 본문

| 상태 | 들어가는 법 | 표시 |
|---|---|---|
| 커맨드 라인 (기본) | 패널을 누르면, `Ctrl+L`(Mac ⌘L) | 입력줄 커서 |
| 패널 본문 | 빈 줄에서 Esc, `F6`, `Ctrl+↓`(Windows) | 본문에 주황 안쪽 테두리 |

- 본문에서는 관심종목 줄을 `↑` `↓`로 옮기고 Delete·Backspace(Mac `⌫`)로 빼요. 마우스로는 줄 끝의 ✕예요.
- 본문에서 영문 글자나 숫자를 치면 커맨드 라인으로 돌아가 그 글자부터 입력돼요. Esc, `F6`, `Ctrl+L`로도 돌아가요.
- 빈 줄이고 목록이 없으면 Tab·Shift+Tab은 보통처럼 다음 요소로 포커스를 옮겨요. 키보드가 커맨드 라인에 갇히지 않게 하려는 거예요.

### 7.12 명령 팔레트

- `Ctrl+K`(Mac ⌘K)로 화면 가운데에 큰 커맨드 라인을 열어요. 커맨드 라인과 똑같이 동작하고 줄을 더 많이 보여 줘요.
- 대상은 **팔레트를 연 그 창의 활성 패널**이에요. 위쪽 칩(`→ 패널 2 · AAPL US GP`)에 보여요.
- `Alt+1…9`(Mac Option+1…9)로 대상 패널을 바꿔요.
- 실행하면 닫혀요. Esc로도 닫아요.

### 7.13 붙여넣기와 기록

- 명령을 붙여 넣으면 읽기만 하고 **실행하지 않아요.** 꺾쇠(`<`, `>`)와 끝의 `GO`는 지워요. 확인한 뒤 Enter를 눌러요.
- 실행한 명령은 표준형(`005930 KS EQUITY GP`)으로 기록에 남아요(최근 500개). 빈 줄에서 `↑`로 꺼내요. 글자를 치고 목록을 닫은 뒤 `↑`를 누르면 그 글자가 든 기록만, `Ctrl+R`로는 기록을 검색해요(v0.2). 최근 화면 목록은 `LAST⏎`.
- 실행하면 줄이 비고, 그 패널의 명령이 흐린 글씨로 보여요. 그 위에 바로 새 명령을 치면 덮어써요.

### 7.15 기능 메뉴와 로컬 검색 페이지 (v0.2)

**기능 메뉴**(설정 → 커맨드 라인 → 종목만 입력하고 Enter를 누르면 → 블룸버그식 기능 메뉴)

- `005930⏎`처럼 종목만 치면 패널이 그 종목의 **기능 메뉴**로 바뀌어요. 이름·현재가와 쓸 수 있는 기능이 번호로 보여요(주식: 1) GP 2) GIP 3) DES 4) N 5) COMP). 아직 없는 기능은 아래에 흐리게 보여요.
- 커맨드 라인에 번호를 치고 Enter(`3⏎`)하거나 줄을 누르면 그 기능이 열려요. 메뉴가 아닌 곳에서 숫자는 종목코드예요.
- 기능을 함께 치면(`005930 GP⏎`) 메뉴 없이 바로 열려요.

**로컬 검색 페이지**

- 후보 목록의 **더 보기**를 누르거나, 일치하는 것이 없을 때(`⏎ 검색`) Enter를 누르면 패널이 로컬 검색 페이지로 바뀌어요.
- 앱 안의 종목 목록(국내·미국·코인·환율·지수)과 기능에서 찾은 줄을 자산군별로 묶어 200줄까지 보여 줘요. 위 입력칸에서 다른 말로 다시 찾을 수 있어요(인터넷을 쓰지 않아요). 오타 한 글자·초성·영문 머리글자도 돼요.
- 줄을 누르면 그 종목·기능이 이 패널에서 열려요. 국내 종목은 영문 이름이 목록에 없어서 한글 이름·코드로 찾아요.

### 7.16 기능 목록 (F1, v0.2)

어떤 기능이 있는지 모를 때 `F1`을 눌러요. 후보 목록 자리에 지금 쓸 수 있는 기능이 두 묶음으로 떠요.

| 묶음 | 기능 | 쓰는 법 |
|---|---|---|
| **종목 다음에 쓰는 기능** | GP, GIP, DES, COMP, N | `005930 DES⏎`처럼 종목 뒤에 써요. N은 종목 없이도 돼요(전체 뉴스·공시) |
| **종목 없이 쓰는 기능** | MON, WEI, FXC, CRYP, MOST, HMAP, IMAP, LAST | `WEI⏎`처럼 기능만 써요. MOST·HMAP·IMAP은 뒤에 시장·지수를 붙일 수 있어요(`MOST KQ`) |

- 목록이 창보다 길면 목록 안에서 스크롤돼요(마우스 휠, `↑` `↓`로 내려가면 고른 줄을 따라 내려가요). 패널이 창 아래쪽이면 목록이 위로 열려요.
- `↑` `↓`로 고르면 오른쪽 ⏎ 라벨이 무엇이 열리는지 보여 줘요. `Enter`(또는 클릭)로 열고, `Tab`은 줄에 넣기만 해요. `Esc`나 `F1`을 한 번 더 누르면 닫혀요. 글자를 치면 목록이 닫히고 보통 입력으로 돌아가요.
- 종목 다음 묶음의 기능을 고르면:
  - 줄에 종목을 쳐 뒀으면 그 종목으로 열어요(`005930` → F1 → DES = `005930 DES`).
  - 빈 줄이면 패널에 띄운 종목으로 열어요.
  - 종목이 없으면 줄에 `DES `만 넣어요. 이어서 종목을 치고 Enter(`DES 005930⏎`).
- 종목 없이 묶음의 기능은 줄에 친 글자와 상관없이 그 기능만 열어요.
- 커맨드 라인 밖(패널 본문 등)에서 `F1`을 누르면 활성 패널의 커맨드 라인으로 와서 목록을 열어요.
- Mac 노트북 키보드에서는 `fn`을 함께 눌러요(`fn+F1`). 시스템 설정에서 F1 등을 표준 기능 키로 쓰게 했으면 `F1`만 눌러도 돼요.
- 아직 만들지 않은 기능은 이 목록에 없어요. 앞으로 생길 기능은 [8.1](#81-기능-코드와-명령)과 기능 메뉴([7.15](#715-기능-메뉴와-로컬-검색-페이지-v02))에서 볼 수 있어요.
- 설명 창(기능의 자세한 설명)은 `Ctrl+/`(Mac `⌘/`)로 봐요. v0.1까지는 `F1`이 설명 창이었어요. `F1` 키는 설정 → 단축키에서 바꿀 수 있어요.

### 8.7 코인

## 10. 설정

`Ctrl+,`(Mac `⌘,`), 커맨드 라인의 `설정⏎`·`PDF⏎`로 열어요. 상태 표시줄의 `데모 시세`를 누르면 데이터 연결이 바로 열려요. **바꾸면 바로** 모든 패널과 떼어낸 창에 적용돼요. 저장 버튼은 없어요.

### 10.1 일반

- **시작할 때 마지막 배치 복원**: 켜 두면 앱을 끌 때의 모든 창과 화면 탭의 배치가 다음 실행 때 복원돼요. 끄면 늘 기본 배치로 시작해요.

### 10.2 화면

- **테마**: Modern(블룸버그 터미널 색: 검정 바탕에 흰 숫자, 앰버 라벨·제목·종목 이름, 켜진 탭·버튼은 앰버 바탕, 묶음 줄은 남색 띠). Classic은 후순위예요.
- **강조 색**: 블룸버그 앰버(기본), 예전 주황, 흰색, 청록 중에서. 라벨·표 머리줄·종목 이름 색이 강조 색을 따라 바뀌어요.
- **등락 색**: **글로벌식**(기본, 블룸버그의 상승 초록 ▲ · 하락 빨강 ▼) 또는 **한국식**(상승 빨강 ▲ · 하락 파랑 ▼).
- **글자 크기**: 90%, 100%, 110%, 120%, 135%. 표·차트·커맨드 라인·떼어낸 창까지 화면 전체를 같은 배율로 키워요.
- **데이터 신선도 배지**: 설명만 있어요. 끌 수 없어요([5장](#5-데이터-신선도-배지)).

### 10.3 커맨드 라인

- **자동완성 도움 수준**: 입문·표준·전문가·끔 카드 중에서 골라요. 비교표에서 고른 수준이 강조되고, 아래 **미리보기**가 `0059`를 쳤을 때 그 수준에서 어떻게 보이는지 바로 보여 줘요([7.6](#76-도움-수준-입문표준전문가끔)).
- **종목만 입력하고 Enter를 누르면**: 지금 기능 유지(기본값) / 블룸버그식 기능 메뉴(v0.2). 블룸버그식이면 `005930⏎`이 기능 메뉴를 열어요([7.15](#715-기능-메뉴와-로컬-검색-페이지-v02)).
- **자산군별 기본 기능**(v0.2): 종목만 쳤는데 지금 기능을 그 종목에 못 쓸 때 열 기능을 주식·코인·환율·지수마다 골라요(기본 GP). 예: 주식을 DES로 하면 WEI를 보던 패널에서 `005930⏎` → 종목 개요.
- **입력 도우미**
  - **Tab으로 시장·자산군 채우기**: 끄면 Tab이 종목만 채우고 시장·자산군을 써 넣지 않아요.
  - **한/영 실수 교정**: 끄면 한/영 변환 줄과 자동 교정이 모두 꺼져요. 세벌식 등 다른 자판을 쓰면 꺼요.
  - **HTS식 6자리 바로 열기**(v0.2, 기본 꺼짐): 켜면 국내 종목코드 6자리를 다 치는 순간 Enter 없이 종목이 바뀌어요.
  - **F키 모드**(Windows, v0.2, 기본 꺼짐): 켜면 커맨드 라인에서 F8 = EQUITY, F9 = CRYPTO, F10 = INDEX, F11 = CURNCY를 넣어요. 켜 있는 동안 F11은 전체 화면이 아니에요. 전체 화면 단축키가 F11이면 단축키 탭에서 다른 키로 바꿔요(설정 창이 알려 줘요).
  - **사용 팁**: 끄면 짧은 형태 팁을 보여 주지 않아요.
  - **기억된 선택 초기화**: 기억된 선택(↺)과 겹침 기본값을 지워요. 사용 기록(순위)은 남아요.
- **별칭**(v0.2): `ALIAS 별칭 종목⏎`으로 만든 별칭 목록과 **지우기**([7.7.1](#771-별칭-만들기-alias-v02)).
- **한글 입력 기록기**: 커맨드 라인에서 한글을 칠 때의 키·조합·입력 이벤트 순서를 남겨요. Tab·Enter·클릭이 이상하게 동작하면 켜 두고 다시 해 본 뒤 **기록 복사**를 눌러 보내 주세요. 기록에는 커맨드 라인에 친 글자가 들어가요(앱키 입력칸은 기록하지 않아요). **지우기**로 비워요. 기본은 꺼짐이에요.

### 10.4 단축키

- 바꿀 키의 **키 모양(키캡)** 을 누르고 새 키를 눌러요. **Esc**는 취소, **Backspace**는 그 키를 지워요.
- **+** 로 같은 일에 키를 하나 더 붙여요.
- 다른 일에 이미 쓰는 키는 받지 않고 무엇과 겹치는지 알려 줘요. Tab·Enter 같은 바꿀 수 없는 키, Shift+글자, Ctrl+숫자, Ctrl+Z 같은 편집 키도 받지 않아요.
- 줄마다 **기본값**, 맨 아래 **모두 기본값으로**.
- 아래쪽에 **바꿀 수 없는 키** 목록이 있어요.

### 10.5 데이터 연결

- **한국투자증권 Open API**: 상태, 앱키·앱시크릿(바꿀 때만 입력), 서버(실전·모의), **저장하고 연결 테스트**, **키 지우기**, 실시간 슬롯과 조회 호출 사용량, 기능별 실시간 슬롯 표([2.2](#22-한국투자증권-키-넣기)).
- **Binance**: 키가 필요 없다는 안내와 연결 주소.
- **환율**: 한국투자증권 키가 있으면 10초마다, 없으면 ECB 기준환율(하루 한 번)이라는 안내.
- **DART 전자공시**(v0.2): 상태(끝 4자리), 인증키(40자리, 바꿀 때만 입력), **저장하고 확인**(최근 공시를 한 번 받아 봐요), **인증키 지우기**. 인증키는 OpenDART(opendart.fss.or.kr)에서 회원 가입 뒤 무료로 받아요.
- **뉴스 RSS**: 받는 곳과 5분 간격, 뉴스 아카이브 안내.
- **BOK ECOS**(v0.3): 상태(끝 4자리), 인증키(바꿀 때만 입력), **저장하고 확인**(국고채 3년 금리를 한 번 받아 봐요), **지우기**. 인증키는 한국은행 경제통계시스템 Open API(ecos.bok.or.kr/api)에서 무료로 받아요. GC의 국고채 커브에 써요.
- **SEC EDGAR 연락처**(v0.3): 영문 이름과 이메일(예: `Hong Gildong me@example.com`). 요청 머리글에 들어가서 한글은 넣을 수 없어요. `SEC가 요청을 막았어요(HTTP 403: …)`가 나오면 괄호 안이 SEC가 알려 준 이유예요. SEC는 한도를 넘거나 연락처가 없다고 보면 약 10분(길면 하루) 동안 막아서, 10분쯤 뒤에 다시 **저장하고 확인**을 눌러요. 막힌 동안 더 보내면 막힘이 길어져서, 앱은 막힌 뒤 FA 화면에서는 1시간, 확인 버튼은 10분 동안 SEC에 보내지 않고 `약 N분 동안 SEC에 요청하지 않아요`라고 알려 줘요. 연락처가 맞는데도 계속 막히면 SEC가 쓰고 있는 인터넷 연결의 프로그램 요청을 막는 경우예요(브라우저로는 열려도 그래요). SEC는 키 대신 요청마다 연락처를 달라고 해서, FA의 미국 재무제표를 받을 때만 SEC에 보내요. **저장하고 확인**은 애플 자료를 한 번 받아 봐요. 화면에는 앞 세 글자만 보여요.
- **FRED**(v0.3): API 키(32자, fred.stlouisfed.org에서 무료). **저장하고 확인**은 미국 10년물 금리를 한 번 받아 봐요. ECO의 미국 지표 발표일과 최근 값에 써요.
- **KRX Open API**(v0.4): 인증키(openapi.krx.co.kr에서 회원 가입 뒤 "ETF 일별매매정보" 서비스를 신청해 무료로 받아요). FFLO(ETF 자금 흐름)의 일별 상장 좌수·NAV에 써요. **저장하고 확인**은 최근 거래일 ETF 자료를 한 번 받아 봐요.
- **KOSIS**(v0.6): 인증키(KOSIS 공유서비스 kosis.kr/openapi에서 회원 가입 뒤 무료로 받아요). ECST 내 통계 탭의 KOSIS 통계에 써요. **저장하고 확인**은 통계 목록을 한 번 받아 봐요.
- **앞으로 추가될 키**: KOSIS(v0.6), 공공데이터포털(v0.7), EIA(v0.11).

- **지금 확인**: GitHub 저장소([Releases](https://github.com/anecdote0324/TICKER/releases))에서 이 컴퓨터에 맞는 더 새 버전을 찾아요.
- **자동 확인**(처음에 켜짐): 켜고 20초 뒤와 6시간마다 확인해서, 새 버전이 있으면 `새 버전 v… 이 있어요` 알림을 띄워요. 알림의 **업데이트**를 누르면 이 화면이 열려요.
- **미리 보기 버전**: 켜면 시험 중인 미리 보기(Pre-release)도 받아요. 직접 정하지 않으면 지금 쓰는 버전이 미리 보기일 때만 켜져요.
- **업데이트하고 다시 시작**: 단추 하나로 받기(진행 막대) → 파일 지문(SHA-256)·크기 확인 → 앱을 닫고 설치 → 다시 켜기까지 알아서 해요. 보통 프로그램 업데이트처럼 손댈 것이 없어요.
- 자동 확인이 켜져 있으면 새 버전을 **뒤에서 받아 두고**, 다 받으면 `v… 업데이트를 받았어요` 알림의 **다시 시작해서 업데이트**로 설치해요. 지금 하던 일을 마치고 눌러도 돼요.
- **이 버전 건너뛰기**는 그 버전의 알림과 뒤에서 받기를 끄고, 여기서는 계속 받을 수 있어요.
  - **Windows 설치형**: 설치 창 없이 설치하고 다시 켜져요.
  - **Windows 휴대용**: 새 휴대용 파일을 지금 파일 옆에 받아 켜고 이 창은 닫혀요. 예전 파일은 지워도 돼요.
  - **Mac**: 앱이 닫히면 응용 프로그램 폴더의 TICKER를 새 버전으로 바꿔 끼우고 다시 켜요. 서명하지 않은 앱이라 업데이트 뒤 처음 켤 때 키체인 허용(로그인 암호, **항상 허용**)을 한 번 더 물을 수 있어요. 응용 프로그램 폴더가 아닌 곳(dmg 안 등)에서 켰거나 Mac 업데이트 파일(zip)이 없는 예전 릴리스면, 받은 설치 파일을 열어 주고 직접 덮어써요. 바꿔 끼운 기록은 데이터 폴더의 `logs/update.log`에 남아요.
- 설정·한국투자증권 키·화면 배치는 데이터 폴더에 있어서 업데이트해도 그대로예요.
- 이 앱의 저장소 릴리스 파일만 받아요. 저장소가 비공개이면 확인할 수 없어요(`업데이트 저장소를 찾을 수 없어요`).
- **패치노트**: 업데이트한 뒤 처음 켜면 새 버전에서 새로 생긴 기능·바뀐 것·고친 것을 패치노트 창으로 보여 줘요(여러 버전을 건너뛰었으면 그 사이 버전 것도 함께). `Enter`·`Esc`·**확인**으로 닫고, **지난 패치노트도 보기**로 예전 버전 것도 봐요. 설정 → 정보 → **패치노트 보기**로 언제든 다시 열어요. 같은 내용이 GitHub Releases의 설명과 저장소 `patchnote/` 폴더에도 있어요.

## 12. 자주 묻는 것과 문제 해결

**주식·지수에 `데모`가 붙어 있어요.**
한국투자증권 키를 넣지 않아서 가짜 시세를 보여 주는 거예요. [2.2](#22-한국투자증권-키-넣기)대로 키를 넣으면 실제 시세로 바뀌어요. 코인과 환율은 키 없이도 실제 값이에요.

**BTC가 실시간인지 어떻게 알아요?**
신선도 배지가 없으면 실시간이에요. 상태 표시줄의 Binance 점이 **초록**이면 연결된 거예요. 상태 표시줄의 `데모 시세`는 주식·지수 이야기예요.

**연결 테스트가 끝나지 않거나, 키를 넣은 뒤 시세가 모두(코인까지) 멈췄어요.**
지금 버전은 연결 테스트가 단계마다 시간 제한이 있어서, 늦어도 1분 안에 성공이나 막힌 단계를 보여 줘요. 서버가 멈추면 상태 표시줄이 `⚠ 내장 서버 응답 없음`으로 바뀌어요. 그때 설정 → 정보 → **진단 정보 복사**를 눌러 붙여 넣어 보내 주세요. 화면이 굳어서 설정을 못 열면 앱을 끄고 다시 켠 뒤 복사해요(데이터 폴더의 `logs/server.log`에도 남아 있어요).

**국내 종목 몇 개가 `—`로 비어 있거나 차트가 비어 있어요.**
v0.1.0-beta.7까지는 조회가 한도를 넘으면 조회 대기줄이 통째로 멈추는 문제가 있었어요. 새 버전으로 덮어 설치하면 돼요. 그래도 비어 있으면 진단 정보를 보내 주세요.

**장이 끝난 국내 종목에 `마감`이 붙어요.**
정상이에요. 장이 끝나 체결이 없으면 마지막 값에 `마감 15:30`(다음 날부터는 `마감 10/30`)이 붙어요. 장이 닫힌 종목은 5분마다 마감 값을 다시 확인해요.

**WEI의 해외 지수 몇 개가 `0.00`이에요.**
v0.1.0-beta.9까지는 FTSE 100·DAX·CAC 40·니케이·항셍·대만·다우존스를 잘못된 코드로 조회해서 0으로 보였어요. 새 버전으로 덮어 설치하면 돼요. 그래도 값을 받지 못한 지수는 `—`로 보여요.

**기본 배치의 패널이나 연동 색이 이 설명과 달라요.**
앱은 지난번 배치를 저장해 두고 다시 열어요. 예전 버전에서 쓰던 배치가 남아 있으면 패널이 빠져 있거나 연동 색이 다를 수 있어요. 맨 위 줄의 `워크스페이스 ▾` → **기본 배치로 새로 시작**을 누르면 기본 배치로 돌아가요(알림의 되돌리기로 되돌릴 수 있어요).

**`⚠ 멈춤`이 떠요.**
받아야 할 때 새 값을 받지 못했어요. 인터넷 연결을 확인해요. 상태 표시줄에서 어느 출처가 끊겼는지(빈 점 + ⚠) 볼 수 있어요. 연결이 돌아오면 저절로 다시 받아요. 한국투자증권이면 조회 한도를 넘었을 수도 있어요(잠시 뒤 풀려요).

**환율이 움직이지 않아요.**
배지가 `일별`이면 ECB 기준환율이라 하루 한 번만 바뀌어요. 한국투자증권 키를 넣으면 10초마다 받아요(`10초 주기`). 키가 있는데도 `일별`이면 한국투자증권 환율 조회가 1분 넘게 실패한 거예요. 진단 정보를 보내 주세요.

**Enter를 눌렀는데 실행이 안 되고 줄만 골라져요.**
입력이 여러 뜻일 수 있어서예요. 한 번 더 Enter를 누르면 실행돼요. ⏎ 라벨이 `⏎ 선택:`이면 고르기, `⏎ 실행:`이면 실행이에요([7.4](#74-enter-한-번에-실행되는-것과-선택만-하는-것)).

**`FXC`를 쳤는데 미국 종목 FXC가 아니라 환율이 떠요.**
줄 첫머리의 기능 코드는 기능으로 읽어요. 종목을 원하면 `FXC US`처럼 시장을 붙여요([7.9](#79-겹치는-이름)).

**한글 모드로 쳤더니 이상한 글자가 됐어요.**
기능 칸이면 저절로 고쳐서 실행해요(`헤` → GP). 종목 칸이면 `ㅁ메ㅣ → AAPL` 줄을 골라요. 한글 입력이 계속 이상하면 설정 → 커맨드 라인 → 한글 입력 기록기를 켜고 다시 해 본 뒤 기록을 보내 주세요.

**패널을 실수로 닫았어요.**
패널의 ✕는 되돌릴 수 없어요. 화면 탭의 ✕, 워크스페이스 불러오기·지우기·새로 시작은 알림의 **되돌리기**로 돌아갈 수 있어요. 자주 쓰는 배치는 워크스페이스에 이름을 붙여 저장해 두세요.

**떼어낸 창을 닫았더니 어디 갔어요?**
패널을 떼어낸 창이면 메인 창의 원래 자리로, 화면 탭을 떼어낸 창이면 메인 창의 화면 탭으로 돌아와요. 없애려면 패널의 ✕나 화면 탭의 ✕를 눌러요.

**떼어낸 창이 안 보여요 / 모니터를 뺐어요.**
메인 창의 화면 탭에서 떼어낸 화면(흐린 기울임 글씨)을 누르면 그 창을 앞으로 가져와요. 화면 밖에 있으면 ↙로 메인 창에 돌려놓은 뒤 다시 떼어내요. 앱은 화면 밖으로 나간 창을 메인 모니터로 모아요.

**화면 탭의 떼어내기 버튼(↗)이 안 보여요.**
메인 창에 화면이 하나뿐이면 떼어낼 수 없어요. `+`로 화면 탭을 하나 더 만들면 보여요.

**설치형과 휴대용 중 무엇을 받아요?**
설치형(`TICKER.Setup.<버전>.exe`)을 권해요. 켜는 게 빠르고 시작 메뉴에 등록돼요([1.1](#11-설치-파일-받기)).

**미리 보기와 정식은 무엇이 달라요?**
미리 보기는 시험 중인 버전, 정식은 확인을 마친 버전이에요. 받는 법과 설치법은 같고, 덮어 설치해도 설정·키·배치가 남아요.

**전체 화면에서 나가고 싶어요.**
전체 화면을 켠 키를 한 번 더 눌러요. Windows는 `F11`, Mac은 `⌃⌘F`예요. 설정에서 키를 바꿨다면 바꾼 키예요([4.6](#46-전체-화면)).

**새 버전이 나왔는지 어떻게 알아요?**
앱이 켤 때와 6시간마다 확인해서 `새 버전 v… 이 있어요` 알림을 띄워요. 직접 확인하려면 설정 → 정보 → 업데이트의 **지금 확인**을 눌러요([10.8](#108-업데이트)).

**Windows에서 제거가 막혀요.**
[1.2](#12-windows에서-처음-열-때)의 제거 방법을 보세요.

**Mac에서 "손상되었기 때문에 열 수 없습니다"가 떠요.**
`xattr -cr /Applications/TICKER.app`을 터미널에서 실행해요([1.3](#13-mac에서-처음-열-때)).

**앱이 느려요.**
설정 → 정보 → 성능의 숫자(커맨드 라인 해석 p95, 16ms를 넘긴 입력 이벤트)를 알려 주세요. 글자 크기를 바꾸거나 패널 수를 줄여 볼 수도 있어요.

**설정·배치를 처음 상태로 돌리고 싶어요.**
배치는 워크스페이스 ▾ → 기본 배치로 새로 시작. 설정까지 모두 지우려면 앱을 끄고 데이터 폴더([1.5](#15-데이터-폴더))를 지워요. 한국투자증권 키도 함께 지워져요.
