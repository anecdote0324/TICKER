# TICKER 사용설명서

TICKER는 블룸버그 터미널을 닮은 개인용 데스크톱 시세 터미널이에요. 이 설명서는 지금 앱(v0.1.0)에서 되는 모든 기능과 모든 명령어를 설명해요. 기능이 생기거나 바뀌면 이 설명서도 함께 고쳐요.

- 아직 만들지 않은 기능은 "v0.2에서 제공 예정"처럼 적어 두었어요. 버전별 계획은 [버전별 기능](../versions.md)에 있어요.
- `Mod`는 Windows의 **Ctrl**, Mac의 **⌘(Command)** 예요. 키를 적을 때 Windows 키를 먼저, Mac 키를 괄호 안에 적어요. 예: `Ctrl+K`(Mac `⌘K`).
- `⏎`는 Enter(Mac Return) 키예요.

## 1. 설치하고 처음 열기 (꼭 읽어 주세요)

### 1.1 설치 파일 받기

GitHub 저장소의 [Releases](https://github.com/anecdote0324/BloombergTerminal/releases)에서 받을 버전의 **Assets**를 열어 내 컴퓨터에 맞는 파일을 받아요.

| 컴퓨터 | 받을 파일 | 설명 |
|---|---|---|
| Windows (권장) | `TICKER.Setup.<버전>.exe` | 설치형. 시작 메뉴와 바탕 화면에 등록되고, 켜는 게 빨라요 |
| Windows (설치 없이) | `TICKER.<버전>.exe` | 휴대용. 설치하지 않고 바로 실행해요. 켤 때마다 임시 폴더에 압축을 풀어서 조금 느려요 |
| Mac (Apple Silicon, M1 이상) | `TICKER-<버전>-arm64.dmg` | 인텔 Mac은 지원하지 않아요 |

- `Source code (zip)`, `Source code (tar.gz)`는 프로그램 코드라 실행 파일이 아니에요.
- `Latest` 표시가 붙은 것이 정식 버전이에요(지금은 `v0.1.0`). 저장소 첫 화면 오른쪽의 Releases에도 이 버전이 보여요. 정식 뒤에 나온 시험 버전에는 `Pre-release` 표시가 붙어요.
- **미리 보기(Pre-release)** 는 시험 중인 버전이고, **정식(Latest)** 은 확인을 마친 버전이에요. 둘 다 받는 방법과 설치 방법은 같아요.
- 설치형을 권하는 이유: 켜는 속도가 빠르고, 시작 메뉴에서 찾을 수 있고, 새 버전을 같은 자리에 덮어 설치할 수 있어요. 휴대용은 USB에 넣어 다니거나 잠깐 써 볼 때 좋아요. 두 방식 모두 설정·키·화면 배치는 같은 데이터 폴더(1.5)에 저장돼요.

### 1.2 Windows에서 처음 열 때

개인용이라 코드 서명을 하지 않아서, Windows가 처음 한 번 막아요. 아래처럼 허용하면 돼요.

1. 브라우저가 "일반적으로 다운로드되지 않는 파일"이라고 하면 다운로드 목록에서 `…` → **유지**(필요하면 **그래도 유지**)를 눌러요.
2. 실행할 때 파란 "Windows의 PC 보호" 창이 뜨면 **추가 정보** → **실행**을 눌러요.
3. 설치형은 설치가 끝나면 바로 켜져요. 다음부터는 시작 메뉴나 바탕 화면의 **TICKER**로 켜요.

주의할 것

- **새 버전**은 새 설치 파일을 받아 그대로 실행하면 덮어 설치돼요. 먼저 지울 필요가 없어요. 설정·한국투자증권 키·화면 배치는 그대로 남아요.
- **제거**: 설치 폴더의 제거 프로그램(`Uninstall TICKER.exe`)은 Windows 보안이 "이 앱의 일부가 차단되었습니다"로 막을 수 있어요. 먼저 **설정 → 앱 → 설치된 앱**에서 TICKER를 제거해 보고, 거기서도 막히면 앱을 끈 뒤 설치 폴더(`%LOCALAPPDATA%\Programs\TICKER`)와 바탕 화면·시작 메뉴의 바로 가기를 지워요. 설정과 키까지 지우려면 데이터 폴더(`%APPDATA%\TICKER`)도 지워요.
- 백신 프로그램이 서명 없는 앱이라고 경고할 수 있어요. 이 저장소의 Releases에서 받은 파일이면 허용해도 돼요.

### 1.3 Mac에서 처음 열 때

Apple 개발자 서명과 공증을 하지 않아서, macOS가 처음 한 번 막아요.

1. `.dmg`를 열고 **TICKER**를 **응용 프로그램(Applications)** 폴더로 끌어 놓아요. dmg 안에서 바로 실행하지 말아요.
2. 응용 프로그램 폴더에서 TICKER를 열면 "Apple은 'TICKER'에 … 악성 코드가 없음을 확인할 수 없습니다"(확인되지 않은 개발자) 경고가 떠요. **완료**(또는 **취소**)를 눌러 닫아요.
3. **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래쪽의 "TICKER이(가) 차단되었습니다" 옆 **그래도 열기**를 눌러요. 암호(또는 Touch ID)를 넣고, 다시 뜨는 창에서 **열기**를 눌러요.
   - macOS 15(Sequoia)부터는 Finder에서 오른쪽 클릭 → 열기로는 넘어가지 않아요. 꼭 시스템 설정에서 허용해요.
4. "'TICKER'이(가) 손상되었기 때문에 열 수 없습니다"가 뜨면, **터미널** 앱에서 아래를 실행한 뒤 다시 열어요. 인터넷에서 받은 파일에 붙는 격리 표시를 지우는 명령이에요.

   ```
   xattr -cr /Applications/TICKER.app
   ```

5. 한국투자증권 키를 처음 저장할 때 "TICKER이(가) 키체인에 있는 … 을 사용하려고 합니다" 창이 뜨면 로그인 암호를 넣고 **항상 허용**을 눌러요. 키는 Mac의 키체인으로 암호화해서 저장해요.
6. 새 버전을 설치하면(응용 프로그램 폴더에 덮어쓰기) 2~3번을 한 번 더 해야 할 수 있어요. 설정·키·화면 배치는 그대로 남아요.

주의할 것

- Mac 버전은 아직 실제 Mac에서 확인하지 못했어요. 이상한 점이 있으면 알려 주세요.
- 창을 닫으면 앱이 끝나요(Mac 앱의 관례와 달리 Dock에 남지 않아요).
- **제거**: 응용 프로그램 폴더의 TICKER를 휴지통으로 옮겨요. 설정·키까지 지우려면 `~/Library/Application Support/TICKER` 폴더도 지우고, 키체인 접근 앱에서 TICKER 항목을 지워요.

### 1.4 공통 주의사항

- **자동 업데이트는 없어요.** 새 버전은 Releases에서 받아 덮어 설치해요. 앱의 버전은 **설정 → 정보**에서 볼 수 있어요.
- **한국투자증권 키가 없으면** 주식·지수는 `데모` 표시가 붙은 가짜 시세로 보여요. 코인(Binance)과 환율은 키 없이도 실제 값이에요. 키 넣는 법은 [2장](#2-한국투자증권-키-넣기와-데이터-출처)에 있어요.
- **인터넷이 필요해요.** 시세는 인터넷으로 받아요. 처음 켤 때 인터넷이 없어도 앱에 들어 있는 종목 목록 사본으로 종목 검색은 돼요.
- **앱을 끄면 시세 수집도 멈춰요.** 꺼져 있던 동안의 시세는 데이터 출처가 과거 값을 주는 범위에서만 다시 채워요.
- **같은 앱을 두 번 켜면** 새로 켜지 않고 이미 켜진 창을 앞으로 가져와요.
- **나 혼자 쓰는 앱이에요.** 받은 시세를 다른 사람에게 보여 주거나 다시 배포하지 않아요(데이터 출처의 이용 조건).
- 예전 이름(Terminal)으로 설치했었다면, TICKER를 처음 켤 때 설정·키·화면 배치를 자동으로 옮겨 와요. 확인한 뒤 예전 Terminal 앱과 폴더는 지워도 돼요.

### 1.5 데이터 폴더

설정, 한국투자증권·DART 키(암호화), 화면 배치, 명령 기록, 분봉·이력(SQLite `history.db`), 뉴스 아카이브(`news.db`, v0.2), 서버 기록(`logs/server.log`)이 여기에 저장돼요. 덮어 설치해도 지워지지 않아요. 서버 기록에는 앱키 끝 4자리만 남고, 앱시크릿·토큰은 남지 않아요.

| 컴퓨터 | 데이터 폴더 | 설치 폴더 |
|---|---|---|
| Windows | `%APPDATA%\TICKER` | `%LOCALAPPDATA%\Programs\TICKER` (설치형) |
| Mac | `~/Library/Application Support/TICKER` | `/Applications/TICKER.app` |

### 1.6 처음 켜면 보이는 것

처음 켜면 **Market Pulse** 화면에 7개 패널로 된 기본 배치가 열려요.

```
┌ 1 MON 관심종목 ─┬ 2 GP 가격 차트(삼성전자) ┬ 3 WEI 세계 지수 ─┐
│ 국내·미국·      │                          ├ 6 FXC 환율 매트릭스 ┤
│ 코인·환율·지수  │                          │                  │
├ 4 N 뉴스·공시 ──┼ 5 HMAP 업종 히트맵(코스피) ┼ 7 CRYP 코인 시세판 ┤
└────────────────┴──────────────────────────┴──────────────────┘
 시세 흐름 띠
 상태 표시줄
```

- 1·2번 패널은 같은 **파랑 연동 그룹**이에요. 1번 관심종목에서 종목을 누르면 2번 차트가 그 종목으로 바뀌어요.
- 4번 N(전체 뉴스)과 5번 HMAP(코스피 업종)은 연동 그룹 없이 시작해요. v0.1에서 쓰던 배치(4번 두 번째 관심종목, 5번 장중 차트)를 저장해 두었다면 그대로 열려요. 새 배치를 보려면 워크스페이스 메뉴의 **기본 배치로 새로 시작**을 눌러요.
- 2번 패널의 커맨드 라인을 눌러 `AAPL US`를 치고 Enter를 눌러 보세요. 애플 차트로 바뀌어요. 커맨드 라인은 [7장](#7-커맨드-라인-쓰는-법)에서 자세히 설명해요.
- 커맨드 라인에 `?`를 치고 Enter를 누르면 명령 문법 요약이 떠요.

## 2. 한국투자증권 키 넣기와 데이터 출처

### 2.1 데이터 출처

| 대상 | 출처 | 키 | 속도 |
|---|---|---|---|
| 국내·미국 주식, 국내 지수, 해외 지수 | 한국투자증권 Open API | 필요 | 화면에 보이고 장이 열린 종목은 실시간, 넘치는 종목은 몇 초 간격 조회. 해외 지수는 1분 간격 조회. 장이 닫힌 종목은 5분마다 마감 값을 확인 |
| 코인 | Binance (USDT 현물 공개 시세) | 필요 없음 | 실시간 |
| 환율 | 한국투자증권 Open API(키가 있을 때), 없으면 ECB 기준환율(Frankfurter) | 한국투자증권 키(없으면 필요 없음) | 키가 있으면 10초마다(`10초 주기` 배지), 없으면 하루 한 번 발표(`일별` 배지). 환율 차트의 봉도 키가 있으면 한국투자증권(약 14개월), 없으면 ECB(2년) |
| 종목 개요(DES)의 업종·상장일·매출액·영업이익·ROE | 한국투자증권 종목 마스터(국내만) | 필요 없음 | 하루 한 번 |
| 종목 개요(DES)의 PER·PBR·52주 고저 | 한국투자증권 Open API(주식현재가 시세, 해외주식 현재가상세) | 필요 | 패널이 열려 있는 동안 60초마다 |
| 뉴스 헤드라인(N) | RSS: 한국경제(증권·경제), 서울경제, 전자신문, MarketWatch(톱·마켓펄스), Investing.com | 필요 없음 | 5분마다 |
| 공시(N) | DART 전자공시(OpenDART) | DART 인증키(무료) | 2분마다(오늘 공시), 종목을 열면 그 회사의 지난 1년 |
| 키가 없을 때 주식·지수 | 앱이 만든 데모 시세 | — | `데모` 배지 |

- Binance 일반 주소가 막힌 지역이나 네트워크에서는 시세 전용 주소(data-api·data-stream.binance.vision)로 저절로 바꿔 연결해요.
- 키가 없을 때 쓰는 ECB 기준환율은 하루 한 번 발표라 장중에 움직이지 않아요. 환율의 장중 차트(GIP)는 없어요.

### 2.2 한국투자증권 키 넣기

1. 한국투자증권 홈페이지에서 Open API를 신청하고 **앱키(App Key)** 와 **앱시크릿(App Secret)** 을 받아요. 시세용으로는 **잔고가 없는 별도 계좌**의 키를 권해요. 이 앱은 매매 기능이 없지만, 키가 새어 나가도 피해가 없게 하려는 거예요.
2. 앱에서 **설정**(`Ctrl+,`, Mac `⌘,`) → **데이터 연결**로 가요.
3. 앱키와 앱시크릿을 넣고, 서버를 **실전** 또는 **모의**(모의투자 계좌의 키) 중에서 골라요.
4. **저장하고 연결 테스트**를 눌러요. 성공하면 `연결됐어요 · 삼성전자 현재가 …원`이 뜨고, 상태 표시줄에 `한국투자증권 실시간 n/40`이 보이고, 주식·지수의 `데모` 배지가 사라져요.
   - 실패하면 어느 단계에서 막혔는지(`토큰 받기`, `삼성전자 현재가 조회`)와 한국투자증권의 오류 내용(예: `EGW00103 유효하지 않은 AppKey`)을 함께 보여 줘요. 한국투자증권이 25초 동안 답하지 않아도 실패로 알려 줘요.
   - 접근 토큰은 1분에 한 번만 받을 수 있어요. 방금 받았다는 오류가 나오면 1분 뒤 **다시 테스트**를 눌러요.

알아 둘 것

- 키는 운영체제의 보안 저장소(Windows DPAPI, Mac 키체인)로 암호화해서 데이터 폴더에 저장해요. 저장한 뒤에는 화면에 다시 보여 주지 않아요. 바꿀 때만 새로 입력해요.
- **키 지우기**를 누르면 저장된 키를 지우고 데모 시세로 돌아가요.
- 받은 접근 토큰(24시간)은 저장해 두고 다시 써요. 그래서 앱을 여러 번 껐다 켜도 하루에 한 번만 받아요. 앱키를 바꾸거나 실전·모의를 바꾸면 새로 받아요.
- 한국투자증권은 토큰을 발급할 때마다 **카카오 알림톡**을 보내요. 알림톡이 하루에 여러 번 오면 진단 정보를 보내 주세요.
- 키는 채팅·메일·저장소 등 어디에도 붙여 넣지 말아요.
- 한국투자증권의 제한: **실시간 구독은 약 40개**, **조회는 초당 약 20건**까지예요. 앱은 화면에 보이는 종목부터 실시간으로 받고, 넘치는 종목은 몇 초 간격 조회로 바꿔요. 조회는 여유를 두고 초당 15건부터 보내고, 한국투자증권이 초과라고 답하면(`EGW00201`) 스스로 줄였다가 조용하면 천천히 되돌려요.
- **장이 닫힌 종목은 실시간 구독을 쓰지 않아요.** 국내 장이 끝난 밤에는 국내 주식이 5분마다 마감 값만 확인하고(`마감` 배지), 그 자리는 장이 열린 미국 주식이 써요. 국내 주식은 장 시작 전(08:30)부터, 미국 주식은 프리·애프터마켓에도 실시간으로 받아요. 장이 열리고 닫히면 30초 안에 저절로 바꿔요.
- 한국투자증권이 실시간 구독을 거절하면(`MAX SUBSCRIBE OVER`) 그 종목은 몇 초 간격 조회로 받고(`3초 주기` 같은 배지), 잠시 뒤 다시 구독해 봐요. 상태 표시줄의 한국투자증권에 마우스를 올리면 거절된 수가 보여요. 지금 쓰는 양은 설정 → 데이터 연결의 **실시간 슬롯**과 **조회 호출**, 그리고 상태 표시줄의 `한국투자증권 실시간 n/40`에서 볼 수 있어요.
- 슬롯은 국내·미국 주식의 체결만 써요. 기능을 열 때 슬롯이 모자라면 몇 초 간격 조회로 바뀐다고 알려 줘요. **기능별 실시간 슬롯** 표와 기능 설명 창(F1)에도 슬롯 수가 보여요.

## 3. 화면 둘러보기

```
┌ 맨 위 줄: TICKER · 화면 탭 · 패널 추가 · 워크스페이스 ▾ · 날짜 · 세계 시계 ┐
│ 패널들 (화면 탭마다 따로)                                               │
│ 시세 흐름 띠                                                           │
└ 상태 표시줄 ───────────────────────────────────────────────────────────┘
```

### 3.1 맨 위 줄

| 요소 | 하는 일 |
|---|---|
| **TICKER** 로고 | 앱 이름 |
| **화면 탭** (Market Pulse, 화면 2 …) | 누르면 그 화면의 패널 배치로 바뀌어요. 두 번 누르면 이름 바꾸기(Enter 확정, Esc 취소). ↗ 떼어내기, ✕ 닫기. `+`로 새 화면 탭 추가 ([4.1](#41-화면-탭)) |
| **패널 추가** | 지금 화면의 활성 패널 오른쪽에 빈 패널을 추가해요 |
| **워크스페이스 ▾** | 지금 배치를 이름 붙여 저장·불러오기·덮어쓰기·지우기, 기본 배치로 새로 시작 ([4.5](#45-워크스페이스-저장불러오기)) |
| 날짜와 세계 시계 | 서울(초까지)·도쿄·런던·뉴욕 시각과 장 상태(`장중`은 강조 색, `개장전`·`시간외`·`마감`은 회색) |

### 3.2 패널

패널 하나는 세 부분이에요.

```
┌ 2 │ 005930 KS EQUITY GP              ■ ↗ □ ✕ ┐  ← 1줄
│ GP 가격 차트 · 삼성전자 005930 KS   [배지] 도구 │  ← 2줄(제목 줄)
│ 본문 (차트·표)                                │
└──────────────────────────────────────────────┘
```

**1줄**

| 요소 | 하는 일 |
|---|---|
| 패널 번호 | 패널마다 붙는 번호(1, 2, 3 …). 끌기 손잡이이기도 해요. 끌어서 다른 자리로 옮기거나 다른 패널 위에 놓아 창 안 탭으로 묶어요. `Ctrl+숫자`(Mac `⌘숫자`)로 그 번호 패널로 가요 |
| 커맨드 라인 | 명령을 입력하는 칸. 지금 띄운 명령이 흐리게 보여요. 토큰(단어)에 마우스를 올리면 뜻(`GP = 가격 차트`, `KS = 코스피`)이 보이고, 누르면 그 토큰을 고칠 수 있게 줄에 넣어요 |
| `?` | 도움말 |
| ■ 연동 색 | 연동 그룹. 누를 때마다 파랑 → 보라 → 청록 → 없음으로 바뀌어요 ([4.4](#44-연동-그룹)) |
| ↗ | 이 패널(묶음)을 새 창으로 떼어내기 ([4.3](#43-새-창으로-떼어내기)) |
| □ | 최대화 / 원래 크기로 |
| ✕ | 패널 닫기. 되돌릴 수 없어요 |

**2줄(제목 줄)**: 기능 코드(주황), 기능 이름과 종목 이름·코드, 데이터 신선도 배지, 기능별 도구(차트의 일·주·월, 기간 버튼, 관심종목의 묶음 탭 등).

**본문**: 차트나 표. 패널 본문을 누르거나 `F6`을 누르면 본문에 주황 안쪽 테두리가 생기고, 키보드가 본문으로 가요([7.11](#711-포커스-커맨드-라인과-패널-본문)).

### 3.3 시세 흐름 띠

화면 아래쪽에 코스피·코스닥·S&P 500·나스닥 종합·닛케이·항셍·DAX, 원달러·원엔·원유로, BTC·ETH·XRP·SOL이 흘러가요. 실시간이 아닌 항목에는 짧은 신선도 배지가 붙어요.

### 3.4 상태 표시줄

| 요소 | 뜻 |
|---|---|
| `데모 시세` | 한국투자증권 키가 없어서 주식·지수가 가짜 값일 때 늘 보여요. 누르면 설정의 데이터 연결이 열려요 |
| 연결 상태 | 한국투자증권(실시간 구독 수 `n/40`), Binance, 환율(`… 마다 확인`). **초록 점** = 연결됨, **빈 점 + ⚠** = 끊김·멈춤, **회색 점** = 데모 |
| 종목 수 | 검색할 수 있는 종목 수. 첫 실행용 사본을 쓰는 중이면 그 날짜도 보여요. 목록을 받는 중이면 `종목 목록 불러오는 중…` |
| 연동 그룹 | 그룹마다 지금 종목 |
| `도움: 입문 ▾` | 자동완성 도움 수준을 바로 바꿔요 ([7.6](#76-도움-수준-입문표준전문가끔)) |
| 단축키 안내 | `명령 팔레트 Ctrl+K`, `설정 Ctrl+,` (바꾼 키로 보여요) |
| `도움말 ?` | 도움말 열기 |
| `⚠ 내장 서버 연결 끊김 · 다시 연결 중` | 앱 안의 서버와 연결이 끊겼을 때. 저절로 다시 연결해요 |
| `⚠ 내장 서버 응답 없음` | 앱 안의 서버가 15초 넘게 아무것도 보내지 않을 때. 시세가 멈춰 있다는 뜻이라 연결 점도 모두 ⚠로 바뀌어요. 설정 → 정보 → **진단 정보 복사**로 상태를 보내 주세요 |

## 4. 화면 탭·패널·창 다루기

### 4.1 화면 탭

화면 탭 하나가 패널 배치 하나예요. 예: "Market Pulse"는 시장 전체, "Deep Dive"는 종목 하나를 깊게 보는 배치.

- **추가**: 화면 탭 끝의 `+`. 빈 화면이 생기고, 가운데의 **패널 추가**로 패널을 넣어요.
- **이름 바꾸기**: 탭을 두 번 눌러요. Enter로 확정, Esc로 취소.
- **닫기**: 탭 오른쪽의 `✕`. 안의 패널(그 화면에서 떼어낸 창 포함)도 함께 닫혀요. 바로 뜨는 알림의 **되돌리기**로 배치까지 그대로 복구해요. 탭이 하나뿐이면 `✕`가 없어요.
- **떼어내기**: 탭 이름 오른쪽의 ↗ 버튼. [4.3](#43-새-창으로-떼어내기)을 보세요.

### 4.2 패널 다루기

| 하고 싶은 것 | 방법 |
|---|---|
| 패널 추가 | 맨 위 줄의 **패널 추가**. 활성 패널 오른쪽에 빈 패널이 생겨요. 빈 화면이면 가운데의 **패널 추가** |
| 기능 바꾸기 | 그 패널의 커맨드 라인에 명령을 넣고 Enter (예: `WEI⏎`, `005930 GP⏎`) |
| 옮기기 | 패널 번호 칸을 끌어서 원하는 자리(위·아래·왼쪽·오른쪽 가장자리)에 놓아요 |
| 창 안 탭으로 묶기 | 번호 칸을 끌어 다른 패널 한가운데에 놓아요. 한 자리에서 번호 탭으로 바꿔 봐요 |
| 크기 조절 | 패널 사이 경계선을 끌어요 |
| 최대화 | 1줄의 □. 다시 누르면 원래 크기 |
| 닫기 | 1줄의 ✕ (되돌릴 수 없어요) |
| 뒤로·앞으로 | `Alt+←` / `Alt+→` (Mac `⌘[` / `⌘]`). 그 패널에서 본 기능·종목을 오가요 |
| 다른 패널로 | `Ctrl+Tab` / `Ctrl+Shift+Tab`(다음·이전), `Ctrl+1…9`(Mac `⌘1…9`, 그 번호 패널) |
| 전체 화면 | `F11`(Mac `⌃⌘F`). 그 창만 ([4.6](#46-전체-화면)) |

### 4.3 새 창으로 떼어내기

두 가지 방법이 있어요. 둘 다 다른 모니터로 옮겨 쓰려는 거예요.

**패널 떼어내기** (패널 1줄의 ↗)

- 그 패널(창 안 탭으로 묶인 묶음)이 새 창이 돼요.
- 새 창의 닫기(X)를 누르면 패널이 메인 창의 원래 자리로 돌아와요. 패널을 없애려면 패널의 ✕를 눌러요.

**화면 탭 떼어내기** (화면 탭 이름 옆의 ↗)

- 그 화면이 **패널 배치째로** 새 창이 돼요. 새 창의 맨 위 줄에는 로고, 화면 이름, **패널 추가**, **메인 창으로 돌려놓기**가 있어요.
- 새 창 안에서도 패널을 끌어 옮기고, 크기를 바꾸고, 패널 하나를 다시 떼어낼 수 있어요.
- 메인 창의 화면 탭에는 떼어낸 화면이 흐린 기울임 글씨와 ↗ 표시로 남아요. 그 탭을 누르면 떼어낸 창을 앞으로 가져와요.
- **돌려놓기**: 떼어낸 창의 **메인 창으로 돌려놓기**, 메인 창 탭 옆의 ↙ 버튼, 또는 떼어낸 창의 닫기(X). 어느 쪽이든 그 화면이 메인 창의 화면 탭으로 돌아와요.
- 메인 창에는 화면이 하나 이상 남아야 해요. 그래서 메인 창에 남은 마지막 화면에는 ↗와 ✕가 없어요. 화면 탭을 하나 더 만들면 떼어낼 수 있어요.
- 떼어낸 창의 위치와 크기를 기억해요. 떼어낸 채로 앱을 끄면 다음에 켤 때 같은 자리에 다시 열려요.
- 떼어낸 창에서 연 명령 팔레트(`Ctrl+K`)와 도움말은 그 창 안에 떠요. 설정 창은 메인 창에 뜨고, 메인 창을 앞으로 가져와요.
- 떼어낸 창 안에 화면 탭을 여러 개 두는 것은 v0.2에서 제공 예정이에요.

공통

- 떼어낸 창도 같은 앱 안의 창이라 시세·종목 목록·설정·연동 그룹을 메인 창과 함께 써요. 떼어낸 창의 관심종목을 누르면 메인 창의 같은 색 패널도 바뀌어요.
- **메인 창을 닫으면** 떼어낸 창까지 모두 닫히고 앱이 끝나요.
- 글자 크기 설정은 떼어낸 창에도 똑같이 걸려요.

### 4.4 연동 그룹

- 패널 1줄의 ■ 색이 연동 그룹이에요. 파랑·보라·청록 세 가지와 없음이 있어요.
- **같은 색 패널끼리는 종목이 함께 바뀌어요.** 한 패널에서 종목을 바꾸면(커맨드 라인에 종목 입력, 관심종목·세계 지수·코인 시세판의 줄 누르기) 같은 색의 다른 패널도 그 종목을 보여 줘요.
- 기능 변경은 퍼지지 않아요. 2번에서 GIP로 바꿔도 5번은 그대로예요.
- 떼어낸 창의 패널도 같은 그룹으로 이어져요.
- 상태 표시줄에 그룹마다 지금 종목이 보여요.

### 4.5 워크스페이스 저장·불러오기

**워크스페이스**는 모든 화면 탭, 그 안의 패널 배치, 떼어낸 창, 패널마다의 기능·종목·연동 색을 묶은 것이에요.

- **자동 저장**: 배치를 바꿀 때마다 저장되고, 다음 실행 때 그대로 복원돼요(설정 → 일반 → 시작할 때 마지막 배치 복원).
- 맨 위 줄 **워크스페이스 ▾** 메뉴. 커맨드 라인에 `BLP⏎`(블룸버그 런치패드)를 쳐도 이 메뉴가 열려요(v0.2).
  - **지금 배치 저장**: 이름을 넣고 저장. 같은 이름이 있으면 **덮어쓰기**로 바뀌어요.
  - 저장한 이름을 누르면 **불러오기**. 줄 오른쪽의 **덮어쓰기**(지금 배치로), **✕**(지우기).
  - **기본 배치로 새로 시작**: 처음 배치(1.6)로 돌아가요.
  - 불러오기·지우기·새로 시작은 바로 뜨는 알림의 **되돌리기**로 바로 전으로 돌아가요.
- 버튼에는 지금 불러온 워크스페이스 이름이 보여요(없으면 `저장 안 함`).

### 4.6 전체 화면

- **Windows: `F11`**, **Mac: `⌃⌘F`**(Control+Command+F) 또는 창 왼쪽 위의 초록 버튼으로 전체 화면을 켜요. 같은 키를 한 번 더 누르면 원래대로 돌아와요.
- 키를 누른 **그 창만** 전체 화면이 돼요. 메인 창과 떼어낸 창(패널 창·화면 창)을 모니터마다 따로 전체 화면으로 쓸 수 있어요.
- 메인 창이 전체 화면이 되면 `전체 화면이에요 · F11로 나가요` 알림이 잠깐 떠요.
- Mac에서 `F11`은 바탕 화면 보기(시스템 키)라서 `⌃⌘F`를 써요.
- 키는 설정 → 단축키의 **전체 화면**에서 바꿀 수 있어요.
- 전체 화면 상태는 다음 실행 때 복원하지 않아요. 창은 전체 화면 전의 크기와 위치로 열려요.

## 5. 데이터 신선도 배지

**배지가 없으면 실시간이에요.** 실시간이 아닌 값에는 빠짐없이 회색 배지가 붙어요. 늦은 값을 실시간으로 착각하지 않게 하려는 거라 끌 수 없어요.

| 상태 | 제목 줄·차트의 배지 | 표의 행·흐름 띠 | 언제 |
|---|---|---|---|
| 실시간 | 없음 | 없음 | 체결·시세가 오는 대로 바뀌어요 (한국투자증권 실시간, Binance) |
| 주기 조회 | `5초 주기` | `5초` | 정해진 간격으로 다시 받아요 (실시간 슬롯 밖의 종목, 해외 지수) |
| 지연 | `15분 지연` | `지연` | 출처가 늦게 줘요 |
| 일별 | `일별 10/21` | `일별` | 하루 한 번 받아요. 날짜는 출처의 기준일 (환율) |
| 장 마감 | `마감 15:30`, `마감 10/30` | `마감` | 장이 끝났어요. 값은 마지막 체결가(종가)이고, 시각은 그 장이 끝난 때예요 |
| 멈춤 | `⚠ 멈춤 14:03` | `⚠` | 받아야 할 때 새 값을 받지 못했어요. 시각은 마지막으로 받은 때. 반전 색으로 눈에 띄게 보여요 |
| 데모 | `데모` | `데모` | 실제 시세가 아닌 가짜 값 (한국투자증권 키 없음) |

- 배지에 마우스를 올리거나 누르면 출처, 기준 시각, 받는 방식 같은 자세한 내용이 보여요.
- 배지의 시각은 한국 시간이에요. 오늘이면 시각, 다른 날이면 날짜, 1년이 넘으면 연도까지 적어요.
- 한 패널의 값이 섞여 있으면(관심종목 등) 제목 줄에는 가장 늦은 상태를, 행마다 짧은 배지를 붙여요.

### 6.1 MON 관심종목

내가 고른 종목의 시세를 묶음별로 모아 봐요.

- 처음 묶음: **국내**(삼성전자, SK하이닉스 등 8개), **미국**(애플, 엔비디아 등 8개), **코인**(BTC, ETH 등 6개), **환율·지수**(원달러, 코스피, S&P 500 등 7개). 기본 배치의 1번 패널은 국내·미국, 4번 패널은 코인·환율·지수를 보여요.
- 제목 줄의 **전체 / 묶음 이름** 탭으로 묶음 하나만 볼 수 있어요. 고른 탭은 패널마다 기억해요(화면을 떼어냈다 돌려놓거나 앱을 다시 켜도 그대로).
- 열: 종목, 현재가, 등락(▲▼와 등락률), 신선도 배지, 추세(작은 선 그래프). 패널이 좁으면 추세 열부터 숨겨요.
- **줄 누르기**: 그 종목을 고르고, 같은 연동 색 패널(차트 등)이 그 종목으로 바뀌어요.
- **종목 추가**: 묶음 머리줄 오른쪽의 `+` → `종목코드·이름 (Enter로 추가, Esc 닫기)` 칸에 코드나 이름을 넣고 Enter.
- **종목 빼기**: 패널 본문에 포커스를 두고(본문 누르기 또는 `F6`) 줄을 고른 뒤 **Delete**.
- **키보드로 고르기**: 본문 포커스에서 `↑` `↓`.
- 관심종목 목록은 모든 MON 패널이 함께 써요. 한 패널에서 추가하면 다른 패널의 같은 묶음에도 보여요.
- 값이 바뀌면 칸이 0.3초 동안 등락 색으로 반짝여요.

### 6.2 GP 가격 차트

- 캔들(봉) 차트, 아래쪽 거래량, 이동평균선(**20봉 주황**, **60봉 회색**. 일봉이면 20일·60일).
- 제목 줄 도구: **1시간 / 2시간 / 4시간 / 일 / 주 / 월**(봉 크기), **1M / 3M / 6M / 1Y / MAX**(보이는 기간, 일봉은 처음 3M, 시간봉은 처음 1M). 고른 봉 크기와 기간은 패널마다 기억해요(시간봉의 기간은 따로).
- **시간봉**(주식·코인): 지난 날까지 이어서 1·2·4시간 단위로 보여 주고, 가로축에 시각이 붙어요.
  - 칸은 정규장 시작에 맞춰요. 국내 1시간봉은 09·10·…·15시(15시 칸은 15:00~15:30), 2시간봉은 09·11·13·15시, 4시간봉은 09·13시예요. 미국은 뉴욕 정각부터(한국투자증권 60분봉이 정각에 와요. 4시간봉은 뉴욕 09·13·17시), 코인은 UTC 정각(한국 09·13·17·21·01·05시)부터예요.
  - 처음 열면 국내는 최근 5거래일, 미국은 약 240시간, 코인은 약 41일을 바로 보여 줘요. 그 앞(1년까지)은 앱이 뒤에서 조금씩 받아 저장하고, 차트는 1분마다 새로 받아서 지난 봉이 점점 이어져요. 한 번 받은 날은 다시 받지 않아요.
  - 국내 시간봉은 한국투자증권이 1분봉만 줘서 1분봉을 받아 묶어요. 하루치에 약 4번 조회라, 1년치를 다 채우는 데 몇 분 걸려요(화면의 시세 조회가 먼저예요).
  - 정규장 봉만 그려요. 미국 시간봉도 정규장과 겹치는 칸만(09시 칸은 09:30부터 정규장) 보여 줘요. 애프터마켓의 몇 주짜리 체결이 현재가처럼 보이지 않게 하려는 거예요.
  - 국내 15시 칸의 종가는 그날 종가(15:30 마감 동시호가)예요. 한국투자증권 분봉에는 15:20 뒤 체결이 없어서 앱이 일봉의 종가로 채워요.
  - 지수와 환율은 시간봉이 없어서 버튼이 안 보여요.
- 차트 왼쪽 위에 마우스가 가리키는 봉의 시가·고가·저가·종가와 신선도 배지.
- 마우스 휠로 확대·축소, 끌어서 앞뒤로 이동해요. 가격 축(오른쪽 숫자)을 위아래로 끌면 세로 배율이 바뀌어요.
- **종목을 바꾸면** 지금 배율 그대로 가장 최근 봉으로 가고, 가격 축은 새 종목의 가격에 다시 맞춰요. 한 번 맞춘 배율을 종목마다 다시 맞출 필요가 없어요. 새 종목의 봉이 올 때까지는 앞 종목의 차트와 가격 축을 지우고 `불러오는 중…`을 보여 줘요.
- **같은 기간 버튼을 다시 누르면** 그 기간의 처음 보기(최근 봉이 오른쪽 끝)로 돌아가요.
- 이동평균선은 가격 축을 맞출 때 빼요. 그래서 이동평균선이 현재가에서 멀리 있으면 차트 밖으로 나갈 수 있어요.
- 블룸버그 별칭: `GPO`(바 차트), `GPC`(캔들 차트)를 쳐도 GP가 열려요. ⏎ 라벨에 `GPO → GP`처럼 보여 줘요.
- 예: `005930 GP⏎`, `AAPL US GP⏎`, `BTC GP⏎`, `USDKRW GP⏎`, `KOSPI GP⏎`

### 6.3 GIP 장중 차트

- **1분봉** 차트예요. 실시간 움직임을 보는 기능이라 봉 크기는 고르지 않아요. 1시간봉 같은 큰 봉과 지난 흐름은 GP에서 봐요([6.2](#62-gp-가격-차트)).
- 받은 분봉은 데이터 폴더의 `history.db`에 쌓아 두고(최근 30일) 다음에 다시 써요.
- 제목 줄 도구: `1분봉` 표시와 **1H / 4H / 1D / MAX**(보이는 기간, 처음은 4H). `1H`는 1시간봉이 아니라 '최근 1시간'이라는 뜻이에요.
- **1D**는 가장 최근 장 전체(코인처럼 24시간 열리는 시장은 최근 24시간), **MAX**는 받아 둔 분봉 전체예요. 고른 기간은 패널마다 기억해요.
- 확대·축소, 종목을 바꿀 때, 같은 버튼을 다시 누를 때의 동작은 GP와 같아요.
- **정규장 봉만** 그려요(국내 09:00~15:30, 미국 주식은 프리·애프터마켓 포함, 코인은 24시간). 장이 닫힌 뒤에는 가장 최근 장의 분봉을 보여 줘요. 아직 분봉이 없으면 `아직 장중 분봉이 없어요`가 떠요.
- 국내 주식은 15:20~15:30 마감 동시호가 동안 봉이 생기지 않아요(체결이 없어요). 장이 끝나면 15:30 봉을 그날 종가와 동시호가 거래량으로 채워요.
- 환율은 하루 한 번 발표되는 기준환율이라 분봉이 없어서 GIP를 쓸 수 없어요.
- 예: `005930 GIP⏎`, `AAPL US GIP⏎`, `BTC GIP⏎`

### 6.4 WEI 세계 지수

- 지역별(한국, 미주, 유럽, 아시아) 주요 지수: 현재, 변동, 변동률, 시간(장 상태와 신선도), 추세.
- 줄을 누르면 그 지수를 고르고, 같은 연동 색 패널이 그 지수로 바뀌어요.
- 해외 지수는 1분마다, 장이 닫힌 지수는 5분마다 확인해요. 장이 닫혔으면 시간 칸에 `마감`만 보여요.
- 값을 받지 못한 지수는 0 대신 `—`로 비워 둬요. **다우존스**는 한국투자증권이 장중 값을 주지 않아서 가장 최근 일봉의 종가를 보여 줘요(`일별` 배지).
- 장중인데 15분 넘게 값이 그대로인 지수(지금은 프랑스 CAC 40에서 봤어요)는 한국투자증권이 장중에 갱신하지 않는 것으로 보고 `일별` 배지를 붙여요.
- 들어 있는 지수: 코스피(KOSPI), 코스닥(KOSDAQ), 코스피200(KOSPI2), S&P 500(SPX), 다우존스(INDU), 나스닥 종합(CCMP), 나스닥 100(NDX), 필라델피아 반도체(SOX), FTSE 100(UKX), 독일 DAX(DAX), 프랑스 CAC 40(CAC), 유로스톡스 50(SX5E), 니케이 225(NKY), 항셍(HSI), 상하이 종합(SHCOMP), 대만 가권(TWSE).

### 6.5 FXC 환율 매트릭스

- USD, EUR, JPY, GBP, CNY, AUD, KRW 일곱 통화 사이의 환율 표예요.
- **칸 하나 = 행 통화 1단위가 열 통화로 얼마인지**예요. 예: USD 행 · JPY 열 = 1달러가 몇 엔인지.
- 한국투자증권 키가 있으면 10초마다 받아요(`10초 주기` 배지). 키가 없거나 1분 넘게 받지 못하면 ECB 기준환율로 돌아가고 `일별` 배지가 붙어요. 표 아래에 지금 출처를 적어요.
- 원화 외환시장은 다음 날 02:00까지 열려요. 기준 시각은 배지에 마우스를 올려 확인해요.
- 환율 차트(`USDKRW GP` 등)도 키가 있으면 한국투자증권 일봉이라 마지막 봉이 지금 환율과 이어져요. 원/달러·달러/엔처럼 달러가 한쪽인 환율은 캔들, 원/유로 같은 교차 환율은 선으로 그려요.
- 별칭: `WCR`을 쳐도 FXC가 열려요.

### 6.6 CRYP 코인 시세판

- Binance USDT 현물에서 거래가 많은 코인 40개: 코인, 현재가(USDT), 24시간 등락, 거래대금, 24시간 범위(저가~고가 막대와 현재 위치).
- 실시간이에요(배지 없음).
- 줄을 누르면 그 코인을 고르고, 같은 연동 색 패널이 그 코인으로 바뀌어요.

### 6.7 DES 종목 개요 (v0.2)

주식 한 종목의 기본 정보를 한 화면에 모아 봐요. 예: `005930 DES⏎`, `AAPL US DES⏎`. 별칭 `ISSD`도 돼요.

- **맨 위**: 이름, 코드·시장, 현재가와 등락(실시간 시세와 같아요), 업종, 52주 최저·최고(날짜)와 지금 자리를 보여 주는 막대. 관리종목·투자주의·투자경고·거래정지 같은 상태가 있으면 빨간 글씨로 붙어요.
- **가치**: 시가총액, 상장주식수, PER, PBR, EPS, BPS. 한국투자증권 키가 있어야 보이고, 패널이 열려 있는 동안 60초마다 다시 받아요. 시가총액은 지금 가격 × 상장주식수로 다시 계산해서 시세와 함께 움직여요.
- **거래**: 거래량, 거래대금. 국내 종목은 외국인 소진율과 거래량 회전율, 미국 종목은 원화 환산가.
- **실적**(국내만): 매출액, 영업이익, 영업이익률, ROE. 한국투자증권 종목 마스터의 값이라 키가 없어도 보여요. 묶음 제목에 기준 월(예: `기준 2026-06`)을 적어요.
- **기본 정보**: 업종(국내는 `제조 > 전기·전자`처럼 KRX 업종 대분류 > 중분류), 상장일(국내), 액면가, 결산월(국내), 통화.
- 묶음 제목 오른쪽에 그 묶음의 출처를 적어요(`한국투자증권 · 60초마다`, `종목 마스터 · 2026-11-03`).
- 키가 없으면 실적·기본 정보만 보이고, 아래에 `한국투자증권 키를 넣으면 PER·PBR·52주 고저도 보여요`라고 알려 줘요.
- 주식이 아닌 종목(코인·환율·지수)에서는 쓸 수 없어요.

### 6.8 MOST 상위 종목 (v0.2)

시장 하나의 거래량·거래대금·상승률·하락률 상위 30종목을 봐요. 기능 뒤에 시장을 붙여요.

| 입력 | 시장 |
|---|---|
| `MOST⏎` | 띄운 종목의 시장(없으면 코스피). 처음 정한 뒤에는 패널이 기억해요 |
| `MOST KS⏎`, `MOST 코스피⏎` | 코스피 |
| `MOST KQ⏎`, `MOST 코스닥⏎` | 코스닥 |
| `MOST US⏎` (`UW`·`UN` 등도 돼요) | 미국: 나스닥과 뉴욕 순위를 합쳐요 |
| `MOST CRYPTO⏎` | 코인: Binance USDT 현물 |

- `EQUITY⏎`(자산군 단어 하나만)도 MOST를 열어요.
- 제목 줄 오른쪽 버튼(코스피·코스닥·미국·코인)으로 시장을, 그 아래 탭(거래량·거래대금·상승률·하락률)으로 순위 종류를 바꿔요.
- 칸: 순위, 종목, 현재가, 등락률, 거래량, 거래대금. 좁은 패널에서는 거래량 칸을 숨겨요.
- 30초마다 다시 받아요(`30초 주기` 배지). 장이 닫혔으면 마감 값이라 `마감` 배지가 붙어요.
- 줄을 누르면 같은 연동 색 패널이 그 종목으로 바뀌어요. 종목 목록에 없는 종목은 누를 수 없어요.
- 국내·미국은 한국투자증권 키가 있어야 해요. 키가 없으면 `MOST CRYPTO`(코인)만 볼 수 있어요.
- 미국 상승률·하락률은 하루 거래량 1만 주 이상, 코인 상승률·하락률은 24시간 거래대금 100만 USDT 이상만 봐요. 코인은 종류마다 수량 단위가 달라서 거래량 순위도 USDT 거래대금 순으로 매겨요.
- 종목 MOST(미국 티커)를 보려면 `MOST US EQUITY`처럼 자산군까지 붙여요. 기능 바로 뒤의 시장 단어는 MOST의 시장으로 읽어요.

### 6.9 COMP 비교 차트 (v0.2)

기준 종목과 비교 종목들의 수익률을 한 차트에 겹쳐 봐요. 기간 시작을 0%로 맞춘 선이에요.

| 입력 | 결과 |
|---|---|
| `005930 COMP⏎` | 삼성전자와 코스피(대표 지수) |
| `005930 COMP 000660 KOSPI⏎` | 삼성전자(기준)와 SK하이닉스·코스피 |
| `COMP AAPL US MSFT US SPX⏎` | 애플(기준)과 마이크로소프트·S&P 500 |
| `BTC COMP ETH SOL⏎` | 비트코인(기준)과 이더리움·솔라나 |

- 첫 종목이 기준(강조 색 굵은 선), 기능 뒤의 종목이 비교 종목이에요. 비교 종목은 5개까지예요.
- 비교 종목을 안 붙이면 대표 지수와 비교해요: 코스피 종목은 코스피, 코스닥 종목은 코스닥, 미국 종목은 S&P 500, 코인은 비트코인(비트코인이면 이더리움), 지수는 S&P 500(S&P 500이면 코스피). 환율은 대표 지수가 없어서 비교 종목을 붙여야 해요.
- 미국 비교 종목은 `AAPL US`처럼 시장을 붙여도 돼요. 그 시장은 바로 앞 비교 종목의 것이에요. 비교 종목 칸에서도 자동완성 목록이 떠요.
- 기간 버튼: 1M, 3M, 6M, YTD(올해 1월 1일부터), 1Y(기본). 한쪽 데이터가 기간보다 짧으면 모두 그 날부터 함께 0%로 맞춰요.
- 위쪽 범례에 이름, 기간 수익률, 마지막 종가가 보여요. 비교 종목 옆 ✕로 비교에서 뺄 수 있어요.
- 일봉 종가로 그리고 1분마다 다시 받아요. 국내·미국 주식은 거래일이 달라서 서로 다른 날짜에 점이 찍혀요.
- 종목만 쳐서(`000660⏎`) 기준 종목을 바꾸면 비교 종목은 그대로예요. 연동 그룹으로 종목이 바뀔 때도 같아요.

### 6.10 N 뉴스·공시 (v0.2)

국내 공시(DART)와 국내외 뉴스 헤드라인을 최신순으로 봐요. 예: `뉴스⏎`, `005930 N⏎`, `AAPL US N⏎`.

- `N`은 한 글자라 줄 첫머리에서는 선택만 해요(Enter 한 번 더). `뉴스⏎`·`공시⏎`나 종목 뒤의 `N`(`005930 N⏎`)은 바로 실행돼요.
- 탭: 전체 · 공시 · 국내 뉴스 · 해외 뉴스. 줄을 누르면 원문(기사, DART 공시 뷰어)을 브라우저로 열어요. 15분 안의 새 줄은 밝은 굵은 글씨예요.
- 칸: 시각(오늘이면 시:분, 아니면 월/일), 출처(한경 증권·서경·MarketWatch…, 공시는 파란 `DART`), 제목(공시는 `[회사명]`이 앞에).
- **종목과 함께**: 국내 주식은 그 회사의 공시와 제목에 회사 이름이 들어간 헤드라인, 미국 주식·코인은 이름(한글 이름, 영문 이름, 3글자 이상 티커)이 들어간 헤드라인만 보여요. 지수·환율은 거르지 않아요. 제목 줄 오른쪽 버튼으로 그 종목만 / 전체를 바꿔요. 연동 그룹으로 종목이 바뀌면 함께 바뀌어요.
- **공시**는 DART 인증키가 있어야 보여요(설정 → 데이터 연결, [10.5](#105-데이터-연결)). 2분마다 오늘 공시 100건을 받고, 종목을 열면 그 회사의 지난 1년 공시를 받아요(10분에 한 번).
- **뉴스**는 키 없이 RSS 7곳에서 5분마다 받아요. 연합뉴스·매일경제·WSJ는 자동 요청을 막아서 넣지 않았어요.
- 받은 헤드라인과 공시는 앱이 켜져 있는 동안 데이터 폴더의 뉴스 아카이브(`news.db`)에 계속 쌓여요(제목·링크·시각만). v0.4의 뉴스 검색이 이 아카이브를 써요.
- 맨 아래에 RSS 몇 곳을 받았는지, DART가 켜졌는지, 아카이브에 쌓인 수가 보여요.

### 6.11 HMAP 업종 히트맵 (v0.2)

지수의 업종마다 기간별 등락을 색 칸으로 봐요. 예: `HMAP⏎`(코스피), `HMAP KOSDAQ⏎`, `HMAP KOSPI2⏎`(코스피200). `KS`·`KQ`·`코스닥`·`코스피200`도 돼요.

- 칸: 업종(옆 숫자는 종목 수), 지수, 오늘, 1주, 1개월, 3개월, 올해, 추세(최근 60일 선).
- 업종은 KRX 업종이에요(코스피·코스닥은 중분류, 중분류가 없으면 대분류. 금융·IT 서비스처럼). 코스피200은 코스피200 섹터 11개(정보기술·금융·산업재 등).
- 오늘 등락은 한국투자증권 업종 지수에서 30초마다, 기간 등락은 업종 지수 일봉(하루 한 번 받아 데이터 폴더에 저장)에서 계산해요. 처음 열면 일봉을 뒤에서 받는 동안 기간 칸이 `—`로 비어 있다가 차례로 채워져요.
- 칸 색은 기간마다 다른 폭에서 가장 진해요: 오늘 ±3%, 1주 ±6%, 1개월 ±10%, 3개월 ±20%, 올해 ±30%. 색은 설정의 등락 색을 따라요.
- 업종 줄을 누르면 그 업종의 종목(시가총액 큰 순, 오늘 등락)이 보이고, 종목을 누르면 같은 연동 색 패널이 그 종목으로 바뀌어요. `← 업종`으로 돌아가요. 코스피·코스닥은 시가총액 상위 200종목 안에서만 보여요.
- 한국투자증권 키가 없으면 업종과 종목 수만 보여요.

### 6.12 IMAP 업종 타일 (v0.2)

업종별로 묶은 종목 타일(시장 지도)이에요. 예: `IMAP⏎`, `IMAP KOSDAQ⏎`, `IMAP KOSPI2⏎`.

- 타일 넓이는 시가총액, 색은 오늘 등락률(±3%에서 가장 진해요). 업종 띠에 업종 이름과 오늘 등락(업종 지수)이 보여요.
- 코스피·코스닥은 시가총액 상위 200종목, 코스피200은 구성 종목 전부를 그려요. 우선주·ETF·ETN은 빼요.
- 종목 시세는 30종목씩 한꺼번에 받아 1분마다 새로 고쳐요. 타일에 마우스를 올리면 이름·현재가·등락률·시가총액이 보여요.
- 타일을 누르면 같은 연동 색 패널이 그 종목으로 바뀌어요.
- 한국투자증권 키가 없으면 회색 타일(업종과 시가총액만)로 그리고 아래에 알려 줘요.

### 6.13 LAST 최근 화면 (v0.2)

최근에 실행한 명령(화면)을 새것부터 봐요. 예: `LAST⏎`, `최근⏎`.

- 칸: 순번, 시각(오늘이면 시:분, 아니면 월/일), 명령(표준형), 여는 화면(예: `삼성전자 종목 개요 (DES)`).
- 같은 명령은 한 번만(가장 최근 것) 보여 줘요. 최근 100개까지 보이고, 기록은 500개까지 남아요.
- 줄을 누르면 이 패널에서 그 화면을 다시 열어요(블룸버그 LAST처럼). 지금 열 수 없는 명령(목록에서 빠진 종목 등)은 흐리게 보여요.

### 6.14 아직 없는 기능

- `FA`(재무제표)·`ECO`(경제 캘린더) 등은 v0.3이에요. 아직 없는 기능을 치면 `⏎ 실행 안 됨: … v0.3에서 제공 예정`처럼 알려 주고 실행하지 않아요.
- 전체 계획은 [버전별 기능](../versions.md)과 [03 기능 코드](../design/03-functions.md)에 있어요.
- 매매(주문) 기능은 넣지 않아요.

## 7. 커맨드 라인 쓰는 법

### 7.1 가장 중요한 두 가지

- **Tab은 채우고, Enter는 실행해요.**
- **입력이 여러 뜻일 수 있으면, 첫 Enter는 1번 줄을 선택만 하고 두 번째 Enter가 실행해요.** 커맨드 라인 오른쪽의 **⏎ 라벨**이 Enter가 할 일을 늘 미리 알려 줘요.

예

| 입력 | 결과 |
|---|---|
| `005930⏎` | 삼성전자. 코드가 정확해서 Enter 한 번에 실행 |
| `삼성⏎⏎` | 이름 일부라 첫 Enter는 1번 줄(삼성전자) 선택, 두 번째 Enter로 실행 |
| `ㅅㅅㅈㅈ` | 초성으로 삼성전자 찾기 |
| `AAPL US GIP⏎` | 애플 장중 차트 |
| `BTC⏎` | 비트코인(BTC/USDT) |
| `WEI⏎` | 세계 지수 |
| `USDKRW⏎` | 원달러 환율 |

### 7.2 명령의 칸

표준 순서는 `종목 시장 자산군 기능 ⏎`예요. 블룸버그의 `IBM US <Equity> GP <GO>`와 같은 모양이에요.

| 칸 | 꼭 필요한가 | 넣을 수 있는 것 |
|---|---|---|
| **종목** | 종목이 필요한 기능일 때만 | 국내 코드(`005930`), 미국 티커(`AAPL`, `BRK.B`), 코인(`BTC`, `BTCUSDT`, `BTC/USDT`), 환율(`USDKRW`, `USD/KRW`), 지수(`KOSPI`, `코스피`), 한글·영문 이름, 초성, 별칭 |
| **시장** | 아니요 | `KS`(코스피), `KQ`(코스닥), `US`(미국) 등 ([8.3](#83-시장-단어)) |
| **자산군** (노란 칩) | 같은 글자가 두 자산군에 있을 때만 | `EQUITY`, `CRYPTO`, `CURNCY`, `INDEX`와 줄임말 ([8.2](#82-자산군-단어)), 단축키 `Ctrl+Shift+E/C/X/I` |
| **기능** | 종목 없이 칠 때 필요. 종목 뒤에선 생략 가능 | 코드(`GP`), 한국어 키워드(`차트`), 키워드 초성(`ㅊㅌ`), 한글 모드로 친 코드(`헤`) |

- 대소문자는 상관없어요. `005930 gp`도 돼요.
- 순서를 바꿔 쳐도 돼요. `GP 005930`, `차트 삼성전자`도 `005930 KS EQUITY GP`로 실행돼요.
- **인자**(v0.2): 기능 뒤에 붙이는 값이에요. MOST는 시장 하나(`MOST KQ`), HMAP·IMAP은 지수 하나(`IMAP KOSDAQ`), COMP는 비교 종목 여러 개(`005930 COMP 000660 KOSPI`)를 받아요. 인자를 받지 않는 기능 뒤에 단어를 치면 `⏎ 실행 안 됨: FXC는 뒤에 인자를 받지 않아요`라고 알려 줘요.
- 기능 바로 뒤, 줄 끝의 `GO`·`<GO>`는 지워요. 그래서 블룸버그식으로 `005930 KS <EQUITY> GP <GO>`를 그대로 쳐도 돼요.

### 7.3 줄여 쓰기와 빈 칸이 정해지는 방법

| 입력 | 실행 | 규칙 |
|---|---|---|
| `005930 GP` | `005930 KS EQUITY GP` | 시장·자산군은 종목에서 정해져요 |
| `005930` (종목만) | 지금 기능 그대로 그 종목 | 보던 기능이 종목용이고 그 종목에 쓸 수 있으면 유지, 아니면 GP. 예: GIP를 보던 패널에서 `005930⏎` → `005930 KS EQUITY GIP`, WEI를 보던 패널에서는 GP |
| `GIP` (기능만) | 패널에 띄운 종목의 GIP | 띄운 종목이 없으면 `[종목]`을 물어요 |
| `MON`, `WEI`, `FXC`, `CRYP` | 그대로 | 종목이 필요 없는 기능. 패널은 띄운 종목을 기억해서, `WEI⏎` 다음 `GP⏎`로 이전 차트가 돌아와요 |
| `005930 WEI` | WEI 실행, 005930을 띄운 종목으로 | 연동 그룹에도 005930이 퍼져요 |
| `BTC`, `btcusdt`, `BTC/USDT`, `비트코인` | `BTC CRYPTO` | 코인은 USDT 쌍만 |
| `USDKRW`, `USD/KRW`, `원달러` | `USDKRW CURNCY` | 환율 |
| `EUR`, `JPY` (통화 하나) | 그 통화의 원화 환율(`EURKRW`, `JPYKRW`) | `KRW`만 치면 `USDKRW` |
| `KRWUSD` (거꾸로) | `USDKRW` | 환율은 USDKRW 방향으로 보여 줘요 |
| `CRYPTO⏎` / `CURNCY⏎` / `INDEX⏎` | CRYP / FXC / WEI | 자산군의 대표 기능 |
| `EQUITY⏎` | 상위 종목(MOST) | v0.1에서는 주식만 보이는 후보 목록이었어요 |
| `?`, `도움말`, `HELP` | 도움말·문법 요약 | |
| `설정`, `PDF` | 설정 창 | `PDF`는 블룸버그의 개인 설정 명령 |

### 7.4 Enter 한 번에 실행되는 것과 선택만 하는 것

**Enter 한 번에 실행**

- 정확히 맞는 코드·이름·키워드: `005930`, `AAPL`, `삼성전자`, `차트`, `WEI`, 종목 뒤의 `GP`
- 종목만 친 것: 지금 기능 그대로(못 쓰면 자산군별 기본 기능, 기본 GP). 설정에서 **블룸버그식 기능 메뉴**를 고르면 그 종목의 기능 메뉴가 열려요(v0.2, [7.15](#715-기능-메뉴와-로컬-검색-페이지-v02))
- 줄 첫머리의 2글자 기능 코드: `GP⏎` (띄운 종목의 가격 차트)
- 종목에서 정해지는 시장·자산군, 기본 기능, 띄운 종목
- 고쳐서 실행: `005930 KQ` → KS(005930은 코스피라서), 종목 뒤 `헤` → GP. 주황 점선 밑줄과 ⏎ 라벨의 `(KQ → KS)`로 알려 줘요
- Tab·클릭·화살표로 이미 **고른** 토큰(글자를 고치기 전까지)

**첫 Enter는 선택만(두 번째 Enter가 실행)**

- 앞부분만 친 것: `0059`, `삼성`, `삼성바이` (후보가 하나여도). 종목 목록이 바뀌면 같은 입력의 결과가 달라질 수 있어서예요
- 짧은 입력: 줄 첫머리 한 글자(`G`, `N`, `ㅅ`), 첫 칸 영문·숫자 2글자 이하 중 기능 코드가 아닌 것(`GS`, `KT`, `GO`)
- 초성·부분·오타: `ㅅㅅㅈㅈ`, `5930`, `apel`
- 첫 칸의 한/영 실수: `ㅁ메ㅣ` → AAPL
- 겹치는 이름: `CVX`(셰브론 / Convex 코인) ([7.9](#79-겹치는-이름))

**실행 안 함(빨간 밑줄 + ✗)**

- 자산군에 안 맞는 기능: `BTC CRYPTO FA` → `FA는 주식 전용이에요`
- 지원하지 않는 시장: `VOD LN` → `지원하지 않는 시장이에요 (KS·KQ·US만)`
- 아직 없는 기능: `ECO` → v0.3에서 제공 예정
- 기능 두 개: `005930 GP GIP` → `기능은 하나만 쓸 수 있어요`
- USDT가 아닌 코인 쌍: `ETHBTC` → `코인은 USDT 마켓만 지원해요`

**일치 없음**: ⏎ 라벨이 `⏎ 검색`이에요. Enter를 누르면 로컬 검색 페이지가 열려요(v0.2, [7.15](#715-기능-메뉴와-로컬-검색-페이지-v02)).

고칠 방법은 늘 목록의 1번 줄에 있어요. Tab을 누르면 그 고침이 적용돼요.

### 7.7 한글로 찾기

- **한글 이름**: `삼성전자`, `카카오`, `애플`, `비트코인`, `코스피`, `원달러`
- **이름 일부**: `삼성` → 삼성전자, 삼성바이오로직스, 삼성SDI …
- **초성**: `ㅅㅅㅈㅈ` → 삼성전자. 기능 키워드 초성도 돼요(`ㅊㅌ` → 차트 → GP)
- **한국어 키워드**: `차트`, `분봉`, `관심종목`, `지수`, `환율`, `코인` 등 ([8.6](#86-한국어-키워드))
- **한/영 실수 교정**: 한글 모드로 영문 코드를 쳐도 알아봐요.
  - 기능·시장·자산군 칸: 바로 고쳐서 실행. `005930 헤⏎` → `005930 GP`
  - 종목 칸: 고치지 않고 `ㅁ메ㅣ → AAPL` 줄을 보여 줘요. 직접 골라야 해요
  - 영문 모드로 한글 이름을 친 경우(`tkatjd`): `tkatjd → 삼성전자 (영→한)` 줄
  - 한글 모드로 친 코드 예(두벌식): GP→`헤`, GIP→`햐ㅔ`, WEI→`ㅈ댜`, FXC→`ㄹㅌㅊ`, CRYP→`ㅊ교ㅔ`, EQUITY→`ㄷ벼ㅑ쇼`, KS→`ㅏㄴ`, AAPL→`ㅁ메ㅣ`, BTC→`ㅠㅅㅊ`
  - 세벌식 등 다른 자판에서는 맞지 않을 수 있어요. 그때는 설정에서 **한/영 실수 교정**을 꺼요.
- **영문 머리글자**(v0.2): 두 단어 이상인 영문 이름은 머리글자로도 찾아요. `boa` → Bank of America, `er` → Equity Residential. 줄에 `머리글자` 표시가 붙어요.
- **오타 한 글자**(v0.2): 4글자 이상 영문 이름을 한 글자 틀려도 찾아요. `apel` → Apple(`오타?` 표시). 결과가 3개보다 적을 때만, 첫 글자는 맞아야 해요. 코드·티커에는 쓰지 않아요. 기능 코드도 4글자 이상이면 한 글자 차이까지(`CRPY` → CRYP).
- 단축키는 한글 모드에서도 키보드 자리로 알아봐요. `Ctrl+Shift+ㄷ`도 `Ctrl+Shift+E`예요.
- 한글 입력 중(조합 중)에 누른 Tab·Enter는 글자가 끝난 뒤 한 번만 처리해요.

### 7.7.1 별칭 만들기 (ALIAS, v0.2)

자주 보는 종목에 짧은 이름을 붙여요.

- 만들기: `ALIAS 별칭 종목⏎`. 예: `ALIAS SS 005930⏎` → 이제 `SS⏎`가 삼성전자예요. `ALIAS AP AAPL US⏎`처럼 시장을 붙여도 돼요. `별칭 이름 종목⏎`도 같아요.
- 별칭은 영문·숫자·한글 2~12글자예요. 기능(GP 등)·명령·시장(KS 등)·자산군 단어는 쓸 수 없어요.
- 줄 첫머리에서는 별칭이 같은 글자의 티커보다 먼저예요(후보 줄에 `ALIAS` 배지). 진짜 티커를 보려면 `SS US`처럼 시장을 붙여요.
- 같은 별칭으로 다시 만들면 바뀌어요. 알림의 **되돌리기**로 되돌릴 수 있어요.
- 목록과 지우기: `ALIAS⏎`(설정 → 커맨드 라인 → 별칭).

| **Ctrl+Shift+E / C / X / I** (Mac ⌘⇧E/C/X/I) | 자산군 EQUITY / CRYPTO / CURNCY / INDEX를 넣어요. 종목이 아직 정해지지 않았으면 그 자산군으로 걸러요 |
| **F8 / F9 / F10 / F11** (Windows, F키 모드를 켰을 때) | EQUITY / CRYPTO / INDEX / CURNCY를 넣어요(v0.2) |
| **숫자 + Enter** (기능 메뉴 페이지에서) | 그 번호의 기능을 열어요(v0.2). 다른 곳에서 숫자는 종목코드예요 |
| **Ctrl+Z / Ctrl+Y, Ctrl+Shift+Z** (Mac ⌘Z / ⌘⇧Z) | 되돌리기·다시. 채우기 한 번 = 되돌리기 한 번 |
| **Backspace** | 한 글자 지우기. 자동 교정(`헤`→`GP`, `KQ`→`KS`) 바로 다음에는 원래 글자로 되돌려요 |
| **Shift+Delete** (Mac Shift+Fn+⌫) | ↺ 줄이 강조돼 있을 때 그 기억을 지워요 |
| 마우스 | 줄 클릭 = Tab, 더블클릭 = Tab 다음 Enter. 클릭 한 번으로는 실행되지 않아요 |

### 7.9 겹치는 이름

같은 글자가 여러 뜻일 때의 규칙이에요. 어느 뜻으로 읽었는지는 진행 표시에 늘 적고, 다른 뜻은 바로 아래 줄에 있어요.

1. **시장이나 자산군을 직접 쓰면** 그것으로 정해요. `BTC US`(미국 ETF), `BTC CRYPTO`(코인), `GS KS`(코스피의 GS홀딩스).
2. **정해 둔 표**: `BTC`, `ETH`, `SOL`, `XRP`는 코인, 통화 코드(`USD`, `EUR`, `JPY` …)는 환율로 읽어요.
3. **내가 정한 기본값**(아래).
4. **그 밖에는 실행하지 않아요.** 첫 Enter는 1번 줄을 선택만 하고 두 줄을 모두 보여 줘요. 예: `CVX`(셰브론 / Convex 코인).

줄 첫머리의 단어

- **3글자 이상의 기능 코드는 기능**이에요. `FXC`, `WEI`, `CRYP`는 미국 티커이기도 하지만 기능으로 읽어요. 종목을 원하면 `FXC US`처럼 시장을 붙이거나 2번 줄을 골라요.
- **2글자 정확한 기능 코드**(`GP`, `FA`)도 기능으로 바로 실행해요. 같은 글자의 종목은 2번 줄에, `GP US`처럼 시장을 붙이면 종목이에요.
- `HELP⏎`는 도움말이에요. 미국 종목 HELP는 `HELP US`로 쳐요.
- `GO`만 치면 미국 종목 Grocery Outlet 검색이에요(2글자라 선택만).
- 한국 회사 이름과 미국 티커가 같은 것(`GS`, `KT`, `KB`)은 선택만 해요.
- 시장 단어(`UA`, `UN`, `AMS` 등)는 종목 뒤에서는 시장으로, 줄 첫머리에서는 종목으로 읽어요.

**내 기본값 정하기**

- 겹치는 입력에서 1번이 아닌 같은 줄을 **두 번** 고르거나, 설명 창의 **기본값으로** 버튼을 누르면 그 줄이 그 입력의 기본값이 돼요. `이제 BTC⏎는 BTC US(ETF)로 열려요 · [되돌리기]` 알림이 떠요.
- 그 뒤 ⏎ 라벨에 `(내가 정한 기본값 ↺)`가 붙어요.
- 지우기: 설명 창의 `기본값 지우기`, ↺ 줄에서 `Shift+Delete`, 또는 설정 → 커맨드 라인 → **기억된 선택 초기화**.
- 애매한 목록에서 고른 줄은 기억해서(↺) 다음에 같은 입력을 하면 위로 올려 줘요.

**겹치는 이름 표**: 도움말의 **겹치는 이름 표**에서 앱이 아는 모든 겹침(약 280줄)과, 그 단어만 치고 Enter를 누르면 무엇을 하는지, 그렇게 정한 이유를 거르며 볼 수 있어요.

### 7.10 목록에 없는 코드 직접 조회

오늘 상장한 종목처럼 앱의 종목 목록에 아직 없는 코드는 한국투자증권에서 직접 찾아요.

- 국내 6자리 코드(숫자로 시작)나 미국 티커 모양(영문 1~5자, `.B` 같은 클래스)을 치면 `목록에 없는 코드예요 — ⏎로 KIS에서 직접 조회` 줄이 보여요.
- 첫 Enter로 그 줄을 고르고, **두 번째 Enter**에 조회해요. 찾으면 `LOOKUP` 표시를 달고 이번 실행 동안 목록에 넣어요. 기능을 안 쳤으면 GP로 열어요.
- 한국투자증권 키가 있어야 해요. 키가 없으면 `한국투자증권 키를 넣으면 직접 조회할 수 있어요`라고 알려 줘요.

### 7.11 포커스: 커맨드 라인과 패널 본문

| 상태 | 들어가는 법 | 표시 |
|---|---|---|
| 커맨드 라인 (기본) | 패널을 누르면, `Ctrl+L`(Mac ⌘L) | 입력줄 커서 |
| 패널 본문 | 빈 줄에서 Esc, `F6`, `Ctrl+↓`(Windows) | 본문에 주황 안쪽 테두리 |

- 본문에서는 관심종목 줄을 `↑` `↓`로 옮기고 Delete로 빼요.
- 본문에서 영문 글자나 숫자를 치면 커맨드 라인으로 돌아가 그 글자부터 입력돼요. Esc, `F6`, `Ctrl+L`로도 돌아가요.
- 빈 줄이고 목록이 없으면 Tab·Shift+Tab은 보통처럼 다음 요소로 포커스를 옮겨요. 키보드가 커맨드 라인에 갇히지 않게 하려는 거예요.

### 7.12 명령 팔레트

- `Ctrl+K`(Mac ⌘K)로 화면 가운데에 큰 커맨드 라인을 열어요. 커맨드 라인과 똑같이 동작하고 줄을 더 많이 보여 줘요.
- 대상은 **팔레트를 연 그 창의 활성 패널**이에요. 위쪽 칩(`→ 패널 2 · AAPL US GP`)에 보여요.
- `Alt+1…9`(Mac Option+1…9)로 대상 패널을 바꿔요.
- 실행하면 닫혀요. Esc로도 닫아요.

### 7.13 붙여넣기와 기록

- 명령을 붙여 넣으면 읽기만 하고 **실행하지 않아요.** 꺾쇠(`<`, `>`)와 끝의 `GO`는 지워요. 확인한 뒤 Enter를 눌러요.
- 실행한 명령은 표준형(`005930 KS EQUITY GP`)으로 기록에 남아요(최근 500개). 빈 줄에서 `↑`로 꺼내요. 글자를 치고 목록을 닫은 뒤 `↑`를 누르면 그 글자가 든 기록만, `Ctrl+R`로는 기록을 검색해요(v0.2). 최근 화면 목록은 `LAST⏎`.
- 실행하면 줄이 비고, 그 패널의 명령이 흐린 글씨로 보여요. 그 위에 바로 새 명령을 치면 덮어써요.

### 7.15 기능 메뉴와 로컬 검색 페이지 (v0.2)

**기능 메뉴**(설정 → 커맨드 라인 → 종목만 입력하고 Enter를 누르면 → 블룸버그식 기능 메뉴)

**로컬 검색 페이지**

- 후보 목록의 **더 보기**를 누르거나, 일치하는 것이 없을 때(`⏎ 검색`) Enter를 누르면 패널이 로컬 검색 페이지로 바뀌어요.
- 앱 안의 종목 목록(국내·미국·코인·환율·지수)과 기능에서 찾은 줄을 자산군별로 묶어 200줄까지 보여 줘요. 위 입력칸에서 다른 말로 다시 찾을 수 있어요(인터넷을 쓰지 않아요). 오타 한 글자·초성·영문 머리글자도 돼요.
- 줄을 누르면 그 종목·기능이 이 패널에서 열려요. 국내 종목은 영문 이름이 목록에 없어서 한글 이름·코드로 찾아요.

### 8.7 코인

- Binance USDT 현물에 있는 코인(약 700개)을 모두 찾을 수 있어요. `BTC`, `BTCUSDT`, `BTC/USDT`, `BTC-USDT`, `비트코인` 모두 `BTC CRYPTO`(BTC/USDT)예요.
- USDT가 아닌 쌍(`ETHBTC`, `ETH/KRW`)은 지원하지 않아요. `USDT`만 치면 `USDT는 기준 통화예요 — 코인 이름과 함께 입력하세요`라고 알려 줘요.

### 8.8 주식

- 국내: 코스피·코스닥 상장 종목. 6자리 코드(`005930`), 한글 이름(`삼성전자`), 초성(`ㅅㅅㅈㅈ`).
- 미국: 나스닥·뉴욕·아멕스 상장 종목. 티커(`AAPL`), 영문·한글 이름(`apple`, `애플`). 클래스 주식은 `BRK.B`, `BRK-B` 모두 `BRK/B US`예요.
- 영문 이름은 여러 단어도 돼요(`bank of america GP`).

## 10. 설정

`Ctrl+,`(Mac `⌘,`), 커맨드 라인의 `설정⏎`·`PDF⏎`로 열어요. 상태 표시줄의 `데모 시세`를 누르면 데이터 연결이 바로 열려요. **바꾸면 바로** 모든 패널과 떼어낸 창에 적용돼요. 저장 버튼은 없어요.

### 10.1 일반

- **시작할 때 마지막 배치 복원**: 켜 두면 앱을 끌 때의 모든 창과 화면 탭의 배치가 다음 실행 때 복원돼요. 끄면 늘 기본 배치로 시작해요.

### 10.2 화면

- **테마**: Modern(블룸버그 터미널 색: 검정 바탕에 흰 숫자, 앰버 라벨·제목·종목 이름, 켜진 탭·버튼은 앰버 바탕, 묶음 줄은 남색 띠). Classic은 후순위예요.
- **강조 색**: 블룸버그 앰버(기본), 예전 주황, 흰색, 청록 중에서. 라벨·표 머리줄·종목 이름 색이 강조 색을 따라 바뀌어요.
- **등락 색**: **글로벌식**(기본, 블룸버그의 상승 초록 ▲ · 하락 빨강 ▼) 또는 **한국식**(상승 빨강 ▲ · 하락 파랑 ▼).
- **글자 크기**: 90%, 100%, 110%, 120%, 135%. 표·차트·커맨드 라인·떼어낸 창까지 화면 전체를 같은 배율로 키워요.
- **데이터 신선도 배지**: 설명만 있어요. 끌 수 없어요([5장](#5-데이터-신선도-배지)).

### 10.3 커맨드 라인

- **자동완성 도움 수준**: 입문·표준·전문가·끔 카드 중에서 골라요. 비교표에서 고른 수준이 강조되고, 아래 **미리보기**가 `0059`를 쳤을 때 그 수준에서 어떻게 보이는지 바로 보여 줘요([7.6](#76-도움-수준-입문표준전문가끔)).
- **종목만 입력하고 Enter를 누르면**: 지금 기능 유지(기본값) / 블룸버그식 기능 메뉴(v0.2). 블룸버그식이면 `005930⏎`이 기능 메뉴를 열어요([7.15](#715-기능-메뉴와-로컬-검색-페이지-v02)).
- **자산군별 기본 기능**(v0.2): 종목만 쳤는데 지금 기능을 그 종목에 못 쓸 때 열 기능을 주식·코인·환율·지수마다 골라요(기본 GP). 예: 주식을 DES로 하면 WEI를 보던 패널에서 `005930⏎` → 종목 개요.
- **입력 도우미**
  - **Tab으로 시장·자산군 채우기**: 끄면 Tab이 종목만 채우고 시장·자산군을 써 넣지 않아요.
  - **한/영 실수 교정**: 끄면 한/영 변환 줄과 자동 교정이 모두 꺼져요. 세벌식 등 다른 자판을 쓰면 꺼요.
  - **HTS식 6자리 바로 열기**(v0.2, 기본 꺼짐): 켜면 국내 종목코드 6자리를 다 치는 순간 Enter 없이 종목이 바뀌어요.
  - **F키 모드**(Windows, v0.2, 기본 꺼짐): 켜면 커맨드 라인에서 F8 = EQUITY, F9 = CRYPTO, F10 = INDEX, F11 = CURNCY를 넣어요. 켜 있는 동안 F11은 전체 화면이 아니에요. 전체 화면 단축키가 F11이면 단축키 탭에서 다른 키로 바꿔요(설정 창이 알려 줘요).
  - **사용 팁**: 끄면 짧은 형태 팁을 보여 주지 않아요.
  - **기억된 선택 초기화**: 기억된 선택(↺)과 겹침 기본값을 지워요. 사용 기록(순위)은 남아요.
- **별칭**(v0.2): `ALIAS 별칭 종목⏎`으로 만든 별칭 목록과 **지우기**([7.7.1](#771-별칭-만들기-alias-v02)).
- **한글 입력 기록기**: 커맨드 라인에서 한글을 칠 때의 키·조합·입력 이벤트 순서를 남겨요. Tab·Enter·클릭이 이상하게 동작하면 켜 두고 다시 해 본 뒤 **기록 복사**를 눌러 보내 주세요. 기록에는 커맨드 라인에 친 글자가 들어가요(앱키 입력칸은 기록하지 않아요). **지우기**로 비워요. 기본은 꺼짐이에요.

### 10.4 단축키

- 줄마다 **기본값**, 맨 아래 **모두 기본값으로**.
- 아래쪽에 **바꿀 수 없는 키** 목록이 있어요.

- **앞으로 추가될 키**: BOK ECOS·FRED·KOSIS·SEC EDGAR(v0.3), 네이버·KRX Open API(v0.4), 공공데이터포털(v0.7), EIA(v0.11).

## 12. 자주 묻는 것과 문제 해결

**주식·지수에 `데모`가 붙어 있어요.**
한국투자증권 키를 넣지 않아서 가짜 시세를 보여 주는 거예요. [2.2](#22-한국투자증권-키-넣기)대로 키를 넣으면 실제 시세로 바뀌어요. 코인과 환율은 키 없이도 실제 값이에요.

**BTC가 실시간인지 어떻게 알아요?**
신선도 배지가 없으면 실시간이에요. 상태 표시줄의 Binance 점이 **초록**이면 연결된 거예요. 상태 표시줄의 `데모 시세`는 주식·지수 이야기예요.

**연결 테스트가 끝나지 않거나, 키를 넣은 뒤 시세가 모두(코인까지) 멈췄어요.**
지금 버전은 연결 테스트가 단계마다 시간 제한이 있어서, 늦어도 1분 안에 성공이나 막힌 단계를 보여 줘요. 서버가 멈추면 상태 표시줄이 `⚠ 내장 서버 응답 없음`으로 바뀌어요. 그때 설정 → 정보 → **진단 정보 복사**를 눌러 붙여 넣어 보내 주세요. 화면이 굳어서 설정을 못 열면 앱을 끄고 다시 켠 뒤 복사해요(데이터 폴더의 `logs/server.log`에도 남아 있어요).

**국내 종목 몇 개가 `—`로 비어 있거나 차트가 비어 있어요.**
v0.1.0-beta.7까지는 조회가 한도를 넘으면 조회 대기줄이 통째로 멈추는 문제가 있었어요. 새 버전으로 덮어 설치하면 돼요. 그래도 비어 있으면 진단 정보를 보내 주세요.

**장이 끝난 국내 종목에 `마감`이 붙어요.**
정상이에요. 장이 끝나 체결이 없으면 마지막 값에 `마감 15:30`(다음 날부터는 `마감 10/30`)이 붙어요. 장이 닫힌 종목은 5분마다 마감 값을 다시 확인해요.

**WEI의 해외 지수 몇 개가 `0.00`이에요.**
v0.1.0-beta.9까지는 FTSE 100·DAX·CAC 40·니케이·항셍·대만·다우존스를 잘못된 코드로 조회해서 0으로 보였어요. 새 버전으로 덮어 설치하면 돼요. 그래도 값을 받지 못한 지수는 `—`로 보여요.

**기본 배치의 패널이나 연동 색이 이 설명과 달라요.**
앱은 지난번 배치를 저장해 두고 다시 열어요. 예전 버전에서 쓰던 배치가 남아 있으면 패널이 빠져 있거나 연동 색이 다를 수 있어요. 맨 위 줄의 `워크스페이스 ▾` → **기본 배치로 새로 시작**을 누르면 기본 배치로 돌아가요(알림의 되돌리기로 되돌릴 수 있어요).

**`⚠ 멈춤`이 떠요.**
받아야 할 때 새 값을 받지 못했어요. 인터넷 연결을 확인해요. 상태 표시줄에서 어느 출처가 끊겼는지(빈 점 + ⚠) 볼 수 있어요. 연결이 돌아오면 저절로 다시 받아요. 한국투자증권이면 조회 한도를 넘었을 수도 있어요(잠시 뒤 풀려요).

**환율이 움직이지 않아요.**
배지가 `일별`이면 ECB 기준환율이라 하루 한 번만 바뀌어요. 한국투자증권 키를 넣으면 10초마다 받아요(`10초 주기`). 키가 있는데도 `일별`이면 한국투자증권 환율 조회가 1분 넘게 실패한 거예요. 진단 정보를 보내 주세요.

**Enter를 눌렀는데 실행이 안 되고 줄만 골라져요.**
입력이 여러 뜻일 수 있어서예요. 한 번 더 Enter를 누르면 실행돼요. ⏎ 라벨이 `⏎ 선택:`이면 고르기, `⏎ 실행:`이면 실행이에요([7.4](#74-enter-한-번에-실행되는-것과-선택만-하는-것)).

**`FXC`를 쳤는데 미국 종목 FXC가 아니라 환율이 떠요.**
줄 첫머리의 기능 코드는 기능으로 읽어요. 종목을 원하면 `FXC US`처럼 시장을 붙여요([7.9](#79-겹치는-이름)).

**한글 모드로 쳤더니 이상한 글자가 됐어요.**
기능 칸이면 저절로 고쳐서 실행해요(`헤` → GP). 종목 칸이면 `ㅁ메ㅣ → AAPL` 줄을 골라요. 한글 입력이 계속 이상하면 설정 → 커맨드 라인 → 한글 입력 기록기를 켜고 다시 해 본 뒤 기록을 보내 주세요.

**패널을 실수로 닫았어요.**
패널의 ✕는 되돌릴 수 없어요. 화면 탭의 ✕, 워크스페이스 불러오기·지우기·새로 시작은 알림의 **되돌리기**로 돌아갈 수 있어요. 자주 쓰는 배치는 워크스페이스에 이름을 붙여 저장해 두세요.

**떼어낸 창을 닫았더니 어디 갔어요?**
패널을 떼어낸 창이면 메인 창의 원래 자리로, 화면 탭을 떼어낸 창이면 메인 창의 화면 탭으로 돌아와요. 없애려면 패널의 ✕나 화면 탭의 ✕를 눌러요.

**떼어낸 창이 안 보여요 / 모니터를 뺐어요.**
메인 창의 화면 탭에서 떼어낸 화면(흐린 기울임 글씨)을 누르면 그 창을 앞으로 가져와요. 화면 밖에 있으면 ↙로 메인 창에 돌려놓은 뒤 다시 떼어내요. 앱은 화면 밖으로 나간 창을 메인 모니터로 모아요.

**화면 탭의 떼어내기 버튼(↗)이 안 보여요.**
메인 창에 화면이 하나뿐이면 떼어낼 수 없어요. `+`로 화면 탭을 하나 더 만들면 보여요.

**설치형과 휴대용 중 무엇을 받아요?**
설치형(`TICKER.Setup.<버전>.exe`)을 권해요. 켜는 게 빠르고 시작 메뉴에 등록돼요([1.1](#11-설치-파일-받기)).

**미리 보기와 정식은 무엇이 달라요?**
미리 보기는 시험 중인 버전, 정식은 확인을 마친 버전이에요. 받는 법과 설치법은 같고, 덮어 설치해도 설정·키·배치가 남아요.

**전체 화면에서 나가고 싶어요.**
전체 화면을 켠 키를 한 번 더 눌러요. Windows는 `F11`, Mac은 `⌃⌘F`예요. 설정에서 키를 바꿨다면 바꾼 키예요([4.6](#46-전체-화면)).

**새 버전이 나왔는지 어떻게 알아요?**
자동 업데이트와 알림이 없어요. Releases 화면에서 확인하고, 설정 → 정보의 앱 버전과 비교해요.

**Windows에서 제거가 막혀요.**
[1.2](#12-windows에서-처음-열-때)의 제거 방법을 보세요.

**Mac에서 "손상되었기 때문에 열 수 없습니다"가 떠요.**
`xattr -cr /Applications/TICKER.app`을 터미널에서 실행해요([1.3](#13-mac에서-처음-열-때)).

**앱이 느려요.**
설정 → 정보 → 성능의 숫자(커맨드 라인 해석 p95, 16ms를 넘긴 입력 이벤트)를 알려 주세요. 글자 크기를 바꾸거나 패널 수를 줄여 볼 수도 있어요.

**설정·배치를 처음 상태로 돌리고 싶어요.**
배치는 워크스페이스 ▾ → 기본 배치로 새로 시작. 설정까지 모두 지우려면 앱을 끄고 데이터 폴더([1.5](#15-데이터-폴더))를 지워요. 한국투자증권 키도 함께 지워져요.
