# 01 개요와 결정 사항

## 목표

블룸버그 터미널처럼 보이고 블룸버그처럼 쓰는 **나만의 시세 터미널**을 만들어요.

- **키보드 중심**: `005930 KS <EQUITY> GP <GO>`처럼 [종목] [시장] [자산군] [기능] 순서로 입력하고, 마우스는 보조로만 써요. `<GO>`는 블룸버그의 실행 키예요. 이 앱에서는 Enter예요.
- **고밀도 멀티 패널**: 검은 배경 위에 여러 창을 빽빽하게 배치하고, 여러 모니터로 나눠 띄울 수 있어요.
- **입문자도 쓸 수 있게**: 커맨드 라인 자동완성이 다음에 입력할 것을 알려줘요. 자세한 내용은 [05 커맨드 라인과 자동완성](05-command-line.md)에 있어요.
- **한국 사용자 우선**: 한글 종목명, 초성 검색, 한/영 실수 교정, 국내 시장을 기본으로 지원해요.
- **블룸버그 기능을 최대한**: 주식뿐 아니라 채권·금리 커브, 매크로, 옵션, 원자재까지 블룸버그 기능을 최대한 구현해요. 다만 개인에게는 의미 없는 속도의 데이터가 필요한 기능(전 종목 틱, 딜러 실시간 호가 등)과 매매 기능은 빼요. 기능별 판정은 [08 블룸버그 기능 커버리지](08-bloomberg-coverage.md)에 있어요.

## 확정된 결정

| 항목 | 결정 | 이유 |
|---|---|---|
| 앱 형태 | Electron 데스크톱 앱(v0.1은 Electron 45). 개발 중에는 브라우저와 실행 스크립트로 작업. 화면은 내장 서버(127.0.0.1, 실행마다 빈 포트)에서 불러와요 | Windows와 Mac에서 같은 Chromium으로 그려서 화면이 똑같고, Node 서버를 앱 안에 그대로 품을 수 있어요 |
| 지원 OS | Windows 주력, macOS(Apple Silicon)는 보조 | 현재 보유한 PC가 Windows예요. Mac 빌드는 GitHub Actions의 Apple Silicon 빌드 서버에서 자동으로 만들어요 |
| 언어 | TypeScript (화면과 서버 모두) | 화면은 어차피 TypeScript여야 하고, 서버와 데이터 형식을 공유할 수 있어요. 서버는 계산보다 중계가 대부분이라 언어 속도 차이가 체감되지 않아요 |
| 화면 기술 | React + Vite, 창 관리 dockview(창 떼어내기는 dockview 팝아웃 창), 메인 차트 TradingView Lightweight Charts, 소형 차트 uPlot(GRID, v0.3). v0.1의 스파크라인은 SVG로 그려요 | 차트 수십 개를 동시에 그리는 데 맞춘 조합. 실제 성능은 개발하면서 재요 |
| 서버 | Node.js + Fastify + WebSocket, 앱 안에서 실행 | 시세 수집과 중계, API 키 보호 |
| DB | SQLite | 파일 하나, 별도 설치 불필요 |
| 저장소 구성 | pnpm 모노레포 | 화면·서버·공통 형식을 한 저장소에서 관리 |
| 시세 데이터 | 한국투자증권 Open API(국내·미국 주식, 지수, 장내채권, 국내선물옵션), Binance(코인, USDT만), 무료 환율 소스, DART·RSS(v0.2), 그리고 무료 공식 데이터(한국은행 ECOS, 미국 재무부 금리, FRED, SEC EDGAR, KRX Open API 등)를 단계별로 추가. 유료 데이터는 쓰지 않음 | [04 데이터 소스](04-data-sources.md) 참고 |
| 기능 범위 | 블룸버그 기능을 최대한 구현. 개인에게 의미 없는 속도가 필요한 기능은 제외. v0.1~v0.3은 기본 화면, v0.4부터 종목 심화·금리·채권·포트폴리오·스크리닝·옵션·원자재를 v0.11까지 차례로 | [03 기능 코드와 단계별 범위](03-functions.md), [08](08-bloomberg-coverage.md) 참고 |
| 데이터 신선도 표시 | 실시간이 아닌 값에는 항상 회색 신선도 배지(`5초 주기`, `15분 지연`, `일별 10/21`, `기준 2026-09`, `마감`, `⚠ 멈춤`)를 붙임. 배지가 없으면 실시간 | 무료 데이터는 대부분 실시간이 아니라서, 늦은 값을 실시간으로 착각하지 않게 해요. [02 화면 디자인](02-ui.md) 참고 |
| 매매(주문) 기능 | 제외 | 사용자 결정. 한국투자증권에 주문 API가 있지만 넣지 않아요. 호가·채권 시세·옵션 체인처럼 보는 기능은 포함해요 |
| 디자인 | Modern Terminal: 검정 배경, 흰 숫자, 주황 포인트. 등락 색 기본은 글로벌식(초록 상승·빨강 하락), 설정에서 한국식 선택 | [02 화면 디자인](02-ui.md) 참고 |
| 커맨드 라인 | Tab은 채우기, Enter는 실행. 애매하면 첫 Enter는 선택, 두 번째 Enter가 실행. ⏎ 라벨이 Enter 결과를 보여줌. 네 가지 도움 수준(입문·표준·전문가·끔)을 설정에서 바꿈. 첫 실행은 입문 | [05 커맨드 라인과 자동완성](05-command-line.md) 참고 |
| 멀티 모니터 | 포함. 패널을 떼어 다른 모니터로 옮길 수 있음. 창마다 화면 탭을 두고, 모든 창과 탭을 묶어 워크스페이스 하나로 저장 | 블룸버그식 듀얼 모니터 구성 |
| 창 닫기 | 메인 창을 닫으면 앱 완전 종료 | 트레이 상주 없음 |
| 화면 크기 | 데스크톱 전용 | 모바일은 지원하지 않아요 |
| AI 기능 | 제외 | 나중에 붙일 자리만 남겨요 |
| 사용 범위 | 나 혼자 쓰는 개인용 | 시세를 다른 사람에게 재배포하면 라이선스 문제가 생겨요 |

**검토했다가 뺀 것**

| 항목 | 이유 |
|---|---|
| 라즈베리파이 서버 | 사용하지 않기로 함 |
| Docker | Win·Mac에서 Docker Desktop은 메모리를 2GB 이상 계속 차지해요. 라즈베리파이를 빼면서 이점이 거의 남지 않았어요 |
| 트레이 상주 | 창을 닫으면 완전 종료하기로 함 |
| Tauri | Node 서버를 따로 묶어야 하고, Windows와 Mac에서 화면 엔진이 달라요 |
| Python 서버 | 화면과 언어가 갈리고, 이 프로젝트에서는 속도 이점이 없어요 |
| 신한투자증권 API | 개인이 쓸 수 있는 웹 방식 API를 찾지 못했고(블로그 같은 간접 자료 기준), 기존 Indi API는 Windows에서만 돌아가는 방식(ActiveX)이라 Mac을 지원할 수 없어요 |
| Upbit, 김치 프리미엄(KIMP) | 코인은 Binance USDT 가격만 쓰기로 함 |
| 매매(주문) 기능 | 사용자 결정. 주문 화면, 주문 관리, 체결 분석, 잔고 자동 연동 모두 넣지 않아요 |
| 유료 데이터 | 사용자 결정. KIS 해외선물 CME·SGX 실시간, 미국 개별주 옵션 체인, 미국 애널리스트 추정치는 넣지 않아요. 무료 범위로 대신할 수 있는 것은 일 1회로 넣어요 |
| Deribit 코인 옵션 | 코인은 Binance만 쓰기로 함. 크립토 옵션은 Binance 옵션 공개 시세로 대신할 수 있는지 확인해요 |
| 모바일 화면 | 데스크톱 전용으로 결정 |
| 자동 업데이트 | 사용자 결정. 새 버전은 릴리스에서 직접 받아요. 코드 서명이 없으면 Mac에서는 어차피 자동 업데이트가 안 돼요 |

## 전체 구조

```
[Electron 앱]
 ├─ 메인 프로세스
 │   └─ 내장 서버 (Node.js)
 │       ├─ 한국투자증권 · Binance · 환율 · DART · 공식 통계 등에서 데이터 수집
 │       ├─ 형식 통일, 실시간 구독 관리, 호출 횟수 조절
 │       └─ 분봉·이력 저장 (SQLite)
 └─ 창 여러 개 (메인 창 + 떼어낸 창)
     └─ 화면 (React) ← localhost WebSocket 으로 시세 수신
```

- 서버는 **이 PC 안에서만 접속**할 수 있게 열어요. 같은 와이파이의 다른 기기에서도 접근할 수 없어요.
- 시세 연결은 **하나만** 두고 모든 창이 나눠 받아요. 여러 창에 같은 종목이 떠 있어도 한 번만 구독해요.
- 시세 처리는 화면과 다른 스레드에서 해서, 시세가 몰려도 키 입력이 느려지지 않게 해요.
- **한국투자증권 요청 예산 관리자**를 v0.1부터 둬요. 실시간 구독 슬롯(약 40개)과 REST 호출 한도(초당 약 20건)를 여러 기능이 나눠 쓰기 때문이에요. 우선순위는 화면에 보이는 종목이 먼저이고, 백그라운드 수집은 남는 예산으로 해요. 기능마다 슬롯을 얼마나 쓰는지 표시해요. 자세한 내용은 [08](08-bloomberg-coverage.md)에 있어요.

**저장소 구성 (예정)**

```
apps/desktop      Electron 메인 프로세스, 창 관리, 메뉴
apps/web          화면 (React + Vite + TypeScript)
apps/server       내장 서버 (Fastify + WebSocket)
packages/shared   공통 형식: 시세·알림 메시지 정의, 값마다 붙는 신선도 정보
docs/design       설계 문서
```

## 실행과 종료

**실행 방식**

| 시기 | 방식 |
|---|---|
| 개발 중 | 브라우저 + 실행 스크립트 (Windows `start.bat`, Mac `start.command`). 서버를 켜고 브라우저를 자동으로 열어요 |
| 완성 후 | Electron 설치 파일 (Windows 설치형 .exe, Mac .dmg). 필요하면 설치 없이 실행하는 버전도 만들어요 |

**설치 파일과 서명**

- Windows용은 Windows에서, Mac용은 Mac 빌드 서버에서 만들어요. GitHub Actions로 버전 태그를 올리면 두 OS용 설치 파일이 자동으로 만들어지게 해요.
- **앱 버전 번호는 태그에서 가져와요.** `v0.1.0` 태그를 올리면 설치 파일 이름과 앱 정보 화면이 모두 0.1.0이 돼요. package.json의 version은 손으로 올리지 않아요(개발 중 실행에서만 쓰는 값이에요).
  - 고치는 판은 끝자리를 올리고(`v0.1.1`), 다음 단계 기능이 다 들어가면 가운데를 올려요(`v0.2.0`).
  - 태그에 `-`가 붙으면(`v0.2.0-beta.1`) 미리 보기 릴리스로 올라가요.
  - 만들어진 릴리스는 초안이라, GitHub 화면에서 공개를 한 번 눌러야 다운로드 페이지에 보여요.
- 개인용이라 코드 서명은 하지 않아요. 그래서 새 버전을 설치할 때마다 처음 실행에서 경고가 떠요.
  - Windows: "Windows의 PC 보호" → "추가 정보" → "실행"
  - Mac: "손상되었기 때문에 열 수 없습니다"가 뜨면 터미널 명령 한 줄로 해결 (설치 안내에 포함)
- 자동 업데이트는 넣지 않아요(사용자 결정). 새 버전은 GitHub 릴리스에서 받아 덮어 설치해요. 설정·앱키·화면 배치는 설치 폴더가 아니라 데이터 폴더(Windows `%APPDATA%\Terminal`, Mac `~/Library/Application Support/Terminal`)에 있어서 그대로 남아요.

**종료 동작**

| 상황 | 동작 |
|---|---|
| 메인 창을 닫을 때 | 떼어낸 창까지 포함해 앱 전체 종료 |
| 떼어낸 창을 닫을 때 | 그 패널만 닫힘. 앱은 계속 실행 |
| 종료할 때 | 실시간 구독 해제, 저장 안 한 분봉을 DB에 저장, 창 배치 자동 저장 |
| 다시 켤 때 | 마지막 창 배치를 그대로 복원. 꺼져 있던 동안 빠진 시세는 소스가 과거 데이터를 주는 범위에서만 채움. 환율 분봉처럼 과거 데이터가 없을 수 있는 것은 빈 채로 남음 |
| 앱 아이콘을 또 눌렀을 때 | 두 번째 실행 대신 이미 켜진 창을 앞으로 가져옴 |
| Mac | Mac 앱은 원래 창을 닫아도 계속 켜져 있는 게 관례지만, 창을 닫으면 종료되게 맞춰요 |

앱이 꺼져 있으면 시세 수집과 알림도 멈춰요. 알림은 앱이 켜져 있을 때만 동작해요.

## 멀티 모니터

| 항목 | 설계 |
|---|---|
| 창 떼어내기 | 패널을 메인 창 밖으로 끌어내면 새 창이 되고, 원하는 모니터로 옮길 수 있어요 |
| 화면 탭과 워크스페이스 | 창마다 맨 위에 자기 화면 탭이 있어요. 탭을 바꾸면 그 창의 배치만 바뀌어요. 모든 창과 탭을 묶은 것이 워크스페이스 하나예요([02](02-ui.md)) |
| 배치 기억 | 어느 모니터의 어느 위치에 어떤 창이 있었는지 저장하고 다음 실행 때 복원해요 |
| 모니터가 빠졌을 때 | 사라진 모니터에 있던 창을 메인 모니터로 모아요. 창이 화면 밖에 숨어 버리는 문제를 막아요 |
| 모니터마다 다른 배율 | 창을 옮기면 그 모니터의 배율로 다시 그려서 차트가 흐릿해지지 않아요 |
| 실시간 구독 | 어떤 창에도 안 보이는 종목은 구독을 해제해요 |
| 연동 그룹 | 같은 색 그룹이면 다른 모니터에 있는 창끼리도 종목이 함께 바뀌어요 |
| 키 입력 | 지금 포커스가 있는 창의 패널로 들어가요 |

## Windows와 Mac 함께 지원하기

| 항목 | 문제 | 대응 |
|---|---|---|
| 단축키 | Windows는 `Ctrl`, Mac은 `Cmd`. Mac 노트북은 F키에 `fn`이 필요 | OS에 따라 자동으로 바꾸고, F키에 의존하지 않아요 |
| 폰트 | OS마다 기본 폰트가 달라 화면 밀도가 달라짐 | 폰트 파일을 앱에 포함해요 |
| 데이터 저장 위치 | Windows `%APPDATA%`, Mac `~/Library/Application Support` | OS에 맞게 자동 처리 |
| 화면 배율 | Windows 노트북은 125%·150% 배율이 흔해요 | 배율에 맞춰 선명하게 그려요 |
| 잠자기 | 노트북을 덮었다 열면 시세 연결이 끊김 | 자동 재연결 |
| OS별 빌드가 필요한 라이브러리 | 플랫폼마다 빌드 문제가 잘 생김 | 최소한으로만 사용 |
| 스크립트 줄바꿈 | `.bat`은 CRLF, `.command`는 LF여야 실행됨 | `.gitattributes`로 고정 |
| Electron 기본 단축키 | Ctrl+R(새로고침), Ctrl+W(창 닫기), Ctrl+Shift+I(개발자 도구) 등이 기본으로 걸려 있음 | 메뉴를 직접 만들어요. Windows는 메뉴 막대를 두지 않고, Mac은 복사·붙여넣기가 되도록 기본 App·Edit·Window 메뉴를 남겨요. 배포판에서는 새로고침·개발자 도구 단축키를 빼고, Ctrl+R은 명령 기록 검색에 써요. Windows의 Ctrl+W(창 닫기)도 빼요. 터미널 습관으로 단어를 지우려다 창이 닫히는 일을 막아요. 자세한 내용은 [05](05-command-line.md) §10.3 |

지금은 Mac이 없어서 Mac에서 직접 테스트할 수 없어요. 빌드할 때 앱을 자동으로 실행해 스크린샷을 찍는 검사로 보완해요. 다만 한글 입력이나 Mac 전용 단축키처럼 손으로 쳐 봐야 하는 동작은 스크린샷으로 확인할 수 없어요. 이런 것은 Mac 기기를 쓸 수 있을 때 확인해요. 그 전에는 확인하지 못한 채로 남아요.

## 보안

- 한국투자증권 앱키·앱시크릿과 다른 데이터 소스의 키는 PC 안에 **암호화해서** 저장해요. 화면 코드에 넣거나 GitHub에 올리지 않아요.
- 한국투자증권 앱키는 시세 조회용이어도 **주문까지 낼 수 있는 키**예요. 앱에는 매매 기능이 없지만 키가 새면 위험해요. 그래서 시세용으로는 잔고가 없는 별도 계좌의 키를 쓰는 것을 권해요.
- 서버는 이 PC 안에서만 접속할 수 있어요. 그래도 같은 PC의 웹 브라우저에서 연 악성 사이트가 내장 서버로 요청을 보낼 수 있어서 막아 둬요.
  - 실행할 때마다 새로 만드는 무작위 토큰을 요청마다 확인해요.
  - `Host`·`Origin` 헤더를 엄격하게 검사하고, 다른 사이트의 접근(CORS)을 허용하지 않아요.
- Electron 보안 설정을 켜요: 화면과 시스템 기능 분리(contextIsolation), 샌드박스, Node 기능 끄기. 뉴스·공시 원문은 앱 화면에 HTML로 바로 넣지 않고 외부 브라우저나 분리된 창으로 열어요.
- 시세를 다른 사람에게 보여주는 기능은 만들지 않아요. FRED, KRX, 공공데이터처럼 출처 표시가 의무인 데이터는 화면에 출처를 보여줘요.

## 성능 원칙

이 앱에서 느려질 수 있는 곳은 서버가 아니라 **차트 수십 개를 그리는 화면**이에요. 언어가 아니라 그리는 방식으로 해결해요.

- 캔버스 기반 차트를 써요.
- 값이 바뀐 셀만 다시 그려요.
- 갱신을 화면 주사율(초당 약 60회)에 맞춰 묶어서 처리해요.
- 시세 메시지 해석은 별도 스레드에서 해요.
- 무거운 계산이 생기면 그 부분만 나중에 Rust 등으로 바꿔 끼워요. 지금 미리 하지는 않아요.
