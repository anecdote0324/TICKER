# 03 기능 코드와 단계별 범위

블룸버그처럼 기능마다 1~4글자 코드가 있고(`N`은 한 글자), 커맨드 라인에서 코드로 불러요.

## 기능 코드 목록

| 코드 | 이름 | 하는 일 | 종목 필요 | 단계 |
|---|---|---|---|---|
| **MON** | 관심종목 | 내가 고른 국내·미국 주식, 코인, 환율을 한 목록에 섞어서 보여줘요. 주식·코인은 실시간이고, 환율은 30~60초마다, 실시간 구독 한도를 넘는 주식은 몇 초마다 갱신돼요 | 불필요 | v0.1 |
| **GP** | 가격 차트 | 일봉·주봉·월봉 캔들 차트, 거래량, 이동평균선 | 필요 | v0.1 |
| **GIP** | 장중 차트 | 오늘 장중 움직임 (분봉) | 필요 · 데이터 소스가 분봉을 줄 때만 | v0.1 |
| **WEI** | 세계 지수 | 미주·유럽·아시아 주요 지수. 데이터 소스는 확인 필요([04](04-data-sources.md)) | 불필요 | v0.1 |
| **FXC** | 환율 매트릭스 | 주요 통화끼리의 환율 표 | 불필요 | v0.1 |
| **CRYP** | 코인 시세판 | Binance USDT 현물 주요 코인 | 불필요 | v0.1 |
| **N** | 뉴스·공시 | DART 공시와 RSS 뉴스 헤드라인 | 선택 | v0.2 |
| **DES** | 종목 개요 | 시가총액, PER, 52주 고저 등 기본 정보 | 필요 | v0.2 |
| **COMP** | 비교 차트 | 여러 종목·지수를 한 차트에 겹쳐 비교 | 여러 개(인자) | v0.2 |
| **HMAP** | 업종 히트맵 | 업종·종목의 기간별 등락을 색 셀로 | 지수 하나(인자) | v0.2 |
| **IMAP** | 업종 타일 | 업종별 등락 색 타일 | 지수 하나(인자) | v0.2 |
| **MOST** | 상위 종목 | 거래량·거래대금·등락률 상위 | 시장 하나(인자) | v0.2 |
| **FA** | 재무제표 | 손익계산서, 재무상태표 등. 국내 주식은 DART, 미국 재무제표 소스는 미정 | 필요 · 주식만 | v0.3 |
| **ECO** | 경제 캘린더 | 경제지표 발표 일정. 데이터 소스 미정 | 불필요 | v0.3 |
| **GC** | 금리 커브 | 국채 금리 커브. 데이터 소스 미정 | 불필요 | v0.3 |
| **GRID** | 소형 차트 격자 | 여러 지수·환율의 소형 차트를 격자로 | 여러 개(인자) | v0.3 |
| **MAP** | 세계지도 | 지역별 시장 현황을 지도 위에 | 불필요 | v0.3 |
| **PORT** | 포트폴리오 | 내 보유 종목 손익. 직접 입력하거나 CSV로 가져오기 | 불필요 | v0.3 |
| **ALRT** | 알림 | 가격·뉴스 조건 알림. 앱이 켜져 있을 때만 동작하고, Windows 알림 센터 / Mac 알림 센터로 보여요 | 선택 | v0.3 |

"인자"는 기능 뒤에 붙이는 추가 값이에요. 예를 들어 `COMP` 뒤에 비교할 종목들을, `HMAP` 뒤에 지수 하나를 붙여요.

**자산군별로 쓸 수 있는 기능** (자동완성 목록에 나오는 기본 순서)

| 자산군 | 기능 |
|---|---|
| EQUITY (주식) | GP, GIP, DES, N, COMP, FA |
| CRYPTO (코인) | GP, GIP, COMP |
| CURNCY (환율) | GP, GIP, COMP |
| INDEX (지수) | GP, GIP, COMP |

쓸 수 있는 기능은 직접 목록으로 정하지 않고 **계산해서** 정해요. 예를 들어 환율 소스가 분봉을 주지 않으면 USDKRW에서는 GIP가 자동으로 빠져요. 분봉 제공 여부는 [07](07-open-questions.md)에서 확인해요.

## 단계별 범위

### v0.1: 뼈대와 실시간 시세

목표는 **블룸버그처럼 보이고 실제로 움직이는 화면**이에요.

| 구분 | 내용 |
|---|---|
| 앱 기반 | Electron 앱, Modern Terminal 테마, 창 관리, 워크스페이스 저장·복원, 멀티 모니터(창 떼어내기) |
| 커맨드 라인 | 자동완성(네 가지 도움 수준 포함), 한글 이름·초성 검색, 한/영 실수 교정 |
| 설정 | 설정 창. 자동완성 도움 수준, Enter 동작(v0.1은 "지금 기능 유지" 하나, 선택지는 v0.2부터), 입력 도우미 |
| 데이터 | 한국투자증권(국내·미국), Binance(코인), 환율 소스 |
| 기능 | MON, GP, GIP, WEI, FXC, CRYP |

### v0.2: 정보 확장

- N, DES, COMP, HMAP, IMAP, MOST
- 자동완성 설명 창에 간단 시세 표시
- "종목만 입력하고 Enter"의 블룸버그식 기능 메뉴 선택지

### v0.3: 분석과 개인화

- FA, ECO, GC, GRID, MAP, PORT, ALRT

### 그 이후 (선택)

- AI 기능 (뉴스 요약, 자연어 명령)
- 자동 업데이트
- Classic 테마 (넣을지 미정, [07](07-open-questions.md))

## 뺀 기능

| 기능 | 이유 |
|---|---|
| KIMP (김치 프리미엄) | Upbit 원화 가격이 필요한데, 코인은 Binance USDT만 쓰기로 함 |
| 증권 계좌 잔고 자동 연동 | 매매 계좌(신한투자증권)는 Mac에서도 쓸 수 있는 잔고 조회 방법을 찾지 못했어요. PORT는 직접 입력이나 CSV로 대신해요 |
| 주문 기능 | 이 앱은 시세를 보는 용도예요. 매매는 기존 증권사 앱에서 해요 |
