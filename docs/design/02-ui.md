# 02 화면 디자인

목업 (비공개 claude.ai 링크): https://claude.ai/artifact/1AE6PgM1jVf4bTsRT85xoV

## 컨셉: Modern Terminal

참고한 것은 블룸버그의 최신 화면이에요. 옛날 CRT처럼 모든 글자를 앰버색으로 칠하지 않고, **흰 숫자에 회색 라벨, 주황은 포인트로만** 써요.

참고 이미지에서 읽은 특징:

| 관찰 | 의미 |
|---|---|
| 순검정 배경 위에 창 수십 개가 빽빽하게 배치됨 | 고정 4분할이 아니라 자유 배치 창(런치패드) 방식 |
| 주황은 헤더와 탭 바에만 쓰임 | 주황은 UI 포인트 색 |
| 초록·빨강을 셀 배경에도 칠함 | 히트맵형 표 |
| 표 안의 흰색 스파크라인 | 숫자와 추세를 한 줄에서 |
| 소형 차트 격자, 색 타일 격자 | 여러 종목을 한눈에 비교 |
| 회색 띠로 구분된 그룹 헤더 | 지역별·종류별 묶음 |
| 검정에서 주황으로 번지는 그라데이션 | 작업 화면이 아니라 로그인·시작 화면에만 쓸 요소 |

## 원칙

1. **데이터 자체가 장식**: 그림자, 큰 둥근 모서리, 패널 안 그라데이션은 쓰지 않아요. 그림자는 자동완성 목록처럼 위에 떠 있는 요소에만 써요.
2. **색에는 의미가 있을 때만**: 주황은 포커스·강조, 초록·빨강(또는 빨강·파랑)은 상승·하락, 파랑은 선택, 흰색은 값, 회색은 라벨.
3. **고밀도**: 글자 11~12px, 행 높이 22~24px, 패널 사이 간격 1~2px.
4. **숫자 정렬**: 자릿수 폭이 같은 숫자를 쓰고 오른쪽 정렬해서, 값이 바뀌어도 글자가 흔들리지 않게 해요.
5. **색만으로 구분하지 않기**: 등락에는 항상 ▲▼를 붙이고, 오류 표시에는 ✗를 붙여요.

## 색

| 용도 | 값 |
|---|---|
| 전체 배경 | `#000000` |
| 패널 배경 | `#0A0A0A` |
| 패널 헤더, 그룹 헤더 띠 | `#141414` ~ `#161616` |
| 구분선 | `#1E1E1E` ~ `#242424` |
| 강조 (주황) | `#FB8B1E` |
| 값 (흰색) | `#E6E6E6` ~ `#F2F2F2` |
| 라벨 (회색) | `#8C8C8C` |
| 자산군 칩 (블룸버그 노란 키) | `#F5C542` 바탕에 검정 글자 |
| 선택된 행 | `#16325E` |
| 흐린 글씨 (자동완성 미리보기) | `#7A7A7A` 이상 |
| 연동 그룹 | 파랑 `#3DA5FF`, 보라 `#B98CFF` 등. 연동 없음은 회색 테두리 |

**등락 색은 설정에서 고를 수 있어요.**

| 방식 | 상승 | 하락 |
|---|---|---|
| 글로벌식 | 초록 `#3FD08A` ▲ | 빨강 `#FF5F57` ▼ |
| 한국식 | 빨강 `#FF5F57` ▲ | 파랑 `#4C9AFF` ▼ |

기본값은 아직 정하지 않았어요. [07 미정 사항](07-open-questions.md)에 있어요.

히트맵 셀은 등락 폭에 따라 같은 색의 어두운 단계에서 밝은 단계로 칠하고, 글자는 항상 흰색이에요.

어두운 배경 위의 글자는 모두 명도 대비 4.5:1 이상을 지켜요. `#8C8C8C` 회색 라벨도 기준을 넘어요.

## 글꼴

| 용도 | 글꼴 |
|---|---|
| 숫자, 종목 코드, 기능 코드 | IBM Plex Mono |
| 한글 라벨, 본문 | IBM Plex Sans KR |
| 커맨드 라인 | 한글이 정확히 영문 2칸 폭인 고정폭 글꼴 후보 (D2Coding 등). 구현할 때 확정해요 |

글꼴 파일은 앱에 포함해서 Windows와 Mac에서 똑같이 보이게 해요.

## 패널 구조

모든 패널은 같은 틀을 써요.

```
┌ 2 │ 005930 KS Equity GP              ■(연동 색) ⤢ □ ✕ ┐  ← 1줄: 패널 번호, 커맨드 라인, 연동 그룹, 떼어내기·최대화·닫기
│ GP 가격 차트 · 005930 KS 삼성전자     1D 5D 1M [3M] … │  ← 2줄: 기능 코드(주황), 제목, 기능별 도구
│ 본문                                                 │
```

- 1줄의 커맨드 라인은 평소에는 지금 실행 중인 명령을 흐리게 보여주고, 입력을 시작하면 입력칸이 돼요.
- 포커스가 있는 패널은 주황 테두리와 주황 번호 칸으로 표시해요.
- 커맨드 라인과 자동완성의 자세한 동작은 [05 커맨드 라인과 자동완성](05-command-line.md)에 있어요.

## 화면 공통 요소

| 위치 | 내용 |
|---|---|
| 맨 위 줄 | 로고, 워크스페이스 탭(Market Pulse, Deep Dive, +), 날짜, 서울·도쿄·런던·뉴욕 시계와 장 상태 |
| 맨 아래 위쪽 줄 | 시세가 흐르는 띠 (주요 지수, 환율, 코인) |
| 맨 아래 줄 (상태 표시줄) | 연결 상태(한국투자증권 실시간 구독 수, Binance, 환율 갱신 주기), 연동 그룹, **자동완성 도움 수준 빠른 전환 `도움: 입문 ▾`**, 명령 팔레트(Ctrl+K)와 도움말 안내 |

## 화면 배치 예시

**모니터 1 · Market Pulse** (목업으로 만든 화면, 1920×1080)

```
┌──────────────┬──────────────────────────────┬──────────────────────┐
│ 1 MON        │ 2 GP 가격 차트                │ 3 WEI 세계 지수        │
│ 관심종목      │   캔들 + 거래량 + 이동평균선    │   미주 / 유럽 / 아시아  │
│ 국내·미국·    │   (자동완성 목록이 열린 상태)   ├──────────────────────┤
│ 코인·환율     │                              │ 6 FXC 환율 매트릭스    │
├──────────────┼──────────────────────────────┼──────────────────────┤
│ 4 N          │ 5 HMAP 업종 히트맵             │ 7 CRYP 코인 시세판     │
│ 뉴스·공시     │   스파크라인 + 기간별 등락 색    │   Binance USDT 현물    │
└──────────────┴──────────────────────────────┴──────────────────────┘
 시세 흐름 띠
 상태 표시줄
```

**모니터 2 · Deep Dive** (아직 목업 없음)

```
┌──────────────────┬──────────────────────┬──────────────────────┐
│ WEI              │ IMAP 업종 타일          │ GP + 가격대별 거래량    │
│ 지역별 그룹 헤더   ├──────────────────────┼──────────────────────┤
│                  │ GRID 3×3 소형 차트      │ GIP 분봉 + 거래량       │
│                  │                       ├──────────────────────┤
│                  │                       │ MAP 세계지도            │
└──────────────────┴──────────────────────┴──────────────────────┘
```

워크스페이스는 사용자가 자유롭게 바꾸고 저장할 수 있어요. 위 배치는 처음 제공하는 기본값이에요.

## 위젯 표현

| 위젯 | 표현 |
|---|---|
| 관심종목 (MON) | 그룹 헤더 띠, 이름 + 코드, 현재가, 등락(▲▼ + %), 스파크라인 |
| 가격 차트 (GP) | 캔들, 거래량 막대, 이동평균선(20일 주황, 60일 밝은 회색), 오른쪽 가격 축, 현재가 주황 꼬리표, 왼쪽 위 시가·고가·저가·종가 |
| 세계 지수 (WEI) | 지역별 그룹, 현재·변동·변동률·시간(장중/개장전/마감)·스파크라인 |
| 환율 매트릭스 (FXC) | 행 1단위당 열 통화, 셀 배경을 등락 색으로 |
| 코인 시세판 (CRYP) | 심볼 + 한글명, 현재가(USDT), 24시간 등락, 거래대금, 24시간 범위 막대 |
| 뉴스·공시 (N) | 시간, 출처 표시(DART 주황 테두리, RSS 회색), 관련 종목, 제목 |
| 업종 히트맵 (HMAP) | 업종, 1개월 추세 스파크라인, 기간별(1D·1W·1M·3M·YTD) 등락 색 셀 |

## 인터랙션

- **틱 플래시**: 값이 바뀌면 셀 배경이 0.3초 동안 등락 색으로 반짝여요.
- **십자선 동기화**: 한 차트에 마우스를 올리면 다른 차트에도 같은 시점에 세로선이 표시돼요.
- **연동 그룹**: 창마다 색 표시를 두고, 같은 색끼리 종목이 함께 바뀌어요.
- **창 조작**: 드래그, 크기 조절, 가장자리에 붙이기, 창 안 탭, 최대화, 다른 모니터로 떼어내기.
- **F키 주의**: 블룸버그는 자산군을 F키로 고르지만 브라우저·Electron 기본 단축키와 겹쳐요. 대신 입력한 단어(`EQ`, `CRY` 등)와 별도 단축키를 써요. 자세한 내용은 05 문서에 있어요.

## 테마

- 기본은 **Modern** (이 문서의 색).
- 모든 글자를 앰버색으로 칠하는 **Classic** 테마는 나중에 선택 사항으로 넣어요.
- 강조 색은 설정에서 바꿀 수 있어요 (주황, 노랑, 파랑, 흰색 후보).
