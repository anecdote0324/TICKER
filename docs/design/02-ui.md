# 02 화면 디자인

목업 (비공개 claude.ai 링크): https://claude.ai/artifact/1AE6PgM1jVf4bTsRT85xoV — 더 이상 고치지 않아요. 화면의 기준은 실제 앱과 이 문서예요

## 컨셉: 블룸버그 터미널

**블룸버그 터미널과 거의 같게** 만들어요(사용자 결정. 혼자 쓰는 앱이에요). 값은 흰 숫자이고, 라벨·표 머리줄·패널 제목·종목 이름은 앰버, 켜진 탭·버튼과 기능 코드는 앰버 바탕에 검정 글자예요. 묶음 줄은 옛 블룸버그 화면의 남색 띠, 등락은 블룸버그의 초록·빨강이에요. 색은 사용자가 준 블룸버그 화면 사진(최신 런치패드 화면, 옛 선물 화면)에서 뽑았어요.

처음에는 흰 숫자에 회색 라벨, 주황은 포인트로만 쓰는 **Modern Terminal**이었어요. 주황을 더 적극적으로, 블룸버그와 같은 색감으로 바꿨어요.

참고 이미지에서 읽은 특징:

| 관찰 | 의미 |
|---|---|
| 순검정 배경 위에 창 수십 개가 빽빽하게 배치됨 | 고정 4분할이 아니라 자유 배치 창(런치패드) 방식 |
| 주황(앰버)이 헤더·탭 바·라벨·버튼에 넓게 쓰임 | 라벨·제목·켜진 버튼은 앰버 |
| 옛 화면: 노란 앰버 설명 글자, 남색 머리줄 띠, 빨간 메뉴 버튼 | 종목 이름은 옅은 앰버, 묶음 줄은 남색 띠 |
| 초록·빨강을 셀 배경에도 칠함 | 히트맵형 표 |
| 표 안의 흰색 스파크라인 | 숫자와 추세를 한 줄에서 |
| 소형 차트 격자, 색 타일 격자 | 여러 종목을 한눈에 비교 |
| 회색 띠로 구분된 그룹 헤더 | 지역별·종류별 묶음 |
| 검정에서 주황으로 번지는 그라데이션 | 작업 화면이 아니라 로그인·시작 화면에만 쓸 요소 |

## 원칙

1. **데이터 자체가 장식**: 그림자, 큰 둥근 모서리, 패널 안 그라데이션은 쓰지 않아요. 그림자는 자동완성 목록처럼 위에 떠 있는 요소에만 써요.
2. **색에는 의미가 있을 때만**: 앰버는 라벨·제목·포커스·켜진 버튼, 초록·빨강(또는 빨강·파랑)은 상승·하락, 파랑 배경은 선택, 남색 띠는 묶음, 흰색은 값, 회색은 보조 설명.
3. **고밀도**: 글자 11~12px, 행 높이 22~24px, 패널 사이 간격 1~2px.
4. **숫자 정렬**: 자릿수 폭이 같은 숫자를 쓰고 오른쪽 정렬해서, 값이 바뀌어도 글자가 흔들리지 않게 해요.
5. **색만으로 구분하지 않기**: 등락에는 항상 ▲▼를 붙이고, 오류 표시에는 ✗를 붙여요.
6. **늦은 값은 늦다고 표시하기**: 실시간이 아닌 값에는 항상 신선도 배지를 붙여요. 배지가 없는 값은 실시간이에요([데이터 신선도 표시](#데이터-신선도-표시)).

## 색

| 용도 | 값 |
|---|---|
| 전체 배경, 패널 배경 | `#000000` |
| 패널 헤더, 표 머리줄 | `#181818` |
| 묶음 줄(국내·미국, 한국·미주 등) | 남색 `#0C2266` 띠에 흰 글자 |
| 구분선 | `#1C1C1C` ~ `#262626` |
| 강조 (앰버) | `#FFA028`. 켜진 화면 탭·도구 버튼·기능 코드 배지는 이 색 바탕에 검정 글자. 로고·활성 패널 테두리·현재가 꼬리표·20봉선도 이 색 |
| 라벨·표 머리줄·패널 제목 (앰버) | 강조 색을 12% 어둡게(`#E18D23`). 강조 색을 바꾸면 따라 바뀌어요 |
| 종목 이름 (옅은 앰버) | 강조 색과 흰색을 섞은 색(`#FFC781`) |
| 값 (흰색) | `#F0F0F0` ~ `#FFFFFF` |
| 보조 설명·코드 (회색) | `#8C8C8C` |
| 자산군 칩 (블룸버그 노란 키) | `#F5C542` 바탕에 검정 글자 |
| 선택된 행 | 파랑 `#0A4FA8` |
| 흐린 글씨 (자동완성 미리보기) | `#7A7A7A` 이상. 헤더 띠 위에서는 `#808080` 이상 |
| 연동 그룹 | 파랑 `#3DA5FF`, 보라 `#B98CFF` 등. 연동 없음은 회색 테두리 |
| 상태 표시줄 연결 점 | 연결됨은 초록(상승 색) 점, 끊김·연결 중은 빈 회색 테두리와 `⚠`. 데모는 실제 연결이 아니라서 회색 점. 내장 서버가 15초 넘게 아무것도 보내지 않으면(서버는 시세가 없어도 5초마다 상태를 보내요) 모든 점을 `⚠`로 바꾸고 `⚠ 내장 서버 응답 없음`을 보여 줘요. 멈춘 서버의 마지막 상태를 초록으로 보여 주지 않으려는 거예요 |

**등락 색은 설정에서 고를 수 있어요.**

| 방식 | 상승 | 하락 |
|---|---|---|
| 글로벌식 (기본) | 초록 `#1FBF3F` ▲ | 빨강 `#E8203C` ▼ |
| 한국식 | 빨강 `#E8203C` ▲ | 파랑 `#2F7BFF` ▼ |

기본값은 **글로벌식**이에요(사용자 결정). 블룸버그 화면 사진에서 뽑은 초록·빨강이에요. 국내 HTS처럼 보고 싶으면 설정에서 한국식으로 바꿔요.

히트맵 셀은 등락 폭에 따라 같은 계열의 어두운 색에서 밝은 색으로 칠하고, 글자는 항상 흰색이에요.

일반 패널 위의 글자는 명도 대비 4.5:1 이상을 지켜요. `#8C8C8C` 회색 글자와 앰버 라벨(`#E18D23`)도 검정·`#181818` 위에서 기준을 넘어요. 헤더 띠(`#181818`) 위의 흐린 글씨는 `#808080` 이상, 선택된 행(`#0A4FA8`) 위의 회색 글자는 `#A0A0A0` 이상으로 밝게 그려요. 앰버 바탕(켜진 탭·버튼)의 글자는 검정이에요. 히트맵의 가장 밝은 색도 흰 글자와 4.5:1 이상이 되게 어둡게 잡아요.

## 글꼴

| 용도 | 글꼴 |
|---|---|
| 숫자, 종목 코드, 기능 코드 | IBM Plex Mono |
| 한글 라벨, 본문 | IBM Plex Sans KR |
| 커맨드 라인 | D2Coding(NAVER, OFL). 한글이 정확히 영문 2칸 폭인 고정폭이라 입력칸과 거울 줄의 글자 위치가 맞아요. 앱에는 woff2(보통·굵게)만 넣어요 |

글꼴 파일은 앱에 포함해서 Windows와 Mac에서 똑같이 보이게 해요. 글꼴 라이선스는 설정 → 정보에 적어요.

글자 크기 설정은 화면 전체(표·차트·커맨드 라인·떼어낸 창)를 같은 배율(90~135%)로 키워요. 데스크톱 앱은 Electron 확대 배율을 모든 창에 걸어요.

## 패널 구조

모든 패널은 같은 틀을 써요.

```
┌ 2 │ 005930 KS EQUITY GP              ■(연동 색) ⤢ □ ✕ ┐  ← 1줄: 패널 번호, 커맨드 라인, 연동 그룹, 떼어내기·최대화·닫기
│ GP 가격 차트 · 005930 KS 삼성전자     1D 5D 1M [3M] … │  ← 2줄: 기능 코드(주황), 제목, 기능별 도구
│ 본문                                                 │
```

- 1줄의 커맨드 라인은 평소에는 지금 실행 중인 명령을 흐리게 보여주고, 입력을 시작하면 입력칸이 돼요.
- 포커스가 있는 패널은 주황 테두리와 주황 번호 칸으로 표시해요.
- 커맨드 라인과 자동완성의 자세한 동작은 [05 커맨드 라인과 자동완성](05-command-line.md)에 있어요.

## 화면 공통 요소

| 위치 | 내용 |
|---|---|
| 맨 위 줄 | 로고, 화면 탭(Market Pulse, Deep Dive, 탭마다 닫기 ✕, 추가 +), 패널 추가, 워크스페이스 메뉴, 날짜, 서울·도쿄·런던·뉴욕 시계와 장 상태 |
| 맨 아래 위쪽 줄 | 시세가 흐르는 띠 (주요 지수, 환율, 코인). 실시간이 아닌 항목에는 짧은 신선도 배지 |
| 맨 아래 줄 (상태 표시줄) | 연결 상태(한국투자증권 실시간 구독 수, Binance, 환율 갱신 주기. 멈춘 소스는 `⚠`), 연동 그룹(쓰고 있는 색마다 색 네모와 지금 종목 코드. 누르면 그 그룹의 첫 패널로), **자동완성 도움 수준 빠른 전환 `도움: 입문 ▾`**, 명령 팔레트(Ctrl+K)와 도움말 안내. 단축키 안내는 설정에서 바꾼 키를 따라가요 |

## 화면 배치 예시

**모니터 1 · Market Pulse** (1920×1080)

```
┌──────────────┬──────────────────────────────┬──────────────────────┐
│ 1 MON        │ 2 GP 가격 차트                │ 3 WEI 세계 지수        │
│ 관심종목      │   캔들 + 거래량 + 이동평균선    │   미주 / 유럽 / 아시아  │
│ 국내·미국·    │   (자동완성 목록이 열린 상태)   ├──────────────────────┤
│ 코인·환율     │                              │ 6 FXC 환율 매트릭스    │
├──────────────┼──────────────────────────────┼──────────────────────┤
│ 4 N          │ 5 HMAP 업종 히트맵             │ 7 CRYP 코인 시세판     │
│ 뉴스·공시     │   스파크라인 + 기간별 등락 색    │   Binance USDT 현물    │
└──────────────┴──────────────────────────────┴──────────────────────┘
 시세 흐름 띠
 상태 표시줄
```

4번 N과 5번 HMAP은 v0.2 기능이에요. v0.2부터 기본 배치가 이 그림이에요.

- **v0.1 기본 배치**: 4번 자리에는 두 번째 관심종목 목록(MON)을, 5번 자리에는 1번 MON과 같은 연동 그룹의 GIP 분봉 차트를 둬요. 1번에서 종목을 고르면 2번 일봉(GP)과 5번 분봉(GIP)이 함께 바뀌어요.
- **v0.2부터**: 기본 배치의 4번·5번이 그림처럼 N(전체 뉴스)과 HMAP(코스피 업종)이에요. 둘 다 연동 그룹 없이 시작하고, 1번 MON은 국내·미국·코인·환율 묶음을 모두 보여 줘요. 사용자가 이미 바꿔서 저장한 배치는 건드리지 않아요(워크스페이스 메뉴의 기본 배치로 새로 시작으로 바꿔요).

**모니터 2 · Deep Dive** (목표 배치 · 목업 없음)

```
┌──────────────────┬──────────────────────┬──────────────────────┐
│ WEI              │ IMAP 업종 타일          │ GP + 가격대별 거래량    │
│ 지역별 그룹 헤더   ├──────────────────────┼──────────────────────┤
│                  │ GRID 3×3 소형 차트      │ GIP 분봉 + 거래량       │
│                  │                       ├──────────────────────┤
│                  │                       │ MAP 세계지도            │
└──────────────────┴──────────────────────┴──────────────────────┘
```

- 모니터 2는 위 그림을 목표로 해요. IMAP은 v0.2, GRID·MAP은 v0.3 기능이에요. 그래서 기본 배치에는 v0.3에서 이 기능들이 다 생긴 뒤에 넣어요. 그 전에는 모니터 2에 기본 창을 띄우지 않고, 사용자가 패널을 떼어 옮겨서 써요.
- **화면 탭과 워크스페이스**
  - 창(모니터)마다 맨 위 줄에 자기 화면 탭이 있어요. Market Pulse와 Deep Dive는 화면 탭 이름의 예시이고, 사용자가 이름을 바꾸거나(두 번 누르기) 탭을 추가(`+`)할 수 있어요.
  - 탭 이름 오른쪽의 `✕`로 그 화면 탭을 닫아요. 안에 있던 패널과 그 화면에서 떼어낸 창도 함께 닫혀요. 바로 뜨는 알림의 `되돌리기`로 배치까지 그대로 복구해요. 탭이 하나만 남으면 `✕`를 보여 주지 않아요.
  - 탭을 바꾸면 그 창의 패널 배치만 바뀌어요. 다른 모니터의 창은 그대로예요.
  - **화면 떼어내기**: 탭 이름 오른쪽의 떼어내기 버튼(↗)을 누르면 그 화면이 패널 배치째로 새 창이 돼요. 다른 모니터로 옮겨 쓰려는 거예요.
    - 떼어낸 창의 맨 위 줄에는 로고, 그 창의 화면 탭(탭마다 메인 창으로 돌려놓기), `+`(이 창에 화면 탭 추가, v0.2), `패널 추가`가 있어요. 그 창 안에서도 패널을 끌어 옮기고, 크기를 바꾸고, 패널 하나를 다시 떼어낼 수 있어요.
    - 떼어낸 창 안의 화면 탭(v0.2): 화면마다 어느 창에 있는지(창 id)를 기억해요. 창 안에서 탭을 고르고, 이름을 바꾸고, 둘 이상이면 닫아요. 창의 닫기(X)를 누르면 그 창의 화면이 모두 메인 창으로 돌아와요.
    - 메인 창의 화면 탭에는 떼어낸 화면이 흐린 기울임 글씨와 ↗ 표시로 남아요. 누르면 그 창을 앞으로 가져오고, 옆의 돌려놓기 버튼(↙)을 누르면 메인 창으로 돌아와요. 떼어낸 창의 닫기(X)도 같아요.
    - 메인 창에는 화면이 하나 이상 남아야 해요. 그래서 메인 창에 남은 마지막 화면에는 떼어내기와 `✕`가 없어요.
    - 떼어낸 창에서 연 명령 팔레트(Ctrl+K)와 도움말은 그 창 안에 떠요. 설정 창은 메인 창에 뜨고, 메인 창을 앞으로 가져와요.
    - 떼어낸 창의 위치·크기를 기억해요. 앱을 끌 때 떼어낸 화면은 다음 실행 때 같은 자리의 창으로 다시 열려요. 창을 열 수 없으면(브라우저의 팝업 차단 등) 메인 창의 화면 탭으로 두고 알려 줘요.
    - 떼어낸 창도 같은 프로그램 안의 창이라 시세·종목 목록·설정·연동 그룹을 메인 창과 함께 써요.
  - 모든 창의 위치와 모든 탭의 배치를 묶은 것이 **워크스페이스** 하나예요. 워크스페이스는 이름을 붙여 저장하고 불러올 수 있어요. 앱을 끄면 지금 워크스페이스가 자동으로 저장되고, 다음 실행 때 복원돼요.
  - 맨 위 줄의 `워크스페이스 ▾` 메뉴에서 지금 배치를 이름을 붙여 저장하고, 저장한 것을 불러오거나 덮어쓰거나 지워요. `기본 배치로 새로 시작`도 여기 있어요. 불러오기·지우기·새로 시작은 알림의 `되돌리기`로 바로 전으로 돌아가요.

## 위젯 표현

| 위젯 | 표현 |
|---|---|
| 관심종목 (MON) | 그룹 헤더 띠, 이름 + 코드, 현재가, 등락(▲▼ + %), 스파크라인. 위쪽 묶음 탭(전체·국내 등)은 패널마다 기억해요(화면을 떼어냈다 돌려놓거나 다시 켜도 그대로) |
| 가격 차트 (GP) | 캔들, 거래량 막대, 이동평균선(20·60봉, 주황·밝은 회색), 오른쪽 가격 축, 현재가 주황 꼬리표, 왼쪽 위 시가·고가·저가·종가. 봉 크기 버튼 `1시간 2시간 4시간 일 주 월`(시간봉은 주식·코인만)과 기간 버튼 1M·3M·6M·1Y·MAX(일봉 기본 3M, 시간봉 기본 1M, 따로 기억). 시간봉은 과거까지 이어서 보여 주고 가로축에 시각을 붙여요. 국내 2시간봉은 09·11·13·15시, 4시간봉은 09·13시 칸이고(정규장이 시작하는 정각에 맞춤), 미국은 뉴욕 정각(한국투자증권 60분봉과 같게, 4시간봉 09·13·17시), 코인은 UTC 정각에 맞춰요(Binance와 같음). 시간봉은 1분마다 다시 받아서 오늘 봉과 뒤에서 채운 지난 봉이 이어져요. 시간봉은 정규장 봉만 그려요(미국도 정규장과 겹치는 칸만. 애프터마켓 16주 체결이 현재가처럼 보였어요). 국내 15시 칸의 종가는 그날 종가로 채워요(아래 GIP). 실시간 시세로는 정규장 시세만 마지막 칸을 고치고, 마감 시각 정각의 종가(미국 16:00)는 마지막 장중 칸에 넣어요. 종목을 바꾸면 새 봉이 올 때까지 앞 종목의 봉과 시가·고가·저가·종가를 지우고, 가격 축을 숨기고(앞 종목의 눈금이 남지 않게), `불러오는 중…`을 차트 위에 보여 줘요. 시가·고가·저가·종가 머리줄은 실시간 시세로 고친 마지막 봉을 따라가요 |
| 장중 차트 (GIP) | 1분봉 캔들과 거래량. 실시간 움직임을 보는 기능이라 봉 크기는 고르지 않아요(시간봉은 GP, 사용자 결정). 제목 줄에 `1분봉`을 적고, 보이는 기간 버튼 1H·4H·1D·MAX(기본 4H, 1D는 가장 최근 장 전체이고 24시간 시장은 최근 24시간)를 둬요. 1H는 1시간봉이 아니라 최근 1시간이에요. 장이 막 열려 봉이 몇 개 없어도 30개는 자리를 잡아요. 저장해 둔 며칠치 분봉이 있어도 처음에는 최근 4시간만 보여요. 정규장 봉만 그려요(국내 09:00~15:30, 미국 주식은 프리·애프터마켓 포함). 장이 닫힌 뒤에는 가장 최근 장의 분봉을 보여 주고, 아직 분봉이 없으면 `아직 장중 분봉이 없어요 · 장이 열리면 1분마다 봉이 생겨요`. 국내 15:30 마감 동시호가 체결은 한국투자증권 분봉에 없어서(15:20에서 끝남), 끝난 날마다 일봉의 종가와 남은 거래량으로 15:30 봉을 채워요 |
| 세계 지수 (WEI) | 지역별 그룹, 현재·변동·변동률·시간(장 상태와 신선도 배지)·스파크라인. 장이 닫혔으면 배지의 `마감`만 보여요(`마감 마감`이 되지 않게). 값을 받지 못한 지수는 0 대신 `—` |
| 환율 매트릭스 (FXC) | 각 칸은 왼쪽(행) 통화 1단위가 위쪽(열) 통화로 얼마인지 보여 줘요. 셀 배경은 등락 색. 아래에 환율 출처(한국투자증권 10초 간격 조회 또는 ECB 기준환율)를 적어요. ECB 값이 섞여 있을 때만 출처 표시 문구를 붙여요 |
| 코인 시세판 (CRYP) | 심볼 + 한글명, 현재가(USDT), 24시간 등락, 거래대금, 24시간 범위 막대 |
| 뉴스·공시 (N) | 시간, 출처 표시(DART 주황 테두리, RSS 회색), 관련 종목, 제목 |
| 업종 히트맵 (HMAP) | 업종, 1개월 추세 스파크라인, 기간별(1D·1W·1M·3M·YTD) 등락 색 셀 |

## 데이터 신선도 표시

이 앱은 유료 데이터를 쓰지 않아서, 실시간으로 받는 값보다 몇 초 간격·지연·하루 한 번으로 받는 값이 훨씬 많아요. 늦은 값을 실시간으로 착각하지 않게, 실시간이 아닌 값은 화면에서 언제나 알아볼 수 있게 해요.

### 원칙

- **배지가 없으면 실시간**이에요. 실시간이 아닌 값에는 빠짐없이 신선도 배지를 붙여요.
- 배지는 자동완성 도움 수준과 상관없이 늘 보여요. 설정으로 끌 수 없어요.
- 배지는 회색이고, 상태를 색이 아니라 글자로 알려요. 등락 색, 주황 강조, 자산군 칩 노랑과 겹치지 않게 해요.
- 늦은 값도 흐리게 칠하지 않아요. 값은 그대로 읽기 쉬워야 해요. 멈춘 값만 배지를 반전해서 눈에 띄게 해요.

### 상태와 배지

| 상태 | 긴 배지 (제목 줄·차트) | 짧은 배지 (표의 행·시세 흐름 띠) | 언제 | 예 |
|---|---|---|---|---|
| 실시간 | 없음 | 없음 | WebSocket으로 체결·시세가 오는 대로 바뀌어요 | 화면에 보이는 국내·미국 종목의 KIS 실시간 체결, Binance |
| 주기 조회 | `5초 주기` | `5초` | 정해진 간격으로 다시 받아요 | 실시간 구독 슬롯 밖의 종목, 해외지수, 환율(한국투자증권 10초) |
| 지연 | `15분 지연` | `지연` | 원천이 늦게 줘요 | 무료 15분 지연 시세(홍콩·일본 등), 지연 옵션 시세 |
| 일별 | `일별 10/21` | `일별` | 하루 한 번 받아요. 날짜는 원천이 매긴 기준일이에요 | KRX Open API(전일까지), 금융위 채권, 미국 재무부 금리, BOK ECOS 일별 통계 |
| 주기 발표 | `기준 2026-09`, `기준 2026 2Q` | `월간`, `분기`, `연간` | 월·분기·연 단위로 발표돼요 | 거시지표, 재무제표, 공시 기반 지분 정보 |
| 장 마감 | `마감 15:30`, `마감 10/30` | `마감` | 장이 끝났어요. 값은 마지막 체결가(종가)이고, 시각은 그 장이 끝난 때예요. 실시간 종목도 주기 조회 종목도 같아요 | 15:30 이후의 국내 주식, 주말 |
| 멈춤 | `⚠ 멈춤 14:03` | `⚠` | 받아야 할 때 새 값을 받지 못했어요. 시각은 마지막으로 받은 때예요 | 연결 끊김, 조회 실패, 호출 한도 초과 |
| 데모 | `데모` | `데모` | 실제 시세가 아닌 가짜 값이에요. 한국투자증권 키를 넣기 전에 주식·지수 화면을 볼 수 있게 만든 값이에요 | 키 없이 연 주식·지수. 상태 표시줄에도 `데모 시세`를 늘 보여 줘요 |

- 한 값이 두 상태에 걸치면 더 늦은 쪽을 보여요. 예를 들어 15분 지연 시세를 1분마다 조회하면 `15분 지연`이에요. 자세한 내용은 마우스를 올려 봐요.
- 배지의 시각은 한국 시간이에요. 오늘이면 시각(`14:03`), 다른 날이면 날짜(`10/21`), 1년이 넘으면 연도까지(`2025-10-21`) 적어요.
- 일별·주기 발표 값의 날짜는 원천의 기준일을 그대로 적어요. 시차 때문에 날짜를 옮기지 않아요.
- 회사 이름, 종목 코드, 설정처럼 시장 데이터가 아닌 것에는 배지를 붙이지 않아요.

### 붙는 자리

| 자리 | 표시 |
|---|---|
| 패널 2줄 (제목 줄) | 패널의 값이 모두 같은 상태면 제목 오른쪽, 기능별 도구 앞에 긴 배지 하나만 붙여요. 상태가 섞인 패널에서는 가장 늦은 상태를 붙이고 행마다 짧은 배지를 붙여요 |
| 표의 행 | 실시간과 아닌 값이 섞이는 표(MON, WEI, CRYP 등)는 행 끝 좁은 열에 짧은 배지를 붙여요. 실시간 행은 비워 둬요. WEI는 기존 시간 열에 장 상태와 함께 적어요. 패널이 좁으면 추세(스파크라인) 열부터 숨기고, 배지 열은 숨기지 않아요 |
| 차트 | 왼쪽 위 시가·고가·저가·종가 줄 끝에 긴 배지를 붙여요. 실시간 차트에서도 연결이 끊기면 `⚠ 멈춤`이 붙어요 |
| 시세 흐름 띠 | 항목 뒤에 짧은 배지를 회색 글자로 붙여요 |
| 커맨드 라인 기능 카드 | 그 기능의 데이터 속도를 같은 말(실시간·주기 조회·지연·일별·주기 발표)로 보여 줘요([05](05-command-line.md) §4.6) |
| 상태 표시줄 | 소스별 연결 상태를 보여 주고, 멈춘 소스 앞에 `⚠`를 붙여요 |

```
┌ 6 │ FXC                                   ■ ⤢ □ ✕ ┐
│ FXC 환율 매트릭스            [30초 주기] …         │  ← 모두 같은 상태: 제목 줄에 긴 배지 하나
│ ...                                               │

│ 삼성전자    005930   71,200  ▲ 1.2%        ~~~~  │  ← 실시간 행: 배지 없음
│ 테슬라      TSLA     251.30  ▼ 0.8%   5초  ~~~~  │  ← 실시간 슬롯 밖: 주기 조회
│ 닛케이225   NKY    38,120.5  ▲ 0.3%   지연 ~~~~  │
```

### 배지 모양

| 상태 | 모양 |
|---|---|
| 보통 (주기 조회·지연·일별·주기 발표·장 마감) | 회색 1px 테두리 상자. 글자는 회색 라벨 색(`#8C8C8C`), 11px. 표의 행에서는 테두리 없이 글자만 |
| 멈춤·늦음 | 배경을 회색(`#8C8C8C`)으로 칠하고 글자는 검정. 앞에 `⚠`를 붙여요 |

배지 위에 마우스를 올리거나 누르면 자세한 정보를 보여 줘요.

- 출처 (출처 표시가 의무인 데이터는 정해진 문구)
- 갱신 방식 (실시간, N초 주기, N분 지연, 하루 한 번, 발표 주기)
- 기준 시각 (원천이 매긴 시각이나 기준일. 해외 값은 현지 시각도 함께)
- 받은 시각
- 다음 갱신 예정 시각

### 멈춤 판정

| 받는 방식 | 멈춤으로 보는 때 |
|---|---|
| 실시간 | 연결이 끊기거나 연결 확인 신호가 끊겼을 때. 거래가 뜸한 종목은 체결이 오래 없어도 멈춤으로 보지 않아요 |
| 주기 조회·지연 | 마지막으로 성공한 뒤 주기의 3배와 1분 중 더 긴 시간이 지났을 때 |
| 일별·주기 발표 | 원천이 갱신하기로 한 시각이 꽤 지났는데도 새 기준일이 없을 때 `⚠ 늦음 10/20`처럼 보여요. 휴장일을 알아야 해서 영업일 달력([08](08-bloomberg-coverage.md) §4.3, v0.6)이 생긴 뒤부터 판정해요. 그 전에는 기준일만 보여요 |

- 장이 끝난 시간에는 실시간 값에 `⚠` 대신 `마감`을 붙여요. 장 상태는 맨 위 시계의 장 상태와 같은 판정을 써요.
- 장이 닫힌 종목은 실시간 슬롯을 쓰지 않고 5분마다 마감 값을 다시 확인해요([04](04-data-sources.md) KIS). 그래서 멈춤 판정도 5분 주기를 기준으로 해요.
- 노트북을 덮었다 열어서 다시 연결되는 동안에는, 새 값이 올 때까지 이전 값에 `⚠ 멈춤`이 붙어 있어요.

### 계산한 값

- 여러 값으로 계산한 값(원화 환산, 스프레드, 포트폴리오 평가액, 채권 수익률 계산 등)은 입력 중 가장 늦은 상태를 따라가요. 예를 들어 실시간 주가에 30초 주기 환율을 곱하면 `30초 주기`예요.
- "근사"·"자체 추정" 표시([08](08-bloomberg-coverage.md) §1.2)와는 따로 붙어요. 둘 다 해당하면 둘 다 보여요.

### 값에 붙는 정보

서버가 화면으로 보내는 모든 시장 데이터에 아래 정보를 함께 붙여요. 화면은 이 정보만 보고 배지를 그려요. 기능마다 따로 판단하지 않아서, 소스를 바꾸거나 지연 조건이 달라져도 배지가 저절로 맞게 바뀌어요.

| 정보 | 뜻 |
|---|---|
| 출처 | KIS, Binance, BOK ECOS 등 |
| 받는 방식 | 실시간 / 주기 조회 / 지연 / 일별 / 주기 발표 |
| 기준 시각 | 원천이 매긴 시각이나 기준일 |
| 받은 시각 | 서버가 받은 시각 |
| 주기·지연 시간 | 주기 조회 간격, 원천의 지연 시간 |

이 형식은 화면과 서버가 함께 쓰는 공통 형식(packages/shared)에 둬요.

## 인터랙션

- **차트의 보이는 범위**(GP·GIP)
  - 기간 버튼이 배율을 정해요. 고른 기간과 봉 단위는 패널마다 기억해요(앱을 다시 켜도 그대로). GP 시간봉의 기간은 일·주·월봉과 따로 기억해요. 시간봉의 기간은 달력 날 수로 세요(1M = 최근 31일).
  - 종목만 바꾸면 지금 배율(휠로 바꾼 배율 포함)을 그대로 두고 가장 최근 봉으로 가요. 기간 버튼이나 봉 단위를 바꾸면 그 기간에 맞춰요. 같은 기간 버튼을 다시 누르면 처음 보기로 돌아가요.
  - 가격 축은 종목·기간이 바뀔 때마다 보이는 봉에 다시 맞춰요. 가격 축을 손으로 당겨 자동 맞춤이 꺼져도 다음 종목에는 남지 않아요.
  - 이동평균선은 가격 축 맞춤에서 빼요. 현재가에서 멀리 떨어진 60일선 때문에 캔들이 작게 몰리지 않게 하려는 거예요.

- **틱 플래시**: 실시간·주기 조회 값이 바뀌면 셀 배경이 0.3초 동안 등락 색으로 반짝여요.
- **십자선 동기화**: 한 차트에 마우스를 올리면 다른 차트에도 같은 시점에 세로선이 표시돼요.
- **연동 그룹**: 창마다 색 표시를 두고, 같은 색끼리 종목이 함께 바뀌어요.
- **창 조작**: 드래그, 크기 조절, 가장자리에 붙이기, 창 안 탭, 최대화, 다른 모니터로 떼어내기, 전체 화면.
  - 전체 화면은 Windows F11, Mac ⌃⌘F(또는 창의 초록 버튼)로 켜고 같은 키로 꺼요. 키를 누른 그 창만 바뀌어요(떼어낸 창도 따로). 메인 창이 전체 화면이 되면 `전체 화면이에요 · F11로 나가요` 알림이 잠깐 떠요. 전체 화면 상태는 다음 실행 때 복원하지 않아요.
  - 패널 1줄 왼쪽의 번호 칸이 끌기 손잡이예요. 번호 칸을 끌어 옮기거나 다른 패널 위에 놓아 창 안 탭으로 묶어요.
  - 패널 묶음 하나를 떼어내거나(패널 1줄의 떼어내기), 화면 탭 하나를 패널 배치째로 떼어내요(화면 탭의 떼어내기). v0.2부터 떼어낸 창 안에도 화면 탭을 여러 개 둬요.
- **F키 주의**: 블룸버그는 자산군을 F키로 고르지만 브라우저·Electron 기본 단축키와 겹쳐요. 대신 입력한 단어(`EQ`, `CRY` 등)와 Mod+Shift+E/C/X/I를 써요. F키로 자산군을 넣는 F키 모드는 Windows 전용 선택 사항이에요(v0.2, 설정 → 커맨드 라인, [05](05-command-line.md) §10.2).

## 테마

- 기본은 **블룸버그 터미널** 색(이 문서의 색). 설정의 테마 이름은 Modern 그대로예요.
- 모든 글자를 앰버색으로 칠하는 옛 CRT 같은 **Classic** 테마는 후순위 선택 사항으로 넣어요.
- 강조 색은 설정에서 바꿀 수 있어요: 블룸버그 앰버 `#FFA028`(기본), 예전 주황 `#FB8B1E`, 흰색, 청록. 라벨·종목 이름 색이 강조 색을 따라가요. 예전 기본값(`#FB8B1E`)으로 저장된 설정은 새 기본값으로 바꿔 읽어요(설정 파일 형식 3).
