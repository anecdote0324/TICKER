단계별로 어떤 기능이 어떤 소스를 쓰는지는 [08 블룸버그 기능 커버리지](08-bloomberg-coverage.md)에 있어요.

모든 소스는 **"데이터 소스 어댑터"** 구조로 붙여요. 한 소스가 막히거나 바뀌어도 그 부분만 갈아 끼울 수 있게 해요.

**라이선스와 출처 표시**
- 시세는 나 혼자 보는 용도로만 써요. 다른 사람에게 보여주거나 재배포하는 기능은 만들지 않아요.
- FRED, KRX Open API("KRX 통계정보"), 공공데이터포털(공공누리)은 **출처 표시가 의무**예요. 해당 데이터를 쓰는 화면에 출처를 보여줘요.
- 웹 페이지를 자동으로 긁어 오는 수집은 약관을 확인하기 전에는 하지 않아요.

**유료 데이터는 쓰지 않는 것을 제안해요(미정, [07](07-open-questions.md)).** 후보는 KIS 해외선물 실시간(CME·SGX), 미국 개별주 옵션(Massive·Alpaca), 미국 애널리스트 추정치(FMP·Finnhub)예요.

## 한국투자증권 Open API (KIS)

### 쓰려면 필요한 것

1. **한국투자증권 계좌**: 비대면으로 개설할 수 있어요. 주식과 해외주식을 함께 거래할 수 있는 종합계좌로 열어요.
2. **KIS Developers 서비스 신청**: 인증서 로그인, 휴대폰 인증, 약관 동의 후 API를 연결할 계좌를 골라요.
3. **앱키(App Key)와 앱시크릿(App Secret)**: 계좌 단위로 발급돼요. 앱시크릿은 절대 외부에 노출하면 안 돼요.

- 실제 시세를 봐야 하니 모의투자 키가 아니라 **실전 키**를 써요.
- 계좌 개설과 기본 API 사용은 무료예요. 다만 시세만 받을 때 예수금이 필요한지, 미국 실시간이 정말 무료인지는 확인 필요예요. 홍콩·중국·일본·베트남 실시간은 유료예요.
- 개인 용도라 별도 제휴 절차는 필요 없어요.
- 매매는 기존 신한투자증권 계좌에서 계속하고, 한국투자증권 계좌는 **시세를 받는 용도로만** 써요. 이 앱에는 매매 기능을 넣지 않아요(사용자 결정).
- **주의**: KIS 앱키에는 권한 구분이 없어서, 시세용으로 받은 키로도 주문을 낼 수 있어요. 키가 새는 경우에 대비해 시세용으로는 **잔고가 없는 별도 계좌**의 키를 쓰는 것을 권해요.

### 받을 수 있는 시세

| 시장 | 실시간 체결 | 실시간 호가 | 비고 |
|---|---|---|---|
| 국내 (KRX, NXT) | ✓ | ✓ (10호가) | NXT는 시장 코드 `NX`. KRX·NXT·통합 호가를 고를 수 있어요 |
| 미국 | ✓ 무료(0분 지연)로 안내됨, 확인 필요 | 1호가만 무료로 안내됨 | 주간거래 시세도 조회 가능 |
| 홍콩·중국·일본·베트남 | 무료는 15분 지연 | | 실시간은 유료 신청 |
| 국내 선물옵션 | ✓ | ✓ | KOSPI200 선물·옵션, 야간 시장 포함. 국채선물이 포함되는지는 확인 필요 |
| 장내채권 | ✓ | | KRX 일반채권시장만이라 국고채 지표물 체결은 드물어요(아래 "채권" 참고) |
| 해외선물 | 일봉·정산가 조회 | | CME·SGX 실시간은 유료(미정). 무료 범위는 확인 필요 |

미국 시세 조건은 KIS 공식 GitHub 예제 코드의 설명에 적힌 내용이에요. 공식 요금표는 아니어서 실제로 붙여 볼 때 다시 확인해요.

**종목 마스터 파일**: 국내·해외 종목 목록 파일을 내려받을 수 있어요. 이걸로 자동완성 검색용 종목 목록을 만들어요. KIS 공개 코드를 보면 해외 종목 파일에 한글 이름과 ADR 여부 칸이 있어요. 한글 이름이 실제로 얼마나 채워져 있는지는 확인 필요예요([07](07-open-questions.md)). 잘 채워져 있으면 `애플`로 AAPL을 찾을 수 있어요.

### 제약과 대응

| 제약 | 대응 |
|---|---|
| **실시간 구독 개수 제한** (예제 코드는 40개로 막아 둠, 체결·호가 합산인지 확인 필요) | 지금 화면에 떠 있는 종목만 실시간으로 받고, 나머지는 몇 초 간격으로 조회해요. 여러 창에 같은 종목이 떠 있으면 한 번만 구독하고, 어떤 창에도 안 보이면 해제해요 |
| **REST 호출 횟수 제한** (국내 실전 초당 20회로 안내됨, 해외 한도는 확인 필요) | v0.1부터 **요청 예산 관리자**를 둬요. 모든 KIS 요청을 우선순위 큐로 보내고, 화면에 보이는 것 > 백그라운드 수집 순으로 나눠 써요 |
| 미국 호가는 1호가만 무료 | 터미널 화면에는 충분해요. 여러 호가를 보여주는 호가창은 미국 종목에서 제한돼요 |
| 접속 토큰 발급 | 앱키·앱시크릿으로 토큰을 받아 요청마다 보내요. 토큰은 서버가 관리해요 |

상태 표시줄에 실시간 구독 사용량(예: `18/40`)을 보여줘요.

## 신한투자증권을 쓰지 않는 이유

처음에는 신한투자증권 API를 검토했어요.

| 확인한 것 | 내용 |
|---|---|
| 웹 방식 API | 개인이 쓸 수 있는 REST/WebSocket API를 찾지 못했어요 |
| 신한i Indi API | ActiveX(OCX) 방식이라 **Windows에서만** 동작해요. Mac 지원 목표와 충돌해요 |
| 해외주식 실시간 | Indi로 받을 수 있는지 확인되지 않았어요 |

2차 자료 기준의 결론이에요. 신한이 개인용 웹 API를 내놓으면 다시 검토할 수 있어요.

## Binance (코인)

| 항목 | 내용 |
|---|---|
| 범위 | **USDT 마켓만**. 가격은 USDT로만 표시하고 원화로 환산하지 않아요. 지금은 현물(spot)만이고, USDⓈ-M 선물의 공개 데이터(펀딩비·미결제약정)를 넣을지는 미정([07](07-open-questions.md)) |
| 표기 | `BTC/USDT`. USDT는 1달러에 거의 붙어 움직이지만 같지는 않아서 `$` 대신 `USDT`라고 써요 |
| 계정·키 | 필요 없어요. 공개 시세만 써요 |
| 전체 시장 | 모든 종목의 시세 요약을 스트림 하나로 1초마다 받아요. CRYP 시세판(거래대금·등락률 순 정렬 포함)에 써요 |
| 개별 종목 | 연결 하나로 여러 종목을 동시에 구독해요 |
| 과거 데이터 | 분봉·일봉을 무료로 받아요. 선물 미결제약정·펀딩비도 과거 이력을 한꺼번에 받을 수 있어요(`data.binance.vision`, 2020-09부터) |

**주의할 점**

- **24시간마다 연결이 끊겨요.** 자동으로 다시 연결해서 사용자가 끊김을 못 느끼게 해요.
- **국내 접속 위험**: 금융정보분석원이 미신고 해외 거래소의 국내 접속을 차단한 적이 있어요(2026년 조사 시점 명단에 Binance는 없었어요). 막히면 Binance의 시세 전용 주소(`data-api.binance.vision`, `data-stream.binance.vision`)로 바꿔 연결해요. 그것도 막히면 CRYP 전체가 영향을 받아요.
- **자동완성 검색 목록에서 뺄 것**: 법정화폐·스테이블코인 성격의 종목(EUR, USDC, FDUSD, USDE 등)과 영문·숫자가 아닌 이름의 종목(`牛来` 등).
- 2026년 10월 조사 시점 기준으로 USDT 마켓 종목은 500개가 넘고, 그중 100개 이상이 미국 주식 티커와 이름이 같아요(C, F, T 등). 자동완성에서 이를 처리하는 규칙은 [05 커맨드 라인과 자동완성](05-command-line.md)에 있어요.

## 환율

- 터미널 용도로는 **30~60초 간격 갱신**이면 충분해요. 무료로 틱 단위 실시간 환율을 얻기는 어려워요.
- 현재가는 KIS 환율 조회가 1순위 후보예요(분봉·지연 여부 확인 필요). 안 되면 무료 REST 소스를 실제로 테스트해서 정해요. 비공식 소스는 갑자기 막힐 수 있어요.
- 과거 이력은 한국은행 ECOS 환율을 써요. v0.3 PORT의 원화 환산에 필요해서 v0.3부터 붙여요. 공식 고시환율(FIXI)에는 한국수출입은행·ECB 기준환율도 써요.
- 원화 외환시장은 야간에 다음 날 02:00까지 열려요. FXC와 FIXI에 기준 시각을 함께 보여줘요.
- 환율 소스가 분봉을 주지 않으면 환율에서는 GIP(장중 차트)를 보여주지 않아요.
- 표기는 `USDKRW`처럼 기준 통화가 앞이에요. `KRWUSD`처럼 거꾸로 입력해도 `USDKRW`로 보여줘요.

## 공시와 뉴스

| 소스 | 내용 | 단계 |
|---|---|---|
| DART OpenAPI | 국내 공시. 무료지만 인증키 발급이 필요해요(설정의 데이터 연결에서 입력). 재무제표(XBRL), 지분공시, 임원, 배당, 주요사항보고서, 증권신고서도 제공해요 | v0.2 |
| RSS | 국내외 뉴스 헤드라인. 뉴스 아카이브는 v0.2부터 쌓기 시작해요(검색 기능 NSE는 쌓기 시작한 뒤의 뉴스만 찾을 수 있어요) | v0.2 |
| SEC EDGAR | 미국 공시·재무제표(companyfacts), 13F, Form 4, 8-K. 무료, 초당 10건 이하, 요청에 연락처(User-Agent) 필요. 한도를 넘으면 IP 차단 | v0.3 |
| 네이버 검색 API(뉴스) | 종목 뉴스(CN), 뉴스 검색. 무료, 앱 등록 필요, 하루 한도 확인 필요. 본문은 원문 링크로 열어요 | v0.4 |

미국 실적 발표 일정의 무료 소스는 확인 필요예요. 없으면 SEC 8-K(실적 발표 항목)로 발표 뒤에 표시만 해요.

- 미국 재무부 XML은 테너(만기 구간)가 추가되기도 해요(2025-02에 1.5개월물 추가). 테너 목록을 고정하지 않아요.
- FRED의 ICE BofA 크레딧 스프레드는 최근 3년만 줘서, v0.3부터 매일 저장해요. 그 이전 이력은 받을 수 없어요.
- 경제지표의 "예상치"는 무료 소스가 없어서 빈칸으로 두거나 사용자가 입력해요.

## 채권

| 소스 | 내용 | 비용·한도 | 단계 |
|---|---|---|---|
| KIS 장내채권 | KRX 일반채권시장의 체결·호가, 채권 발행 정보, 채권지수 | 무료 | v0.7 |
| 금융위원회 채권 데이터 3종 (공공데이터포털: 채권시세정보, 채권기본정보, 채권발행정보) | 채권별 일별 시세(T+1, 다음 영업일 13시 이후), 발행 조건 | 무료, 개발계정 하루 10,000건. 공공누리 조건: 비상업, 변경·재배포 금지 | v0.7 |
| KRX Open API | 전 종목 일별(주식·ETF·채권·파생·일반상품), 채권지수 | 무료, 키당 하루 10,000건, 키 유효기간 1년, API마다 승인(약 1일). **전일(T-1) 데이터, 다음 날 08:00 갱신**. 비상업, 제3자 제공 금지, 출처 표시 | v0.7 (전 종목 DB는 v0.9) |

- **개인이 접근할 수 있는 채권시장은 KRX 일반채권시장뿐**이에요. 국고채 지표물은 딜러 전용 국채전문유통시장에서 주로 거래돼서, 장내 체결가는 오래됐거나 비어 있는 경우가 많아요.
- 그래서 채권 평가가격(YAS)의 기본 순서는 ① 금융위 T+1 시세 → ② ECOS 커브로 계산한 이론가 → ③ 장내 마지막 체결(체결 시각 표시)이에요.
- 한국 장중 금리(국고채 실시간 커브)는 무료로 구할 방법이 없어요. KOFIA의 최종호가수익률은 웹 페이지에만 있어서, 약관을 확인하기 전에는 자동으로 가져오지 않아요.
- 블룸버그 평가가격(BVAL), 신용등급 피드, CDS 시세는 개인이 구할 수 없어요. 근사 방법은 [08](08-bloomberg-coverage.md)에 있어요.
