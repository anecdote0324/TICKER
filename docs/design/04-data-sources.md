단계별로 어떤 기능이 어떤 소스를 쓰는지는 [08 블룸버그 기능 커버리지](08-bloomberg-coverage.md)에 있어요.

모든 소스는 **"데이터 소스 어댑터"** 구조로 붙여요. 한 소스가 막히거나 바뀌어도 그 부분만 갈아 끼울 수 있게 해요.

**라이선스와 출처 표시**
- 시세는 나 혼자 보는 용도로만 써요. 다른 사람에게 보여주거나 재배포하는 기능은 만들지 않아요.
- FRED, KRX Open API("KRX 통계정보"), 공공데이터포털(공공누리)은 **출처 표시가 의무**예요. 해당 데이터를 쓰는 화면에 출처를 보여줘요.
- 웹 페이지를 자동으로 긁어 오는 수집은 약관을 확인하기 전에는 하지 않아요.

**유료 데이터는 쓰지 않아요(사용자 결정).** 검토했다가 뺀 유료 소스는 KIS 해외선물 실시간(CME·SGX), 미국 개별주 옵션(Massive·Alpaca), 미국 애널리스트 추정치(FMP·Finnhub)예요. 이 데이터가 있어야 하는 기능은 [08](08-bloomberg-coverage.md) §5.3에 있어요.

**실시간 여부와 신선도 정보**
- 무료 데이터는 대부분 실시간이 아니에요. 실시간으로 받는 것은 KIS WebSocket(화면에 보이는 국내·미국 종목, 약 40개)과 Binance WebSocket뿐이에요. 나머지는 몇 초~몇 분 간격 조회, 원천 지연, 하루 한 번, 발표 주기예요.
- 어댑터는 값마다 출처, 받는 방식(실시간·주기 조회·지연·일별·주기 발표), 기준 시각, 받은 시각, 주기·지연 시간을 붙여서 넘겨요. 화면은 이 정보로 "실시간 아님" 배지를 그려요([02](02-ui.md) 데이터 신선도 표시).
- 그래서 미국 실시간 무료 조건처럼 아직 확인하지 못한 것이 실제로는 지연으로 밝혀져도, 어댑터의 받는 방식만 고치면 화면 표시가 따라 바뀌어요.

## 한국투자증권 Open API (KIS)

### 쓰려면 필요한 것

1. **한국투자증권 계좌**: 비대면으로 개설할 수 있어요. 주식과 해외주식을 함께 거래할 수 있는 종합계좌로 열어요.
2. **KIS Developers 서비스 신청**: 인증서 로그인, 휴대폰 인증, 약관 동의 후 API를 연결할 계좌를 골라요.
3. **앱키(App Key)와 앱시크릿(App Secret)**: 계좌 단위로 발급돼요. 앱시크릿은 절대 외부에 노출하면 안 돼요.

- 실제 시세를 봐야 하니 모의투자 키가 아니라 **실전 키**를 써요.
- 계좌 개설과 기본 API 사용은 무료예요. 다만 시세만 받을 때 예수금이 필요한지, 미국 실시간이 정말 무료인지는 확인 필요예요. 홍콩·중국·일본·베트남 실시간은 유료예요.
- 개인 용도라 별도 제휴 절차는 필요 없어요.
- 매매는 기존 신한투자증권 계좌에서 계속하고, 한국투자증권 계좌는 **시세를 받는 용도로만** 써요. 이 앱에는 매매 기능을 넣지 않아요(사용자 결정).
- **주의**: KIS 앱키에는 권한 구분이 없어서, 시세용으로 받은 키로도 주문을 낼 수 있어요. 키가 새는 경우에 대비해 시세용으로는 **잔고가 없는 별도 계좌**의 키를 쓰는 것을 권해요.

### 받을 수 있는 시세

| 시장 | 실시간 체결 | 실시간 호가 | 비고 |
|---|---|---|---|
| 국내 (KRX, NXT) | ✓ | ✓ (10호가) | NXT는 시장 코드 `NX`. KRX·NXT·통합 호가를 고를 수 있어요 |
| 미국 | ✓ 무료(0분 지연). 공식 예제(해외주식 실시간지연체결가) 설명으로 확인 | 1호가만 무료로 안내됨 | 주간거래(10:00~16:00) 시세도 받을 수 있어요(시장 코드 나스닥 `BAQ`, 뉴욕 `BAY`, 아멕스 `BAA`) |
| 홍콩·중국·일본·베트남 | 무료는 15분 지연 | | 실시간은 유료 신청 |
| 국내 선물옵션 | ✓ | ✓ | KOSPI200 선물·옵션, 야간 시장 포함. 국채선물이 포함되는지는 확인 필요 |
| 장내채권 | ✓ | | KRX 일반채권시장만이라 국고채 지표물 체결은 드물어요(아래 "채권" 참고) |
| 해외선물 | 일봉·정산가 조회 | | CME·SGX 실시간은 유료라 쓰지 않아요. 무료 범위는 확인 필요 |

**시간봉(GP)**: 한국투자증권은 국내 주식에 N분봉 조회가 없어서 1분봉(주식일별분봉조회, 1년 보관)을 받아 1시간봉으로 묶어요. 하루치에 약 4번 조회라, 처음에는 최근 5거래일만 받고 그 앞은 뒤에서 조금씩 채워 저장해요(아래 "공식 저장소에서 확인한 것"). 미국 주식은 해외주식분봉조회에 분 단위(`NMIN=60`)를 넣어 바로 받아요. 지수 시간봉은 분봉 제공을 확인하기 전이라 아직 없어요.

미국 시세 조건은 KIS 공식 GitHub 예제 코드의 설명에 적힌 내용이에요. 공식 요금표는 아니어서 실제로 붙여 볼 때 다시 확인해요.

**종목 마스터 파일**: 국내·해외 종목 목록 파일을 내려받을 수 있어요. 이걸로 자동완성 검색용 종목 목록을 만들어요. KIS 공개 코드를 보면 해외 종목 파일에 한글 이름과 ADR 여부 칸이 있어요. 한글 이름이 실제로 얼마나 채워져 있는지는 확인 필요예요([07](07-open-questions.md)). 잘 채워져 있으면 `애플`로 AAPL을 찾을 수 있어요.

### 제약과 대응

| 제약 | 대응 |
|---|---|
| **실시간 구독 개수 제한** (예제 코드는 40개로 막아 둠, 체결·호가 합산인지 확인 필요) | 지금 화면에 떠 있고 **장이 열린** 종목만 실시간으로 받고, 넘치는 종목은 몇 초 간격으로 조회해요. 장이 닫힌 종목(국내 장 마감 뒤의 국내 주식 등)은 슬롯을 쓰지 않고 5분 간격으로 마감 값만 확인해요. 국내 주식은 장 시작 전(08:30)부터, 미국 주식은 프리·애프터마켓에도 받고, 정규장이 끝난 뒤 10분은 종가 확정을 기다려요. 장이 열리고 닫힐 때 30초 안에 구독을 다시 나눠요. 여러 창에 같은 종목이 떠 있으면 한 번만 구독하고, 어떤 창에도 안 보이면 해제해요 |
| **실시간 구독 거절** (`MAX SUBSCRIBE OVER`. 실제 계정에서 16개만 구독했는데 첫 연결부터 거절됨, 원인 확인 필요) | 키마다 등록 수를 세는 것으로 보고, 연결을 바꿀 때는 이전 연결의 구독을 풀고 닫은 뒤 새로 열어요(두 연결을 겹치지 않아요). 같은 키를 다시 저장하면 지금 연결로 테스트만 해요. 거절된 종목은 몇 초 간격 조회로 받고, 60초 뒤부터 간격을 두 배씩 늘려(최대 10분) 다시 구독해요. 장이 닫힌 종목의 구독을 풀어 자리가 나면 2초 뒤 바로 다시 시도해요. 받아 준 자리는 먼저 띄운 종목부터 써요. 상태 표시줄에 거절된 수를 알려 줘요 |
| **REST 호출 횟수 제한** (국내 실전 초당 20회로 안내됨, 해외 한도는 확인 필요) | v0.1부터 **요청 예산 관리자**를 둬요. 모든 KIS 요청을 우선순위 큐로 보내고, 화면에 보이는 것 > 백그라운드 수집 순으로 나눠 써요. 실전은 초당 15건에서 시작해요(18건에서 `EGW00201 초당 거래건수 초과`를 받았어요). 초과를 받으면 모든 호출을 1초 멈추고 초당 호출 수를 0.7배로 줄여요(최소 2건). 멈춤과 줄이기는 2초에 한 번만 해요(같은 순간에 여러 건이 함께 실패해요). 30초 동안 초과가 없으면 1건씩 15건까지 되돌려요. 15건에서도 5~20초마다 초과를 받았어요(v0.1.0-beta.9). 초과를 받은 요청은 자리를 지킨 채 다시 하되, **다시 보내는 요청도 초당 호출 수 안에서 차례를 기다려요**(조금씩 흩어서). v0.1.0-beta.11까지는 다시 보내는 요청을 세지 않아서, 여러 요청이 1초 뒤 한꺼번에 다시 나가 또 초과를 받았고 초당 2건까지 줄여도 초과가 계속 났어요. 대기줄에 다시 서지는 않아요(동시 8자리가 모두 재시도를 기다리며 대기줄 전체가 멈춰요. v0.1.0-beta.7까지의 문제). 백그라운드 수집(지난 시간봉 채우기)은 초당 호출 수의 절반, 동시 2개까지만 써요. 주기 조회 간격은 장이 열린 종목 수와 지금의 초당 호출 수로 정하고(최소 3초), 해외 지수는 1분, 장이 닫힌 종목은 5분이에요 |
| 미국 호가는 1호가만 무료 | 터미널 화면에는 충분해요. 여러 호가를 보여주는 호가창은 미국 종목에서 제한돼요 |
| 접속 토큰 발급 | 앱키·앱시크릿으로 토큰을 받아 요청마다 보내요. 토큰은 서버가 관리해요 |

상태 표시줄에 실시간 구독 사용량(예: `18/40`)을 보여줘요.

처음에는 신한투자증권 API를 검토했어요.

| 항목 | 내용 |

**주의할 점**

- **24시간마다 연결이 끊겨요.** 자동으로 다시 연결해서 사용자가 끊김을 못 느끼게 해요.
- **국내 접속 위험**: 금융정보분석원이 미신고 해외 거래소의 국내 접속을 차단한 적이 있어요(2026년 조사 시점 명단에 Binance는 없었어요). 막히면 Binance의 시세 전용 주소(`data-api.binance.vision`, `data-stream.binance.vision`)로 바꿔 연결해요. 그것도 막히면 CRYP 전체가 영향을 받아요.
  - 개발 환경(해외 클라우드)에서 일반 주소가 `451`로 막히는 것을 실제로 겪었고, 앱이 시세 전용 주소로 자동으로 넘어가 실시간 시세를 받는 것을 확인했어요. 응답 없이 멈춘 연결은 8초 뒤에 다음 주소로 넘어가요.
- **자동완성 검색 목록에서 뺄 것**: 법정화폐·스테이블코인 성격의 종목(EUR, USDC, FDUSD, USDE 등)과 영문·숫자가 아닌 이름의 종목(`牛来` 등).
- 2026년 10월 조사 시점 기준으로 USDT 마켓 종목은 500개가 넘고, 그중 100개 이상이 미국 주식 티커와 이름이 같아요(C, F, T 등). 자동완성에서 이를 처리하는 규칙은 [05 커맨드 라인과 자동완성](05-command-line.md)에 있어요.

## 환율

- 무료로 틱 단위 실시간 환율을 얻기는 어려워요. 터미널 용도로는 몇 초~몇십 초 간격 갱신이면 충분해요.
- **현재가: 한국투자증권 키가 있으면 KIS 환율 조회를 10초마다 해요**(`10초 주기` 배지). 기간별시세(FHKST03030100)에 시장 구분 `X`(환율)와 해외지수 마스터의 환율 코드를 넣어요(아래 "공식 저장소에서 확인한 것"). 필요한 통화만(FXC는 6개) 받아서 한 번에 초당 0.6건쯤 써요.
  - 통화마다 1달러당 값으로 바꿔 두고 모든 환율을 그걸로 계산해요(원/유로 = 1달러당 원 ÷ 1달러당 유로). 전일 값은 현재가에서 전일 대비를 빼서 구해요.
  - 통화마다 받은 시각을 따로 둬요. 한 통화를 한 번 못 받아도(초당 한도 초과 등) 그 통화의 앞 값을 1분까지 써요. 처음에는 통째로 바꿔서, 그 통화가 든 칸만 ECB 값으로 바뀌었다 돌아오길 되풀이했어요(v0.1.0-beta.11).
  - 1분 넘게 받지 못하거나 키를 지우면 ECB 기준환율로 돌아가요. 상태 표시줄은 `환율 10초마다 확인`(한국투자증권) 또는 `환율 30분마다 확인`(ECB)이에요.
- **차트(GP)의 일·주·월봉도 키가 있으면 KIS 것**이에요(기간별시세 시장 구분 `X`, 일봉 100건씩 3번 ≈ 14개월). 지금 환율과 같은 출처라 마지막 봉이 지금 환율과 이어져요. 달러가 한쪽인 환율(원/달러, 달러/엔 등)은 캔들, 교차 환율(원/유로 등)은 같은 날짜의 종가끼리 계산한 선이에요. 처음에는 ECB 일봉을 써서, ECB를 못 받은 날 저장분으로 그려 선이 며칠 전에서 멈추고 마지막 값이 지금 환율과 달랐어요(v0.1.0-beta.11).
- 키가 없거나 KIS 봉을 받지 못하면 **ECB 기준환율(Frankfurter, `api.frankfurter.dev`)**이에요. 키가 없고, 과거 일별 이력(2년)도 주고, 원화를 포함해요.
  - ECB 기준환율은 영업일마다 한 번(유럽 오후) 정해지는 값이라 화면에 `일별 10/22` 배지가 붙어요. 실시간처럼 보이지 않게 하려는 신선도 표시 원칙 그대로예요.
  - 교차 환율(FXC)은 원화 환율 두 개로 계산하고, 신선도는 둘 중 늦은 쪽을 따라가요.
  - 환율 종목(v0.2): FXC 일곱 통화(USD·EUR·JPY·GBP·CNY·AUD·KRW)끼리 21쌍을 모두 둬요(원화 6쌍, 달러 5쌍, 그 밖의 교차 10쌍 EURJPY·EURGBP·EURCNY·EURAUD·GBPJPY·GBPCNY·GBPAUD·AUDJPY·AUDCNY·CNYJPY). 새 소스 없이 같은 1달러당 값으로 계산해요. FXC 칸을 누르면 연동 그룹 차트가 그 쌍(없으면 뒤집은 쌍)으로 바뀌어요
  - 다른 무료 소스 중 ExchangeRate-API(open.er-api.com)도 하루 한 번이라 이점이 없었어요. 비공식 소스는 갑자기 막힐 수 있어서 쓰지 않아요.
- 과거 이력은 한국은행 ECOS 환율을 써요. v0.3 PORT의 원화 환산에 필요해서 v0.3부터 붙여요. 공식 고시환율(FIXI)에는 한국수출입은행·ECB 기준환율도 써요.
- 원화 외환시장은 야간에 다음 날 02:00까지 열려요. FXC와 FIXI에 기준 시각을 함께 보여줘요.
- 환율 소스가 분봉을 주지 않으면 환율에서는 GIP(장중 차트)를 보여주지 않아요. 해외지수분봉조회(시장 구분 `X`·`KX`)로 환율 분봉을 받을 수 있는지는 확인 전이라, 지금은 환율의 GIP는 안내 문구만 보여요.
- 표기는 `USDKRW`처럼 기준 통화가 앞이에요. `KRWUSD`처럼 거꾸로 입력해도 `USDKRW`로 보여줘요.

S&P 500과 나스닥100의 구성 종목 목록은 지수 회사(S&P Dow Jones Indices·Nasdaq)가 유료로 팔아요. 대신 그 지수를 따르는 ETF가 날마다 공개하는 보유 종목 파일을 써요(사용자 결정). ETF는 지수를 그대로 담아서 종목과 비중이 거의 같아요. 화면에는 어느 ETF의 보유 종목인지와 기준일을 작게 적어요.

| 지수 | ETF | 받는 곳 | 형식 | 앱에서 |
|---|---|---|---|---|
| S&P 500 | State Street SPDR SPY | `ssga.com/library-content/products/fund-data/etfs/us/holdings-daily-us-en-spy.xlsx` (키 없음) | 엑셀(xlsx). 위 4줄에 펀드 이름·기준일(`As of 03-Nov-2026`), 5번째 줄이 머리줄(Name·Ticker·Identifier·SEDOL·Weight·Sector·Shares Held·Local Currency). Sector 칸은 `-`로 비어 있어요. 현금 줄(Ticker `-`)과 임시 코드(`2602335D`) 줄이 섞여 있어요 | 머리줄을 찾아 종목 코드·이름·비중(%)만 읽고, 주식 코드 모양이 아닌 줄은 빼요. `BRK.B` → `BRK/B`. 503종목(2026-11-03) |
| 나스닥100 | Invesco QQQ | `dng-api.invesco.com/cache/v1/accounts/en_US/shareclasses/QQQ/holdings/fund?idType=ticker&interval=monthly&productType=ETF` (키 없음) | JSON. `effectiveDate`, `holdings[]`의 `ticker`·`issuerName`·`percentageOfTotalNetAssets`·`securityTypeCode`. 업종 칸은 없어요 | 주식(COM)과 예탁증서(ADR·DRNY)만, 현금(CURR)·선물(IFUT)·담보(CURRCOL·SYN)는 빼요. 101종목(2026-11-03) |

- 12시간에 한 번 받아 데이터 폴더(`etf-holdings-SPY.json`·`etf-holdings-QQQ.json`)에 둬요. 받지 못하면 마지막으로 받은 파일을 쓰고 화면에 "(이전 파일)"이라고 적어요. 받은 파일은 커밋하지 않아요.
- 두 파일 모두 업종이 없어서, 업종은 한국투자증권 해외 업종 분류(업종별코드조회 → 업종별시세)로 묶어요. 같은 이름의 업종은 나스닥·뉴욕을 합쳐요. 분류에 없는 종목은 "기타", 분류를 받는 동안은 "업종 확인 중" 한 묶음이에요.
- iShares IVV(S&P 500, 업종 칸 있음)의 CSV 주소는 개발 환경에서 CSV 대신 상품 페이지(HTML)를 돌려줘서 쓰지 않았어요. Invesco의 예전 다운로드 주소(`invesco.com/us/financial-products/etfs/holdings/main/holdings/0?...`)는 안내 페이지로 넘어가요.

## 쓰지 않을 소스

| 소스 | 이유 |
|---|---|
| Upbit | 코인은 Binance만 쓰기로 함 |
| Deribit 공개 API | 무료지만 코인은 Binance만 쓰기로 함. 크립토 옵션은 Binance 옵션 공개 API로 대신해요 |
| 유료 소스 (KIS 해외선물 실시간, Massive·Alpaca, FMP·Finnhub) | 유료 데이터는 쓰지 않기로 함 |
| Twelve Data 무료 요금제 | 화면에 보여줄 수 없는 "internal non-display" 조건이에요 |
| NewsAPI 무료 | 개발 전용이고 24시간 지연이에요 |
| 금융위 소매채권수익률 | 2022-03 이후 갱신이 멈췄어요 |
| Cboe 풋콜비율 CSV | 2019-10에서 갱신이 멈췄어요. 현행 풋콜비율 웹 페이지는 자동 추출이 금지돼 있어요 |
| FRED 스왑 금리 | 2016~2022년에 중단·삭제됐어요. 무료 스왑 커브가 없어요 |
| TradingView 히트맵 | 화면을 퍼 오는 것은 약관상 안 되고, 구성 종목 데이터를 따로 주지 않아요. IMAP 미국 지수는 ETF 보유 종목 파일로 대신해요 |

## 설정에 필요한 키

설정의 "데이터 연결"에서 입력해요: KIS 앱키·앱시크릿, DART, ECOS, FRED, KOSIS, KRX Open API, 공공데이터포털, EIA 키, 그리고 SEC EDGAR 요청에 넣을 연락처. 모두 PC 안에 암호화해서 저장해요.
