# 08 블룸버그 기능 커버리지

이 문서는 블룸버그 기능마다 이 앱에 넣을지와, 넣는다면 어떤 데이터로 언제 만들지를 정해요. 관련 문서는 [03 기능 코드](03-functions.md), [04 데이터 소스](04-data-sources.md), [05 커맨드 라인](05-command-line.md), [07 미정 사항](07-open-questions.md)이에요.

이 문서에서 "확인 필요"라고 적은 것은 [07](07-open-questions.md)에 모아요.

## 1. 범위 원칙과 판정 기준

### 1.1 범위 원칙

- 블룸버그 기능을 최대한 구현해요. 다만 개인에게는 의미 없는 속도의 데이터가 있어야 하는 기능은 빼요. 전 종목 틱, 전체 호가 깊이, 밀리초 스트림, 딜러 실시간 호가가 여기에 들어가요.
- 매매(주문) 기능은 모두 빼요(사용자 결정). 호가, 채권 시세, 옵션 체인처럼 **보는** 기능은 넣어요.
- 코인은 Binance의 USDT 가격만 써요. Upbit와 김치 프리미엄(KIMP)은 계속 빼요([01](01-overview.md)).
- 유료 데이터는 쓰지 않아요(사용자 결정). 유료 요금제로만 받을 수 있는 데이터가 있어야 하는 기능은 **사용자 결정으로 제외**예요.
- 무료로 받는 데이터는 대부분 실시간이 아니에요. 실시간이 아닌 값에는 화면에 신선도 배지를 붙여요(1.3, [02](02-ui.md) 데이터 신선도 표시).
- 시세는 나 혼자 봐요([01](01-overview.md)). 비상업 조건이나 출처 표시 조건이 붙은 무료 데이터(KRX, 금융위, FRED)도 이 조건 안에서 써요.

### 1.2 판정

| 판정 | 뜻 | 예 |
|---|---|---|
| **포함** | 무료 데이터로 만들 수 있고, 늦은 데이터로도 쓸모가 남아요 | YAS, CF, PORT 리스크 |
| **근사** | 원래 데이터는 기관용이거나 독점이라 개인이 구할 수 없어요. 대신 공개 데이터로 비슷하게 만들고, 화면에 "근사"나 "자체 추정"과 출처를 표시해요 | MEMB, BVAL, WIRP |
| **데이터 없음 → 제외** | 근사할 방법이 없거나, 가치가 기관 네트워크 자체에 있어요 | IB, CDS 시세 |
| **속도 제외** | 데이터를 구할 수 있어도 늦추면 목적이 사라지는 기능이에요 | MKAC, GIQ, ALLQ |
| **사용자 결정으로 제외** | 사용자가 범위에서 빼기로 한 것이에요. 매매 기능 전부, 유료 데이터가 있어야 하는 것, KIMP, Deribit이 여기에 들어가요 | EMSX, BTCA, CME 실시간, KIMP |

**판단 순서**
1. 매매(주문) 기능이면 **사용자 결정으로 제외**예요. 속도나 데이터 때문에도 빠질 기능이면 사유에 그것도 함께 적어요.
2. 하루 1회나 분 단위로 늦춰도 쓸모가 남는지 봐요. 남지 않으면 **속도 제외**예요. 데이터도 없으면 사유에 "데이터도 없음"을 함께 적어요.
3. 쓸모가 남으면 개인이 데이터를 구할 수 있는지 봐요.
   - 기관 라이선스로만 살 수 있으면, 근사할 방법이 있을 때 **근사**, 없을 때 **데이터 없음 → 제외**예요.
   - 개인 요금제로 살 수 있어도 유료 데이터는 쓰지 않으므로 **사용자 결정으로 제외**예요. 사유에 "유료"를 적어요.
   - 기존 결정(코인은 Binance만 등)과 부딪히면 **사용자 결정으로 제외**예요.
4. 무료로 구할 수 있으면 **포함**이에요. 단계는 한국 개인 투자자에게 주는 가치와 데이터를 준비하는 난이도로 정해요.

**단계 표기**: `v0.4`처럼 버전을 적어요. `후순위`는 v0.11 다음이에요. 단계별 묶음은 3절에 있어요.

### 1.3 속도 표기

| 표기 | 뜻 |
|---|---|
| 실시간 | WebSocket이나 수 초 간격 조회 |
| 지연 | 분 단위 조회, 또는 원천이 늦게 주는 시세(15분 지연 등) |
| 일 1회 | 장 마감 뒤나 다음 날 갱신. 원천이 주·월·분기 단위면 괄호에 적어요 |
| 계산 | 시장 데이터 없이 입력값이나 다른 기능의 데이터로 계산 |
| 정적 | 설정이나 메타데이터 |

**화면 신선도 배지와의 대응** ([02](02-ui.md) 데이터 신선도 표시)

| 속도 표기 | 화면 배지 |
|---|---|
| 실시간 (WebSocket) | 없음. 연결이 끊기면 `⚠ 멈춤`, 장이 끝나면 `마감` |
| 실시간 (수 초 간격 조회) | `5초 주기`처럼 주기 조회 배지 |
| 지연 (분 단위 조회) | `1분 주기` |
| 지연 (원천이 늦게 주는 시세) | `15분 지연` |
| 일 1회 | `일별 10/21`처럼 기준일. 원천이 주·월·분기 단위면 `기준 2026-09`, `기준 2026 2Q` |
| 계산 | 입력 중 가장 늦은 상태를 따라가요 |
| 정적 | 없음 |

이 표의 속도는 기능을 판정할 때 쓰는 대략적인 분류예요. 화면의 배지는 실제로 받은 값의 정보로 그려서, 같은 기능이라도 종목이나 시간에 따라 달라질 수 있어요.

### 1.4 코드 규칙

- 블룸버그 니모닉을 그대로 기능 코드로 써요.
- 같은 일을 하는 코드가 여러 개면 대표 코드 하나를 정하고, 나머지는 **별칭**으로 둬요.
  - 별칭을 입력하면 대표 기능의 해당 탭이 열려요.
  - ⏎ 라벨에 `GPO → GP 바 차트`처럼 어디로 가는지 보여 줘요.
- 기존 코드 19개(MON GP GIP WEI FXC CRYP N DES COMP HMAP IMAP MOST FA ECO GC GRID MAP PORT ALRT)는 그대로 둬요.
- 블룸버그 코드가 없는 한국 전용 기능은 `K`로 시작하는 자체 코드를 쓰고, 화면에 "블룸버그 코드 아님"으로 표시해요.
  - KINV, KPGM, KCRD, KWRN(KVI 별칭), KCB, KELS
  - 블룸버그 코드와 겹치지 않는지는 확인 필요예요.
- 출처에서 확인하지 못한 니모닉은 코드로도 별칭으로도 쓰지 않아요. 그런 기능은 대표 기능의 탭으로만 둬요(6절).
- `G`도 기능 코드로 넣어요. 한 글자 입력은 Enter가 선택만 한다는 규칙([05](05-command-line.md) §6.3)은 그대로예요.
- [05](05-command-line.md) §3.3은 아직 만들지 않은 기능도 앞부분 후보에 넣어요. 이 문서에서 포함·근사로 판정한 코드와 별칭이 그 목록이에요.

## 2. 전체 기능 표

**소스 약어**
- KIS: 한국투자증권 Open API
- ECOS: 한국은행 ECOS. 블룸버그의 ECOS 기능과 헷갈리지 않게 화면에는 "BOK ECOS"로 적어요.
- UST XML: 미국 재무부 일별 금리 XML. 테너 목록을 고정하지 않아요. 2025-02에 1.5개월물이 추가된 적이 있어요.
- KRX API: KRX Open API
  - 데이터는 전일(T-1)까지만 있고, 다음 날 08:00쯤 갱신돼요.
  - API마다 이용 승인을 따로 받아야 해요.
  - 화면에 "KRX 통계정보" 출처를 표시해야 해요.
- 금융위 채권: data.go.kr의 금융위원회 채권시세정보·채권기본정보·채권발행정보. 다음 영업일 13시 이후에 갱신돼요.
- SEC: SEC EDGAR
- FRED: 화면에 FRED 출처 문구를 표시해야 해요.
- ETF PDF: ETF의 구성종목 내역. 설정 명령 `PDF`와는 다른 말이에요.

## 4. 공용 인프라

### 4.1 KIS 요청 예산과 WebSocket 슬롯 배분기 (v0.1)

v0.4부터 KIS 엔드포인트가 20개 넘게 늘어요. 모두 같은 한도를 나눠 쓰니까 v0.1부터 배분기를 둬요.

- 한도
  - REST: 실전 초당 약 20건(확인 필요)
  - WS 등록: 약 40개(예제 코드 기준, 확인 필요). 체결과 호가가 슬롯을 따로 쓰는지도 확인 필요예요.
  - 접근토큰 재발급: 분당 1회
- 요청 큐의 우선순위
  1. 화면에 보이는 종목·기능의 요청
  2. 백그라운드 수집(일별 이력, 지난 시간봉 채우기, 순위, 수급, 사전 수집)
- WS 슬롯도 화면에 보이는 종목에 먼저 줘요. 슬롯이 모자라면 나머지는 몇 초 간격 REST 조회로 내려가요([03](03-functions.md) MON과 같은 방식). 장이 닫힌 종목은 슬롯을 쓰지 않고 5분마다 마감 값만 조회해요([04](04-data-sources.md) KIS 제약과 대응).
- REST 초당 호출 수는 초과(`EGW00201`)를 받으면 0.7배로 줄였다가 30초마다 1건씩 되돌려요.
- 기능마다 슬롯 비용을 표시해요. 기능을 열 때 필요한 슬롯을 보여 주고, 모자라면 REST 조회로 바뀐다고 알려요. 상태 표시줄의 사용량(`18/40`, [04](04-data-sources.md))과 같은 숫자를 써요.
  - v0.1: 커맨드 라인의 기능 설명 창에 `실시간 슬롯 주식이면 1개 · 지금 18/40 사용`을 보여 줘요. 기능을 열거나 MON 행을 골랐을 때 새로 필요한 슬롯이 남은 슬롯보다 많으면 알림으로 몇 개가 조회로 바뀌는지 알려요(더는 안 보이는 주식이 돌려줄 슬롯은 빼고 계산해요). 설정의 데이터 연결에 슬롯·호출 사용량과 기능별 슬롯 표를 보여 줘요.
- DART, SEC(초당 10건), KRX(하루 10,000건), Binance(IP 가중치)도 같은 큐 구조로 소스별 한도 안에서 줄을 세워요.

### 4.2 공용 업종 분류 (v0.2)

- KRX 업종, KSIC(DART 기업개황), 미국 SIC(SEC submissions)를 표 하나로 묶어요. 블룸버그 BICS 대신이에요.
- 미국 SIC는 SEC를 붙이는 v0.3부터 채워요.
- v0.2에 만든 것: KRX 업종(종목 마스터의 업종 대·중분류 코드 + 업종 이름 파일 idxcode.mst. 코스피·코스닥은 중분류, 없으면 대분류)과 코스피200 섹터(마스터의 코스피200 섹터 칸, 11개). KSIC는 DART 기업개황(`induty_code`)으로 DES에 코드만 보여요(인증키가 있을 때). KSIC 이름 표와 KSIC로 업종 묶기는 뒤에
- 쓰는 기능: HMAP·IMAP(v0.2), MOV(v0.4), PORT 특성(v0.8), RV·RVC·EQS·MRR·EA(v0.9)

### 4.3 공용 영업일·휴장일 달력 (v0.6 첫 작업)

- 만듦(v0.6): `@bt/shared` calendar.ts가 규칙으로 휴장일을 계산하고, 장 상태(맨 위 시계의 `휴장`, 마지막 장 마감 시각)와 영업일 계산(n영업일 뒤, 두 나라 공통 영업일)에 써요.
- 한국: 양력 공휴일·대체 공휴일 규칙, 음력 명절(설·추석·부처님오신날)과 선거일 표(2024~2030), 근로자의 날, 연말 휴장. 한국투자증권 키가 있으면 KIS 국내휴장일조회(`chk_holiday`, CTCA0903R)의 개장일 여부(`opnd_yn`)를 하루 한 번 받아 데이터 폴더(`holidays-kr.json`)에 두고, 규칙과 다른 날만 덮어써요(KIS가 하루 1회 호출을 권해요).
- 미국(NYSE)·영국(LSE)·일본(TSE): 규칙 계산(부활절, n번째 월요일, 주말 대체, 춘분·추분 근사식, 도쿄 연초·연말 휴장). KIS 해외 `countries_holiday`는 휴장일 목록이 아니라 해외결제일자조회라서 쓰지 않아요
- 유럽 대륙과 그 밖의 나라: 소스 확인 필요
- 쓰는 기능: FWCM, OIS 복리, FRD(v0.6), YAS 결제일, WBF 이론가(v0.7), KELS 관찰일(v0.10), CTM 만기 일정(v0.11)

### 4.4 데이터 사전 수집

이력을 짧게만 주거나 과거를 아예 주지 않는 데이터는 기능보다 먼저 수집을 시작해요.

| 수집 대상 | 시작 | 이유 |
|---|---|---|
| 뉴스 아카이브 | v0.2 | NSE는 수집을 시작한 뒤의 뉴스만 찾을 수 있어요 |
| FRED ICE BofA OAS | v0.3 | 최근 3년치만 줘요. 그보다 앞선 이력은 받을 수 없어요 |
| KOSPI200 행사가별 IV 스냅샷 | 옵션 기능(v0.10) 착수 전 | 장 마감 뒤 하루 1회면 충분해요. 빈 날은 KRX 옵션 일별(T-1, 2010년부터)로 다시 계산해 채워요. 내재변동성 필드가 있는지는 확인 필요예요 |
| Binance 옵션 행사가별 IV 스냅샷 | eapi로 크립토 탭을 만들 수 있다고 확인되면 바로 | 행사가별 IV의 과거를 주는 무료 소스를 찾지 못했어요 |

- **사전 수집이 필요 없는 것**: Binance OI·펀딩비. data.binance.vision에 2020-09부터 일별 metrics(OI, 롱숏 비율 포함)가 있고, `fundingRate`로 펀딩비 전체 이력을 받을 수 있어요. 기능을 만들 때 한꺼번에 받아요.
- 앱이 꺼져 있으면 수집도 멈춰요([01](01-overview.md)). 소스가 과거를 주는 범위에서는 다음 실행 때 빈 날을 채워요.

## 5. 제외 목록과 근사 목록

### 5.1 속도 제외

데이터를 구할 수 있어도 개인에게 의미 있는 속도가 아니에요.

| 대상 | 이유 |
|---|---|
| MKAC | 마켓메이커별 Level 2는 딜러·HFT용이고 KIS에도 없어요 |
| QR 확장(전 종목 틱 저장, 과거 틱 조회) | KIS 실시간 등록 한도가 있고 개인에게 의미가 없어요. 1~수 종목의 당일 테이프는 포함해요 |
| GIQ | 호가 틱 차트예요. 분봉이면 충분해요 |
| ALLQ(채권), ALLQ BBO·FX 스트리밍 호가 | 딜러 실시간 스트리밍 호가예요. 데이터도 없어요 |
| EBS | 인터뱅크 밀리초 피드예요. 데이터도 없어요 |
| BBO(선물 Level II), Binance 전체 depth diff 스트림 | 전 계약·전 종목의 전체 호가 깊이예요. 보는 1~2 계약의 선물 호가(WEIF·WBF 탭)와 한 종목의 10호가(BQ 탭)는 포함해요 |

## 6. 확인하지 못한 니모닉

- **출처를 찾지 못해 쓰지 않는 것**: Q, PEBD, FLNG, MPP, GY, CURV, IYC, ICX, SWDF, ILBE, ECOW, LPHP, KNEW, NTWK, BBT
- **출처가 약해서 탭으로만 두는 것**
  - MMR → BTMM 단기금리 탭
  - MMAP → HMAP 매트릭스 보기
  - EXS → CTM 만기 일정 탭
  - SKEW → OVDV 탭
  - GIV → GV
  - ECWB → ECST 탭
  - IVOL, VOLS → OVDV·HIVG가 대신해요
  - ASW → 데이터도 없어서 넣지 않아요
  - ICYM → 쓰지 않아요
- **니모닉을 모르는 기능**: 드로잉 도구(G·GP 안), 실질금리·BEI 모니터(IFMO 탭)
- **설명 확인 필요**: DRSK. 출처에 다른 기능의 설명이 잘못 붙어 있어요.
- **출처를 확인해 코드로 쓰는 것**: MEMB(HBS 도서관 안내), WEIF(블룸버그 Getting Started 안내), HS(류블랴나대 블룸버그 안내)

## 7. 정한 것

새로 결정이 필요한 항목이 생기면 [07](07-open-questions.md)에 올려요. 지금 이 문서에 남은 결정 필요 항목은 없어요.

**범위**
- 유료 데이터는 쓰지 않아요. KIS 해외선물 CME·SGX 실시간, 미국 개별주 옵션 체인(Massive·Alpaca), 미국 애널리스트 추정치·투자의견(FMP·Finnhub)은 넣지 않아요(5.3).
- Binance USDⓈ-M 선물 공개 데이터(펀딩비·미결제약정·베이시스·청산)는 넣어요. Binance·USDT 원칙 안이고 거래 없이 데이터만 써요. v0.10 CRYP 선물 탭이에요.
- Deribit은 넣지 않아요(코인은 Binance만). 크립토 옵션 탭은 Binance 옵션(eapi) 공개 시세로 만들 수 있는지 확인한 뒤 v0.10에 넣어요. 확인은 [07](07-open-questions.md)에서 관리해요.
- Binance 접속이 막힐 때의 예비 경로는 `data-api.binance.vision`이에요([04](04-data-sources.md)). 국내 거래소(Upbit 등) 시세를 예비로 쓰는 안은 "Upbit 제외" 결정과 부딪혀서 넣지 않아요.

**데이터와 코드**
- v0.3 데이터 소스: GC = ECOS + UST XML, ECO = FRED releases/dates + BLS·BEA 공표일정 + ECOS(KOSIS와 예상 칸 사용자 입력은 v0.6), 미국 FA = SEC EDGAR, PORT 환산 환율 = ECOS(3절)
- 데이터 사전 수집(4.4)
- 코드 규칙: K 접두 자체 코드, 별칭은 대표 기능의 탭으로 열고 ⏎ 라벨에 표시, `G` 추가(1.4)
- 새 자산군과 티커 문법 자리 예약(4.5)
- 신용등급은 DART 기재 등급 파싱과 수동 입력으로 받아요. 신평사 사이트 자동 수집은 약관을 확인하기 전에는 안 해요.
- 속도 표기와 화면 신선도 배지의 대응(1.3)
