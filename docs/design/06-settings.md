# 06 설정 화면

목업 (비공개 claude.ai 링크, "설정 · 커맨드 라인" 보드, 더 이상 고치지 않아요. 화면의 기준은 실제 앱과 이 문서예요): https://claude.ai/artifact/1AE6PgM1jVf4bTsRT85xoV

## 공통 규칙

- 바꾸면 **바로 적용**돼요. 저장 버튼은 없어요.
- 모든 패널과 떼어낸 창에 함께 적용돼요.
- 설정은 PC의 앱 데이터 폴더에 저장되고, 다음 실행 때 그대로 유지돼요.

## 설정 여는 방법

| 방법 | 설명 |
|---|---|
| `Ctrl+,` (Mac `⌘,`) | Windows·Mac 앱에서 흔히 쓰는 설정 단축키 |
| 커맨드 라인에 `설정⏎` 또는 `PDF⏎` | `PDF`는 블룸버그 Personal Defaults(개인 설정)의 줄임말이에요. 문서 파일 PDF와는 상관없어요. 블룸버그 습관 그대로 쓸 수 있어요 |
| 상태 표시줄의 `도움: 입문 ▾` | 설정 창을 열지 않고 자동완성 도움 수준만 바로 바꾸는 빠른 전환 |

앱키, 앱시크릿, 인증키는 입력하면 가려서 보여주고, PC 안에 암호화해서 저장해요. 한국투자증권 키 입력란 옆에는 "시세용으로는 잔고가 없는 별도 계좌의 키를 권해요(키로 주문도 낼 수 있어요)"라는 안내를 보여줘요.

## 단축키

- 바꿀 수 있는 키: 명령 팔레트, 설정 창, 전체 화면(Windows F11, Mac ⌃⌘F), 커맨드 라인으로, 커맨드 라인 ↔ 패널 본문(F6), 패널 본문으로(Windows Ctrl+↓), 패널 화면 뒤로·앞으로, 다음·이전 패널, 지금 칸 목록 열기(Alt+↓, Windows Ctrl+Space), 기능 목록(F1, v0.2), 설명 창·문법 요약(Mod+/), 자산군 EQUITY·CRYPTO·CURNCY·INDEX(Mod+Shift+E/C/X/I). 기본값은 [05](05-command-line.md) §10이에요.
- 키 이름을 누르면 새 키를 받아요. 누른 조합이 바로 적용돼요. Esc는 취소, Backspace는 그 키를 빼요. `+`로 키를 하나 더 붙일 수 있어요.
- 다른 단축키가 쓰는 키는 받지 않고 어디서 쓰는지 알려 줘요. 입력 규칙의 일부인 키(Tab, Enter, Esc, 화살표, 글자·숫자만, Mod+1…9, Alt+1…9, 되돌리기·복사·붙여넣기 같은 편집 키)도 받지 않아요.
- 바꾼 키만 저장해요. 줄마다 `기본값`, 아래에 `모두 기본값으로`가 있어요.
- 글자·숫자 키는 눌린 자리로 알아봐서 한글 모드에서도 같게 동작해요.
- 바꾼 키는 상태 표시줄·도움말·후보 목록의 키 안내에도 그대로 보여요.

## 커맨드 라인

### 자동완성 도움 수준

네 가지 수준 중 하나를 카드로 골라요. 카드 아래에 수준별 비교표가 있고, 고른 수준의 열이 강조돼요. 그 아래 **미리보기**가 `0059`를 입력했을 때 그 수준에서 실제로 어떻게 보이는지 바로 바꿔 보여줘요.

| 보이는 것 | 입문 | 표준 | 전문가 | 끔 |
|---|---|---|---|---|
| 후보 목록 | 입력하면 바로 | 입력하면 바로 | Tab·↓·Alt+↓를 누를 때, 또는 애매하거나 오류일 때 | ↓·Alt+↓를 누를 때만 |
| 흐린 글씨 미리보기 | ✓ | ✓ | ✓ | — |
| 기능 설명 | ✓ | ✓ | 코드와 이름만 | — |
| 설명 창 | 자리가 있으면 자동 | Ctrl+/ (Mac ⌘/) | Ctrl+/ (Mac ⌘/) | Ctrl+/ (Mac ⌘/) |
| 기능 목록 (v0.2) | F1 | F1 | F1 | F1 |
| 진행 표시 | 전체 | 전체 | 메시지만(오류·교정·겹침) | 메시지만(오류·교정·겹침) |
| 키 안내 · 시작 목록 · 팁 · 안 맞는 기능 흐리게 | ✓ | — | — | — |
| ⏎ 라벨 (Enter 결과 표시) | ✓ | ✓ | ✓ | ✓ |

- **진행 표시**는 입력줄 아래에서 `종목 ✓ │ 시장 ✓ │ 자산군 ✓ │ 기능 ▸`처럼 어디까지 채웠는지 보여 주는 줄이에요.
- 수준은 "보이는 것"만 바꿔요. Tab·Enter가 하는 일은 모든 수준에서 같아요.
- 첫 실행 기본값은 **입문**이에요.
- 입문에서 목록·Tab·화살표 없이 직접 쳐서 Enter 한 번에 실행한 명령이 30개가 되면 "표준으로 바꿀까요?"를 **한 번만** 물어봐요.
- 수준은 사용자가 바꾸기 전에는 저절로 바뀌지 않아요.

### 종목만 입력하고 Enter를 누르면

| 선택지 | 예 | 비고 |
|---|---|---|
| 지금 기능 유지 (지금 기능이 종목용이고 이 종목에 쓸 수 있을 때. 아니면 자산군별 기본 기능, 그것도 없으면 GP) | GIP를 보던 패널에서 `005930⏎` → `005930 KS EQUITY GIP`. WEI를 보던 패널에서는 → `005930 KS EQUITY GP` | 기본값 |
| 블룸버그식: 그 종목의 기능 메뉴 열기 | `005930⏎` → 기능 메뉴(번호 목록). 숫자 + Enter(`3⏎`)로 그 기능. 기능을 함께 치면(`005930 GP⏎`) 메뉴 없이 바로 | v0.2 |

### 자산군별 기본 기능 (v0.2)

종목만 쳤는데 지금 기능을 그 종목에 쓸 수 없을 때(WEI를 보던 패널 등) 열 기능을 자산군(주식·코인·환율·지수)마다 골라요. 그 자산군에 쓸 수 있는 종목 기능만 고를 수 있고, 기본은 GP예요.

### 입력 도우미

| 항목 | 설명 | 기본 |
|---|---|---|
| Tab으로 시장·자산군 자동 채우기 | `0059` → Tab → `005930 KS EQUITY`처럼 빈 칸을 함께 채워요 | 켬 |
| 한/영 실수 교정 | 한글 모드로 친 `헤`를 `GP`로 바꿔요. 종목 뒤에서는 바로 실행하고, 줄 첫머리에서는 제안만 해요 | 켬 |
| 사용 팁 | 더 짧게 입력하는 방법을 가끔 알려줘요 (같은 팁은 최대 3번) | 켬 |
| HTS식 6자리 바로 열기 (v0.2) | 국내 종목코드 6자리를 다 치는 순간 Enter 없이 종목을 바꿔요. 정확한 6자리 코드(코스피·코스닥)에서만 | 끔 |
| F키 모드 (Windows, v0.2) | 커맨드 라인에서 F8 = EQUITY, F9 = CRYPTO, F10 = INDEX, F11 = CURNCY. 켜 있는 동안 F11은 전체 화면이 아니라 CURNCY라서, 전체 화면 단축키가 F11이면 바꾸라고 알려 줘요 | 끔 |
| 기억된 선택 초기화 | 검색어별로 지난번 고른 줄을 맨 위에 올리는 것(↺)과, 겹치는 이름에서 내가 정한 기본값을 지워요. 자주 쓴 종목이 위에 오는 사용 기록은 남아요 | 버튼 |
| 별칭 (v0.2) | `ALIAS 별칭 종목⏎`으로 만든 별칭 목록과 지우기 | 목록 |

각 항목의 실제 동작은 [05 커맨드 라인과 자동완성](05-command-line.md)에 있어요.
