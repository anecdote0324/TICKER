# 06 설정 화면

목업 (비공개 claude.ai 링크, "설정 · 커맨드 라인" 보드): https://claude.ai/artifact/1AE6PgM1jVf4bTsRT85xoV

## 공통 규칙

- 바꾸면 **바로 적용**돼요. 저장 버튼은 없어요.
- 모든 패널과 떼어낸 창에 함께 적용돼요.
- 설정은 PC의 앱 데이터 폴더에 저장되고, 다음 실행 때 그대로 유지돼요.

## 설정 여는 방법

| 방법 | 설명 |
|---|---|
| `Ctrl+,` (Mac `⌘,`) | Windows·Mac 앱에서 흔히 쓰는 설정 단축키 |
| 커맨드 라인에 `설정⏎` 또는 `PDF⏎` | `PDF`는 블룸버그 Personal Defaults(개인 설정)의 줄임말이에요. 문서 파일 PDF와는 상관없어요. 블룸버그 습관 그대로 쓸 수 있어요 |
| 상태 표시줄의 `도움: 입문 ▾` | 설정 창을 열지 않고 자동완성 도움 수준만 바로 바꾸는 빠른 전환 |

## 분류

왼쪽에 분류 목록이 있고, 오른쪽에 해당 항목이 나와요.

| 분류 | 들어갈 항목 |
|---|---|
| 일반 | 시작할 때 마지막 워크스페이스 복원 |
| 화면 | 테마(Modern. Classic은 넣을지 미정), 강조 색(등락·선택·자산군 칩 색과 겹치지 않는 색만), 등락 색(글로벌식·한국식), 글자 크기 |
| **커맨드 라인** | 아래 상세 참고 |
| 단축키 | 단축키 목록과 바꾸기. Windows 언어 전환 단축키 등과 겹칠 때 다시 지정할 수 있게 해요 |
| 데이터 연결 | 한국투자증권 앱키·앱시크릿 입력과 연결 테스트, 실시간 구독·호출 예산 사용량, Binance 연결 상태, 환율 갱신 주기. 기능이 늘어나는 단계마다 키 입력란이 추가돼요: DART(v0.2), ECOS·FRED·KOSIS·SEC EDGAR 연락처(v0.3), 네이버·KRX Open API(v0.4), 공공데이터포털(v0.7), EIA(v0.11). 소스마다 출처 표시 문구와 이용 조건 링크를 함께 보여줘요 |
| 알림 | v0.3 (ALRT)과 함께 |
| 정보 | 앱 버전 |

앱키, 앱시크릿, 인증키는 입력하면 가려서 보여주고, PC 안에 암호화해서 저장해요. 한국투자증권 키 입력란 옆에는 "시세용으로는 잔고가 없는 별도 계좌의 키를 권해요(키로 주문도 낼 수 있어요)"라는 안내를 보여줘요.

## 커맨드 라인

### 자동완성 도움 수준

네 가지 수준 중 하나를 카드로 골라요. 카드 아래에 수준별 비교표가 있고, 고른 수준의 열이 강조돼요. 그 아래 **미리보기**가 `0059`를 입력했을 때 그 수준에서 실제로 어떻게 보이는지 바로 바꿔 보여줘요.

| 보이는 것 | 입문 | 표준 | 전문가 | 끔 |
|---|---|---|---|---|
| 후보 목록 | 입력하면 바로 | 입력하면 바로 | Tab·↓·Alt+↓를 누를 때, 또는 애매하거나 오류일 때 | ↓·Alt+↓를 누를 때만 |
| 흐린 글씨 미리보기 | ✓ | ✓ | ✓ | — |
| 기능 설명 | ✓ | ✓ | 코드와 이름만 | — |
| 설명 창 | 자리가 있으면 자동 | F1 또는 Ctrl+/ (Mac ⌘/) | F1 또는 Ctrl+/ (Mac ⌘/) | F1 또는 Ctrl+/ (Mac ⌘/) |
| 진행 표시 | 전체 | 전체 | 메시지만(오류·교정·겹침) | 메시지만(오류·교정·겹침) |
| 키 안내 · 시작 목록 · 팁 · 안 맞는 기능 흐리게 | ✓ | — | — | — |
| ⏎ 라벨 (Enter 결과 표시) | ✓ | ✓ | ✓ | ✓ |

- **진행 표시**는 입력줄 아래에서 `종목 ✓ │ 시장 ✓ │ 자산군 ✓ │ 기능 ▸`처럼 어디까지 채웠는지 보여 주는 줄이에요.
- 수준은 "보이는 것"만 바꿔요. Tab·Enter가 하는 일은 모든 수준에서 같아요.
- 첫 실행 기본값은 **입문**으로 제안했어요. 아직 확정하지 않았어요 ([07 미정 사항](07-open-questions.md)).
- 입문에서 목록·Tab·화살표 없이 직접 쳐서 Enter 한 번에 실행한 명령이 30개가 되면 "표준으로 바꿀까요?"를 **한 번만** 물어봐요.
- 수준은 사용자가 바꾸기 전에는 저절로 바뀌지 않아요.

### 종목만 입력하고 Enter를 누르면

| 선택지 | 예 | 비고 |
|---|---|---|
| 지금 기능 유지 (지금 기능이 종목용이고 이 종목에 쓸 수 있을 때. 아니면 GP) | GIP를 보던 패널에서 `005930⏎` → `005930 KS EQUITY GIP`. WEI를 보던 패널에서는 → `005930 KS EQUITY GP` | 추천. 기본값은 미정 ([07](07-open-questions.md)) |
| 블룸버그식: 그 종목의 기능 메뉴 열기 | `005930⏎` → 기능 메뉴 | v0.2부터. v0.1에는 첫 선택지만 있어요 |

### 입력 도우미

| 항목 | 설명 | 기본 |
|---|---|---|
| Tab으로 시장·자산군 자동 채우기 | `0059` → Tab → `005930 KS EQUITY`처럼 빈 칸을 함께 채워요 | 켬 |
| 한/영 실수 교정 | 한글 모드로 친 `헤`를 `GP`로 바꿔요. 종목 뒤에서는 바로 실행하고, 줄 첫머리에서는 제안만 해요 | 켬 |
| 사용 팁 | 더 짧게 입력하는 방법을 가끔 알려줘요 (같은 팁은 최대 3번) | 켬 |
| 기억된 선택 초기화 | 검색어별로 지난번 고른 줄을 맨 위에 올리는 것(↺)과, 겹치는 이름에서 내가 정한 기본값을 지워요. 자주 쓴 종목이 위에 오는 사용 기록은 남아요 | 버튼 |

각 항목의 실제 동작은 [05 커맨드 라인과 자동완성](05-command-line.md)에 있어요.

### 나중에 추가할 항목

- 6자리 종목코드를 끝까지 치면 Enter 없이 바로 종목을 바꾸는 HTS 방식 (기본 꺼짐, 넣는 시기 미정)
- 자산군을 F키로 입력하는 F키 모드 (Windows, v0.2)
- 자산군별 기본 기능 지정 (v0.2)
