# 06 설정 화면

목업 (비공개 claude.ai 링크, "설정 · 커맨드 라인" 보드): https://claude.ai/artifact/1AE6PgM1jVf4bTsRT85xoV

## 공통 규칙

- 바꾸면 **바로 적용**돼요. 저장 버튼은 없어요.
- 모든 패널과 떼어낸 창에 함께 적용돼요.
- 설정은 PC의 앱 데이터 폴더에 저장되고, 다음 실행 때 그대로 유지돼요.

## 설정 여는 방법

| 방법 | 설명 |
|---|---|
| `Ctrl+,` (Mac `⌘,`) | Windows·Mac 앱에서 흔히 쓰는 설정 단축키 |
| 커맨드 라인에 `설정⏎` 또는 `PDF⏎` | `PDF`는 블룸버그의 개인 설정 명령과 같아서 블룸버그 습관 그대로 쓸 수 있어요 |
| 상태 표시줄의 `도움: 입문 ▾` | 설정 창을 열지 않고 자동완성 도움 수준만 바로 바꾸는 빠른 전환 |

## 분류

왼쪽에 분류 목록이 있고, 오른쪽에 해당 항목이 나와요.

| 분류 | 들어갈 항목 |
|---|---|
| 일반 | 시작할 때 마지막 워크스페이스 복원 |
| 화면 | 테마(Modern, 나중에 Classic), 강조 색, 등락 색(글로벌식·한국식), 글자 크기 |
| **커맨드 라인** | 아래 상세 참고 |
| 단축키 | 단축키 목록과 바꾸기. Windows 언어 전환 단축키 등과 겹칠 때 다시 지정할 수 있게 해요 |
| 데이터 연결 | 한국투자증권 앱키·앱시크릿 입력과 연결 테스트, Binance 연결 상태, 환율 갱신 주기 |
| 알림 | v0.3 (ALRT)과 함께 |
| 정보 | 앱 버전 |

앱키와 앱시크릿은 입력하면 가려서 보여주고, PC 안에 암호화해서 저장해요.

## 커맨드 라인

### 자동완성 도움 수준

네 단계 중 하나를 카드로 골라요. 카드 아래에 단계별 비교표가 있고, 선택한 단계 열이 강조돼요. 그 아래 **미리보기**가 `0059`를 입력했을 때 그 단계에서 실제로 어떻게 보이는지 바로 바꿔 보여줘요.

| 보이는 것 | 입문 | 표준 | 전문가 | 끔 |
|---|---|---|---|---|
| 후보 목록 | 입력하면 바로 | 입력하면 바로 | Tab · ↓ · 애매할 때 | ↓ 누를 때만 |
| 흐린 글씨 미리보기 | ✓ | ✓ | ✓ | — |
| 기능 설명 | ✓ | ✓ | 코드와 이름만 | — |
| 설명 창 | 자동 | F1 | F1 | F1 |
| 단계 표시 | ✓ | ✓ | 오류만 | 오류만 |
| 키 안내 · 시작 목록 · 팁 | ✓ | — | — | — |
| Enter 결과 표시 (⏎ 라벨) | ✓ | ✓ | ✓ | ✓ |

- 첫 실행 기본값은 **입문**으로 제안했어요. 아직 확정하지 않았어요 ([07 미정 사항](07-open-questions.md)).
- 직접 입력으로 명령을 30번 실행하면 "표준 모드로 바꿀까요?"를 **한 번만** 물어봐요.
- 단계는 사용자가 바꾸기 전에는 저절로 바뀌지 않아요.

### 종목만 입력하고 Enter를 누르면

| 선택지 | 예 | 비고 |
|---|---|---|
| 지금 기능 유지 (기능이 없으면 GP 차트) | `005930⏎` → `005930 KS EQUITY GP` | 추천. 기본값은 미정 ([07](07-open-questions.md)) |
| 블룸버그식: 그 종목의 기능 메뉴 열기 | `005930⏎` → 기능 메뉴 | v0.2 |

### 입력 도우미

| 항목 | 설명 | 기본 |
|---|---|---|
| Tab으로 시장·자산군 자동 채우기 | `0059` → Tab → `005930 KS EQUITY`처럼 빈 칸을 함께 채워요 | 켬 |
| 한/영 실수 교정 | 한글 자판으로 친 `ㅎㅔ`를 `GP`로 바꿔 제안해요 | 켬 |
| 사용 팁 보기 | 더 짧게 입력하는 방법을 가끔 알려줘요 (같은 팁은 최대 3번) | 켬 |
| 기억된 선택 초기화 | 자주 고른 후보가 위로 올라오는 순서를 처음 상태로 되돌려요 | 버튼 |

각 항목의 실제 동작은 [05 커맨드 라인과 자동완성](05-command-line.md)에 있어요.

### 나중에 추가할 항목

- 6자리 종목코드를 끝까지 치면 Enter 없이 바로 종목을 바꾸는 HTS 방식 (기본 꺼짐)
- 자산군을 F키로 입력하는 F키 모드 (Windows, v0.2)
- 자산군별 기본 기능 지정 (v0.2)
