# 버전별 기능

버전마다 어떤 기능이 들어가는지와, 지금 어디까지 만들었는지를 한곳에 모았어요.

- 기능마다 넣을지·뺄지 판정과 데이터 소스는 [08 블룸버그 기능 커버리지](design/08-bloomberg-coverage.md)에 있어요. 이 문서의 기능 목록은 08에서 포함·근사로 판정한 코드예요.
- 단계를 나눈 이유와 v0.1~v0.3의 자세한 범위는 [03 기능 코드와 단계별 범위](design/03-functions.md)에 있어요.
- 기능을 만들거나 범위가 바뀌면 이 문서의 상태도 같은 커밋에서 고쳐요.
- 지금 앱의 쓰는 법(모든 기능·명령어·단축키·설정)은 [사용설명서](manual/README.md)에 있어요. 기능을 만들면 사용설명서도 함께 고쳐요.

**상태 표기**

| 표기 | 뜻 |
|---|---|
| 완료 | 만들었고 이 개발 환경에서 실제로 동작을 확인했어요 |
| 확인 필요 | 만들었지만 실제 환경에서 시험하지 못했어요(한국투자증권 계정, Windows·Mac 실기기 등) |
| 일부 | 설계의 일부만 만들었어요. 남은 일은 그 버전의 "남은 일"에 있어요 |
| 미완 | 그 버전 범위인데 아직 만들지 않았어요 |
| 예정 | 아직 시작하지 않은 버전이에요 |

`*`는 근사 기능이에요. 원래 데이터를 개인이 구할 수 없어서 공개 데이터로 비슷하게 만들고, 화면에 "근사"와 출처를 표시해요.

## v0.1 뼈대와 실시간 시세

목표: **블룸버그처럼 보이고 실제로 움직이는 화면**. 상태: 정식 `v0.1.0`으로 냈어요(11/3). 미리 보기 `v0.1.0-beta.1`~`beta.12`로 실사용 점검을 거쳤고, beta.12를 확인한 뒤 정식으로 내기로 했어요(사용자 결정). 아래 '실제 환경에서 확인할 것'에서 체크하지 않은 것은 정식 뒤에도 [07](design/07-open-questions.md)에서 계속 확인하고, 고칠 것이 나오면 `0.1.x`로 내요.

## 넣지 않는 것

매매(주문) 기능 전부, 유료 데이터가 있어야 하는 기능(CME 실시간, 미국 개별주 옵션 체인, 미국 애널리스트 추정치), 개인에게 의미 없는 속도의 데이터가 필요한 기능(전 종목 틱, 딜러 실시간 호가 등), Upbit·김치 프리미엄, Deribit, 자동 업데이트. 목록과 이유는 [08](design/08-bloomberg-coverage.md) §5에 있어요.
